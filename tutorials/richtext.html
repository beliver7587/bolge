富文本编辑 / PDF 导出

简历工坊的核心能力：所见即所得地编辑，并一键导出 PDF。

1. 这是什么

富文本编辑器让用户像用 Word 一样排版（加粗、列表、标题），底层存的是带格式的 HTML。PDF 导出则把网页/HTML 变成可下载的 PDF 文件。两者结合，就是“在线写简历 → 导出成 PDF 投递”。

2. 富文本编辑器

常见方案：contenteditable 原生属性（浏览器自带可编辑）、或成熟库如 TipTap（基于 ProseMirror）、Slate。简历工坊用 React 生态的编辑器实现模块拖拽与分栏。

// 最简单的可编辑区
<div contenteditable="true">在这里直接打字，可选中加粗…</div>

3. 导出 PDF

前端常用 html2pdf.js（内部用 html2canvas 截图 + jsPDF 生成）：

import html2pdf from 'html2pdf.js';
function exportPdf(){
  html2pdf().set({ filename:'我的简历.pdf', jsPDF:{ unit:'mm', format:'a4' } })
            .from(document.getElementById('resume')).save();
}
注意：html2pdf 是“截图式”，复杂 CSS（如 flex 分页）可能不理想；追求精准可用后端 pdfkit 或浏览器自带 window.print() + 打印样式。

4. 简历工坊怎么做

思路：① 每个简历模块是可拖拽卡片，用户排序；② 内容存为结构化数据（JSON），同时渲染成 HTML 预览；③ 调大模型（见 LLM）一键润色文案；④ 导出时把预览 DOM 转 PDF。

5. 常见坑

坑 1：PDF 分页截断——给模块加 break-inside: avoid（CSS）。
坑 2：字体未嵌入，换设备打开样式跑偏——优先用系统通用字体。
坑 3：编辑器粘贴 Word 带来脏样式，要过滤白名单标签。
