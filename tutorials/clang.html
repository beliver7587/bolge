C 语言

贴近硬件的通用编程语言 —— 学指针、内存与编译，是理解操作系统、嵌入式、底层的第一步。学完你能写可运行的 C 程序。

1. 这是什么

C 语言 诞生于 1972 年，至今仍是操作系统（Linux）、嵌入式、编译器的基石。它离硬件近、运行快，但需手动管理内存。

对比：Python 替你管内存、语法简；C 要自己管，更底层也更难。

2. 环境准备

装编译器 gcc：Windows 装 MinGW 或 WSL；Mac 装 Xcode 命令行工具；Linux sudo apt install gcc。写代码用 VS Code 或记事本皆可。

3. 第一个程序

#include <stdio.h>
int main() {
  printf("Hello C\n");
  return 0;
}

保存为 hello.c，编译运行：

gcc hello.c -o hello
./hello

5. 指针

指针存“地址”，是 C 的灵魂也是难点：

int x = 10;
int *p = &x;        // p 指向 x 的地址
printf("%d", *p);  // 解引用得到 10
要点：& 取地址，* 解引用；理解指针是学通 C 的关键。

6. 一个例子

#include <stdio.h>
int add(int a, int b) { return a + b; }
int main() {
  printf("3+4=%d\n", add(3, 4));
  return 0;
}

7. 常见坑

坑 1：数组越界不报错但会崩或改坏别的数据；时刻检查下标。
坑 2：忘记 return 0 或 main 写错签名，行为未定义。
坑 3：scanf 漏写 &，读不入变量。
坑 4：内存泄漏/野指针（malloc 不 free、用已释放指针）。
