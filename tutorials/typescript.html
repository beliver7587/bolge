TypeScript

给 JavaScript 加上“类型”的超级加强版 —— 写代码时就能发现错误，不 Runtime 才崩。学完你能用 TS 写更稳的前端/后端。

1. 这是什么

TypeScript（TS） 是微软出的语言，本质是“带了类型的 JavaScript”。浏览器不认识 TS，需要先编译成 JS 才能跑。

一句话：JS 是“写完跑起来才知道错没错了”；TS 是“写的时候编辑器就提醒你类型不对”。
为什么学：大项目、团队开发几乎都用 TS；React / Next.js / Node 后端都推荐 TS；能大幅减少低级 bug。

2. 环境准备

1

装 Node.js

见 React 教程 的环境准备。

2

全局安装 TS 编译器

npm install -g typescript
tsc -v        # 看到版本号即成功

3. 第一个 TS 文件

新建 hello.ts：

function greet(name: string): string {
  return '你好，' + name;
}
console.log(greet('小王'));

注意 : string 就是“类型标注”。编译并运行：

tsc hello.ts      # 生成 hello.js
node hello.js     # 输出：你好，小王
试试：把 greet(123) 传个数字，保存后 tsc 会直接报错——“Argument of type 'number' is not assignable to 'string'”。这就是 TS 的价值。

4. 基础类型

let age: number = 18;
let name: string = '小王';
let isOk: boolean = true;
let list: number[] = [1, 2, 3];      // 数字数组
let tuple: [string, number] = ['a', 1]; // 元组
let anything: any = 123;             // 任意类型（尽量少用）
let u: undefined = undefined;
let n: null = null;
提示：多数情况不用手写类型，TS 会“类型推断”，比如 let x = 1 自动知道 x 是 number。

5. 接口与类型

interface 用来描述“一个对象长什么样”，最常见： 

interface User {
  id: number;
  name: string;
  email?: string;        // ? 表示可选
}

function printUser(u: User) {
  console.log(u.id, u.name);
}
printUser({ id: 1, name: '小红' });   // OK，email 可选
好处：函数参数有没有传错字段、少传了必填项，编辑器立刻标红。

6. 泛型入门

泛型 = “类型当参数”，写可复用的通用函数/容器：

function first<T>(arr: T[]): T | undefined {
  return arr[0];
}
first<number>([1, 2, 3]);   // 返回 number
first<string>(['a', 'b']);  // 返回 string
在 React 里：useState<number>(0) 就是泛型，告诉 state 是 number 类型。

7. 在 React 里用

interface Props {
  title: string;
  count?: number;
}
function Card({ title, count = 0 }: Props) {
  return <div><h3>{title}</h3><p>{count}</p></div>;
}

给组件 props 加类型后，用 <Card /> 时漏传必填 title 会报错，安全感拉满。

8. 常见坑

坑 1：TS 只在“编译期”检查，any 会跳过检查。滥用 any 等于白用 TS。
坑 2：装了 TS 却没配置 tsconfig.json，编辑器不报错。新项目用 tsc --init 生成配置（Vite/Next 已自带）。
坑 3：“类型断言” obj as Type 是强行告诉 TS“我比你知道”，用错会埋雷，谨慎用。
坑 4：第三方库没类型时，需装 @types/xxx 或写 declare module 声明，否则报找不到模块。
坑 5：null 和 undefined 默认不能赋给其它类型（strict 模式）；用 string | null 或可选 ?:。
