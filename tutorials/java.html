Java：从小白到企业级语言

Java 是“一次编写、到处运行”的面向对象语言，靠 JVM 跨平台，是企业后端与安卓的主力。本教程讲清它的类型/对象模型、集合与异常，以及 JVM 内存与 GC——理解这些才能用好 Spring 生态。

1. 它是什么

Java 源码编译成字节码，跑在 JVM（Java 虚拟机）上，所以跨平台。强类型、自动 GC、生态庞大。

一句话：Java = 强类型 OOP + JVM + 成熟生态。稳、慢热但长青。

2. 工程化起步

public class Main {
  public static void main(String[] args) {
    System.out.println("hi");
  }
}
// javac Main.java && java Main

现代用 Spring Boot + Maven/Gradle 管理依赖与构建。

3. 基础语法

  • 八种基本类型：int/long/float/double/boolean/char/byte/short。
  • 其余都是对象（如 String）。
  • 数组：int[] a = new int[3];

4. 面向对象

  • 封装：用 private + getter/setter 控制访问。
  • 继承：extends，单继承。
  • 多态：父类引用指向子类对象，运行时动态分派。
资深：面向接口编程（依赖抽象而非实现），是 Spring 依赖注入的自然延伸。

5. 集合框架

接口实现特点
ListArrayList / LinkedList有序可重复
SetHashSet / TreeSet不重复
MapHashMap / TreeMap键值对
坑：遍历时删元素要用 Iterator.remove()，直接 list.remove 会 ConcurrentModificationException。

6. 异常

try { risky(); } catch (IOException e) { log(e); } finally { close(); }
  • checked 异常必须处理或声明；RuntimeException 不强制。
  • 资源用 try-with-resources 自动关闭。

7. 泛型

List<String> list = new ArrayList<>();  // 编译期类型安全

泛型在运行期被擦除（类型擦除），所以 List<String>.class 不存在。

8. JVM 与 GC

  • 堆：对象实例；栈：方法局部变量与调用。
  • GC：自动回收不可达对象，不用像 C 手动 free。
  • 调优关注吞吐/停顿，常用 G1/ZGC 收集器。
资深视角：理解堆分代（年轻/老年代）能解释为什么“大对象/缓存”会触发 Full GC 卡顿。

9. 多线程

new Thread(() -> { /* 任务 */ }).start();
// 或用 ExecutorService 线程池，避免无限制建线程
坑：共享变量不加同步会出竞态；用 synchronized/Lock/并发容器。

10. 与 Spring

Java 是语言，Spring 是框架。学会 Java OOP 与集合后，Spring 才能顺手——框架建立在接口、反射、注解之上。

11. 常见坑

坑 1 相等比较：对象用 == 比引用、equals 比值；String 必须用 equals。
坑 2 NPE：空指针是 Java 头号异常；用 Optional 或判空。
坑 3 自动装箱：Integer 缓存 -128~127，区间外 == 不相等。

12. 资源与路线

  1. 《Java 核心技术》、官方 Java Docs。
  2. 接着学 Spring/Spring Boot 做后端。
  3. 练：用集合 + 异常 + 泛型写一个简单学生管理系统。
资深标志：理解 JVM 内存与 GC、用接口与并发容器写出线程安全代码，并知道何时该上 Spring 而非裸写。

完整流程：Java 程序开发与运行

1. 编写
public class Hello {
  public static void main(String[] args){
    System.out.println("Hello Java");
  }
}
2. 编译运行
javac Hello.java
java Hello
3. Maven 项目
mvn archetype:generate -DgroupId=com.example -DartifactId=demo -DarchetypeArtifactId=maven-archetype-quickstart
mvn package
java -jar target/demo-1.0-SNAPSHOT.jar
要点：Java 是编译型语言；JVM 让字节码跨平台；包名通常用反域名。
