Function Calling 工具调用

把“工具说明书”交给模型 —— 让它自己决定调哪个、传什么参数。

1. 这是什么

模型本身不会查数据库、不会算账、不会发消息。我们给它一份“工具说明书”（每个工具叫什么、要什么参数、返回什么），模型在需要时自己决定：调哪个工具、填什么参数。这就是 Function Calling。它让 AI 从“只会说”变成“还会做”。

2. 给模型工具说明书

const tools = [{
  name: 'query_order',
  description: '查询用户订单状态与物流',
  parameters: {
    type:'object',
    properties:{ orderId:{ type:'string', description:'订单号' } },
    required:['orderId']
  }
}];

3. 执行流程

用户：“我的订单 A10086 到哪了？” → 模型识别要查订单，返回调用 {tool:'query_order', args:{orderId:'A10086'}} → 你的代码执行该工具，拿到结果 → 把结果回传模型 → 模型组织成自然语言回答

4. Memora 的工具

工具作用
search_knowledge主动检索公司知识库
search_memory检索该用户长期记忆
query_order查订单状态/物流
create_ticket建售后工单
escalate_human转人工

5. 常见坑

坑 1：工具描述写不清，模型乱传参——description 要写“何时用、参数含义”。
坑 2：工具执行失败直接抛错让链崩——要捕获并回传结构化错误，让模型自我纠正。
坑 3：暴露危险工具（如删库）给模型——要加权限与确认。
