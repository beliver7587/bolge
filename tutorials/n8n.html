n8n 自动化

开源可视化工作流工具 —— Memora 用它每天定时抓新闻推企业微信。

1. 这是什么

n8n 是开源的可视化工作流自动化平台，类似“程序员版 IFTTT”：拖节点、连线，把“定时触发 → 调接口 → 处理数据 → 发通知”串成自动化流程。Memora 用它做“每日 20:00 抓新闻推企业微信”。

2. 核心概念

  • Trigger（触发器）：流程起点，如 Schedule（定时）、Webhook（被调用）。
  • Node（节点）：每一步操作，如 HTTP Request、Function、消息发送。
  • 连接：节点之间的数据流向。

3. 每日热点实例

Schedule(每天20:00) → HTTP GET 本应用 /api/hotnews/fetch → 组装成 Markdown → HTTP POST 企业微信机器人 webhook

4. 发布模型坑（真实）

致命坑：n8n v2.8 是“发布模型”——导入的工作流只设 active=1 不算发布，必须 activeVersionId = versionId 才会注册定时器。否则日志显示 “0 published”，定时任务死活不跑。修复 SQL：UPDATE workflow_entity SET activeVersionId=versionId WHERE active=1 AND activeVersionId IS NULL;

5. 常见坑

坑 1：把 n8n UI 裸奔公网——务必绑定 127.0.0.1 再用 Nginx 子域名 + Basic Auth 暴露。
坑 2：版本不一致导致工作流不兼容——导入和导出用同版本。
坑 3：用 systemd 托管（见 systemd），别用临时终端跑。
