游戏物理 / AABB 碰撞

2D 游戏最简碰撞算法与手感优化 —— 平台格斗跟手的关键。

1. 这是什么

游戏引擎要算“物理（重力/速度）+ 碰撞（撞没撞上）+ 胜负”。2D 游戏最普遍用 AABB（轴对齐包围盒）做碰撞：把物体当矩形，判断矩形是否重叠。这是成本最低、最稳的碰撞算法，火柴人派对的引擎就用它。

2. AABB 碰撞

两个矩形 (x,y 左上角, w,h 宽高) 重叠的判定：

aabb(ax,ay,aw,ah, bx,by,bw,bh){
  return ax < bx+bw && ax+aw > bx && ay < by+bh && ay+ah > by;
}
解读：四个条件同时满足（A 的左右都跨过 B、上下都跨过 B）才重叠——这就是“撞上了”。

3. 分段重力

为让跳跃“上去轻、下来重”更跟手，用两段重力：

const G_UP = 1800;   // 上升阶段重力（轻）
const G_DOWN = 3200; // 下落阶段重力（重）
const MAX_JUMPS = 2; // 二段跳

4. 手感优化

  • 土狼时间（Coyote Time）：离开平台边缘一小会儿仍允许跳。
  • 跳跃缓冲（Jump Buffer）：落地前提前按跳，落地瞬间自动起跳。
  • 加速度 + 摩擦力：不是一按就满速，而是平滑加减速。

5. 常见坑

坑 1：碰撞只判一帧会“穿透”快速物体——高速物体要做连续/扫掠检测。
坑 2：手感差往往是“重力/速度参数”没调，而非算法问题。
坑 3：坐标用浮点，渲染取整避免抖动。
