SSE 流式输出

服务端一边生成一边推字 —— ChatGPT 打字机效果的本源。

1. 这是什么

SSE = Server-Sent Events，是一种“服务器向浏览器单向持续推送”的协议。模型一个字一个字往外生成，服务器就一个事件一个事件推给前端，于是你看到“打字机”效果。用户首字等待极短，体验远好于“等半天才吐一整段”。

2. SSE vs WebSocket

SSEWebSocket
方向服务器→浏览器（单向）双向
协议基于 HTTP，简单独立握手协议
适用流式文本/通知实时双向（游戏/聊天）

3. 服务端（Node/Express）

function openSSE(res){
  res.setHeader('Content-Type','text/event-stream; charset=utf-8');
  res.setHeader('Cache-Control','no-cache, no-transform');
  res.setHeader('Connection','keep-alive');
  res.setHeader('X-Accel-Buffering','no');   // ★ 关 Nginx 缓冲
}
// 每生成一段就：
res.write(`data: ${JSON.stringify(chunk)}\n\n`);

5. Nginx 关键

必配：经过 Nginx 反代时必须 proxy_buffering off + 响应头 X-Accel-Buffering: no，否则 Nginx 缓冲、前端看不到逐字流式（Memora 真实踩坑）。并把 proxy_read_timeout 调大到 300s+。
