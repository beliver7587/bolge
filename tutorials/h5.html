H5 移动端开发：从零做一个可分享的手机页

在国内，“H5”一般指运行在手机浏览器里的 HTML5 互动页面——邀请函、营销活动、小游戏、问卷都算。它本质是 HTML + CSS + JS，但多了“移动适配、触摸交互、微信分享”这套手机专属玩法。本教程带你从 viewport 适配到上线一个可分享的活动页。

1. 它是什么

H5 页面 = 一个针对手机屏幕优化的单页 Web 应用。它不在应用商店上架，靠二维码/链接在微信、浏览器里打开，用完即走。

一句话：H5 = 手机上的“即点即用”网页，重点在移动适配 + 触摸交互 + 社交分享。

2. 为什么叫 H5

  • 源自 HTML5 的简称，当年 HTML5 让网页能离线、能绘图、能交互，手机页正好吃这波红利。
  • 行业约定俗成：凡是“手机里点开的那张网页”都叫 H5，不管它用没用 Canvas。
  • 和“小程序/App”区分开：H5 不需要安装，扫码即开。

3. 视口与适配

手机浏览器默认会把页面当成 ~980px 宽再缩放到屏幕，所以必须声明 viewport：

<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">
  • width=device-width：页面宽度等于设备宽度（关键）。
  • user-scalable=no：禁止双指缩放，做“像 App”的体验（视场景取舍）。
坑：忘了 viewport，页面会被缩成一张小图，字小到看不清。

4. 尺寸单位 rem/vw

手机屏幕宽度从 320 到 430px 不等，写死 px 会错乱，常用两种方案：

方案 A：vw（最简单）
/* 设计稿宽 375px，则 1px = 100/375 vw ≈ 0.2667vw */
.box { width: 50vw; font-size: 4vw; }
方案 B：rem + 动态根字号
/* JS 按屏宽设 html 的 font-size：设计稿 375 时 1rem=37.5px */
function setRem(){
  var w = document.documentElement.clientWidth;
  document.documentElement.style.fontSize = (w/10) + 'px';
}
setRem();
window.addEventListener('resize', setRem);
/* 之后 CSS 里 1rem = 屏宽的 1/10，写 .title{font-size:.36rem} */
要点：vw 零依赖、所见即所得；rem 兼容更老设备，二者都能做等比缩放。

5. 触摸事件

手机没有鼠标，交互靠 Touch 事件（或现代 Pointer Events）：

var box = document.querySelector('.box');
box.addEventListener('touchstart', function(e){ /* 手指按下 */ });
box.addEventListener('touchmove',  function(e){ /* 手指滑动 */ e.preventDefault(); });
box.addEventListener('touchend',   function(e){ /* 手指抬起 */ });
// 滑动方向判断
var dx = e.changedTouches[0].clientX - startX;
if (dx > 40) swipeLeft();
  • touchmove 默认会滚动页面，需要阻止时用 e.preventDefault()（注意 passive 监听）。
  • 点击建议用 click 或 touchend，别用 hover（手机没悬停）。

6. 动画与交互

  • CSS 动画：transition 做过渡、@keyframes + animation 做循环/入场。
  • JS 动画：requestAnimationFrame 驱动逐帧，适合游戏/粒子。
  • 入场动效：监听滚动用 IntersectionObserver 触发“元素进入视口再播动画”，首屏更顺。
.fade-up { opacity:0; transform:translateY(20px); transition:.4s; }
.fade-up.in { opacity:1; transform:none; }

7. 微信与分享

H5 大多在微信里传播，想自定义“标题/缩略图/描述”要接微信 JS-SDK：

// 1. 后端用 access_token 算 signature，前端注入
wx.config({ appId, timestamp, nonceStr, signature, jsApiList:['updateAppMessageShareData'] });
// 2. 自定义分享卡片
wx.ready(function(){
  wx.updateAppMessageShareData({ title:'邀请你参加', desc:'…', link:location.href, imgUrl:'…' });
});
坑：签名必须用当前页面 URL（不含 # 后的部分）去算，否则 iOS 分享失效。

8. 常见 H5 组件

  • 轮播图：touch 横滑 + 自动播放 + 指示点。
  • 下拉刷新 / 上拉加载：监听 touchmove 到顶/到底触发。
  • 弹层 / Toast：轻提示与模态框，注意遮罩穿透滚动。
  • 九宫格抽奖 / 大转盘：CSS 旋转 + 随机角度，H5 活动常客。

9. 性能与首屏

  • 首屏直出：HTML 里直接写首屏内容，别等 JS 渲染。
  • 图片优化：用 webp、按屏宽取图、loading="lazy" 懒加载。
  • 体积：骨架屏 + 按需加载，首屏 JS 别超过 100KB 量级。
  • 真机测：安卓/iOS 各测一遍，低端机才暴露卡顿。

10. H5 vs 小程序 vs App

维度H5小程序App
入口链接/二维码微信内搜索应用商店
安装不用装不用装要装
能力受浏览器限制微信 API 多系统级最强
传播最易分享中等最难
选型：要“扫码即看、病毒传播”选 H5；要“更强能力+留存”选小程序；要“深度体验”才上 App。

11. 常见坑

坑 1 1px 边框：Retina 屏 1px 仍显粗，用 transform:scaleY(.5) 或 0.5px 处理。
坑 2 300ms 点击延迟：老浏览器点击有延迟，加 touch-action:manipulation 或 viewport 禁缩放即可消除。
坑 3 iOS 滚动回弹：局部滚动容器加 -webkit-overflow-scrolling:touch。
