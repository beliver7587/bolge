HTTPS / TLS：从小白到资深

HTTPS = HTTP + TLS。TLS 用证书证明“你访问的确实是这个域名”，并加密传输内容，保证机密性、完整性、身份认证。本教程讲透握手流程、证书体系、Let's Encrypt/ACME 自动续期、Nginx 配置、安全加固与证书治理——这是任何公网服务的上线底线。

1. 它解决什么问题

  • 窃听：明文 HTTP 在公共 WiFi/运营商链路上可被抓包；TLS 加密。
  • 篡改：中间人可注入广告/改内容；TLS 保证完整性。
  • 冒充：证书证明服务端身份，防钓鱼站点。
现实：浏览器对 HTTP 标“不安全”；微信/Apple 强制 HTTPS，否则扫码打不开、无法上架。

2. TLS 握手

  • 核心：客户端验证证书链（根→中间→站点），协商对称密钥（ECDHE 实现前向保密）。
  • 前向保密 FS：每次会话独立临时密钥，即便长期私钥日后泄露，历史流量也解不开。
  • SNI：客户端在握手早期声明域名，使一台 IP 能托管多张证书（虚拟主机）。

3. 证书类型

类型验证适用
DV域名所有权个人/普通站点（Let's Encrypt 即 DV）
OV/EV组织身份企业/金融（EV 已弱化）
通配符 *.example.com—多子域
SAN 多域名—一张证书覆盖多个域

4. Let's Encrypt 与 ACME

Let's Encrypt 提供免费 DV 证书，靠 ACME 协议自动签发/续期。Certbot 是常用客户端：

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d example.com -d www.example.com   # http-01 验证 + 自动改 Nginx
sudo certbot renew --dry-run                            # 测试续期
  • 验证方式：http-01（需 80 端口放验证文件）/ dns-01（需改 DNS 记录，适合通配符与无 80 端口场景）。
  • 自动续期：Certbot 装 systemd timer/cron，证书 90 天有效，到期前自动续；务必确认定时器在跑。

5. Nginx 配置

server {
  listen 443 ssl;
  server_name example.com;
  ssl_certificate     /etc/letsencrypt/live/example.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;
}
# 80 全跳 443
server { listen 80; server_name example.com; return 301 https://$host$request_uri; }

6. 证书管理

  • 监控告警：证书过期会导致全站不可信；用监控（或 certbot renew 状态）提前告警。
  • 多服务统一：可一处签发，再分发 fullchain.pem/privkey.pem 给其他服务（如 n8n、Memora）。
  • 权限：私钥文件只 root 可读（600），切勿进 git。

7. 安全加固

ssl_protocols TLSv1.2 TLSv1.3;
ssl_ciphers HIGH:!aNULL:!MD5;
ssl_prefer_server_ciphers off;       # TLS1.3 下由客户端优选
add_header Strict-Transport-Security "max-age=63072000" always;   # HSTS
ssl_stapling on;                     # OCSP stapling 加速校验
资深：用 Mozilla SSL Config Generator 生成基线，再以 SSL Labs 评分（目标 A+）迭代。

8. 常见坑

坑 1：域名 A 记录没解析到服务器，ACME 验证失败；先确认解析生效。
坑 2：防火墙未放行 443，HTTPS 打不开。
坑 3：证书过期没续，站点变“不安全”；确认 renew 定时器。
坑 4：混合内容：HTTPS 页引用 HTTP 资源，锁变灰；统一 https 或相对协议。
坑 5：WebSocket 须用 wss://，否则被 HTTPS 页拦截。
坑 6：私钥泄露 → 立即吊销并重签。

9. 调试与成长

  • 测试握手与评级：openssl s_client -connect example.com:443、SSL Labs 在线评测。
  • 查到期：echo | openssl s_client -servername example.com -connect example.com:443 2>/dev/null | openssl x509 -noout -dates。
阶段能力标志
小白能用 Certbot 申请并配 HTTPS
初级会自动续期、80 跳 443、多域名
中级HSTS、OCSP、证书监控告警
资深安全套件调优、评级 A+、密钥治理
练习：① Certbot 申请证书并配 Nginx ② 设 HSTS 与 OCSP stapling ③ 用 SSL Labs 跑分并修到 A+ ④ 确认 renew 定时器 ⑤ 把证书分发到第二个服务 ⑥ 用 openssl 查到期时间。
你已进阶：理解 TLS 握手与证书生命周期，能落地加密、自动续期与加固——这是资深后端保障公网通信安全的底线能力。
