CSS：从小白到布局专家

CSS 控制网页的外观与布局：颜色、间距、字体、定位、动画。本教程从盒模型讲到 Flex/Grid 与响应式，帮你建立“看见设计稿就能写出布局”的能力。

1. 它是什么

CSS（Cascading Style Sheets）用选择器选中 HTML 元素并施加样式，且样式可“层叠”合并。

一句话：HTML 给结构，CSS 给样子。层叠（Cascade）= 多条规则按优先级合并到同一元素。

2. 引入与优先级

  • 外部 <link>：最推荐，样式与结构分离。
  • 内部 <style>：单页快但难复用。
  • 内联 style=""：优先级最高但难维护。
优先级：内联 > ID > 类/属性 > 标签。重要但不滥用——多用类，少用 ID 与 !important。

3. 盒模型

每个元素是个盒子：content + padding + border + margin。

* { box-sizing: border-box; }  /* 推荐：width 含 padding+border */
.box { width: 100px; padding: 10px; border: 1px; }  /* 实际宽=100，非 122 */
务必：全局 border-box 是资深前端的标准起手式，算宽高不再头疼。

5. 布局总览

  • 普通流：块级换行、行内并排。
  • Flex：一维（行或列）对齐神器。
  • Grid：二维（行列）布局。
  • 定位：脱离文档流做叠加。

6. Flexbox

.row { display:flex; align-items:center; justify-content:space-between; gap:12px; }
/* 子项 .item { flex:1 } 等分剩余空间 */
  • justify-content：主轴对齐；align-items：交叉轴对齐。
  • flex-wrap：放不下换行。
一句话：想“一排东西怎么排”就用 Flex。

7. Grid

.grid { display:grid; grid-template-columns:repeat(3,1fr); gap:16px; }

1fr 表示“一份剩余空间”，repeat(3,1fr) 即三等分。Grid 适合卡片墙、仪表盘。

选型：二维用 Grid，一维用 Flex；二者常组合（Grid 套 Flex）。

8. 定位

值行为
relative相对原位，不脱离流
absolute相对最近定位祖先，脱离流
fixed相对视口，滚动不动
sticky滚动到阈值变 fixed

9. 响应式

@media (max-width: 768px) { .grid { grid-template-columns: 1fr; } }
  • 移动优先：先写小屏，再用 min-width 往上加。
  • 单位用 rem（相对根字号）、vw/vh（相对视口）。

10. 单位

单位相对
px绝对像素
rem根元素字号
em当前元素字号
vw/vh视口宽/高

11. 过渡与动画

.btn { transition: background .2s; }
.btn:hover { background: #5b8cff; }
@keyframes spin { to { transform: rotate(360deg); } }
.loader { animation: spin 1s linear infinite; }

transform（位移/旋转/缩放）走 GPU，性能好；别用 top/left 做动画。

12. 变量

:root { --brand: #5b8cff; }
.card { color: var(--brand); }

CSS 变量让主题一处改全局变，是 design token 的落地方式（见 Tailwind）。

13. 常见坑

坑 1 margin 塌陷：相邻块的上/下 margin 会合并；用 padding 或 flex 隔离。
坑 2 z-index 无效：只对定位元素生效，且受 stacking context 影响。
坑 3 高度塌陷：子元素 float 后父无高，用 overflow:hidden 或 flex。

14. 与 Tailwind

Tailwind 本质是“用工具类写这些 CSS”，底层还是盒模型/Flex/Grid。懂原生 CSS 才能看懂并调试 Tailwind 生成的样式。

15. 资源与路线

  1. MDN CSS 文档。
  2. 练：用 Flex 做导航栏、用 Grid 做卡片墙、写一套响应式。
  3. 进阶：BEM 命名、CSS 架构、与 React 的 CSS Modules。
资深标志：看到设计稿能立刻判断“Flex 还是 Grid”、预知塌陷/溢出风险，并用变量与架构让样式可维护。
