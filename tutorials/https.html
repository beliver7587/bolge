HTTPS / TLS

给网站加上加密传输 —— 让数据不被窃听、地址栏显示小锁。用免费的 Let's Encrypt 证书即可。学完你能把站点升级为 https。

1. 这是什么

HTTPS = HTTP + TLS 加密。TLS 用证书证明“你访问的确实是这个域名”，并加密传输内容。没有它，浏览器会标记“不安全”，且密码/接口明文可被劫持。

一句话：证书 = 网站的“身份证”，由可信机构签发；HTTPS = 给通信上锁。

2. 环境准备

  • 一个已解析到服务器 IP 的域名（A 记录）。
  • 已装 Nginx 且 80 端口可访问。

3. 申请证书

用 Certbot（Let's Encrypt 免费证书）：

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d example.com -d www.example.com

按提示输入邮箱、同意条款，Certbot 会自动申请证书并改写 Nginx 配置启用 HTTPS。

4. 配置 Nginx

Certbot 自动生成类似：

server {
  listen 443 ssl;
  server_name example.com;
  ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;
}
# 80 自动跳 443
server { listen 80; server_name example.com; return 301 https://$host$request_uri; }

5. 自动续期

证书 90 天有效，Certbot 装了定时任务自动续。手动测试：

sudo certbot renew --dry-run

6. 常见坑

坑 1：域名没正确解析到服务器，Certbot 验证失败；先确认 A 记录生效。
坑 2：防火墙没放行 443，https 访问不了。
坑 3：证书过期没续，网站变“不安全”；确认 certbot 定时器在跑。
坑 4：混合内容：https 页面里引用 http 资源，锁会变灰；资源统一用 https 或相对协议。
坑 5：WebSocket 用 wss://，否则被 https 页拦截。
