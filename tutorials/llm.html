大模型 LLM

大语言模型 —— 能理解并生成自然语言的 AI，是 Agent/RAG/客服的大脑。学完你能用 API 调通第一个 AI 对话。

1. 这是什么

LLM（Large Language Model） 是用海量文本训练出的模型，能续写、问答、总结、写代码。我们用它的 API 来“对话”。

一句话：你发一段“提示（prompt）”，它返回“补全/回答”。本质是预测下一个最合理的词。
供应商：OpenAI、Anthropic、Google，以及国产（通义/智谱/DeepSeek 等），见 供应商抽象。

2. 环境准备

装 SDK（以 OpenAI 兼容为例）并准备 API Key：

npm install openai
export OPENAI_API_KEY=sk-xxxx   # 在环境变量里，别硬编码进代码

3. 第一次调用

import OpenAI from 'openai';
const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });
const r = await client.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: '用一句话解释什么是数据库' }]
});
console.log(r.choices[0].message.content);

4. 消息与角色

角色作用
system系统指令（人设/规则），常放最前
user用户说的话
assistant模型的回复（多轮对话要回传）
messages = [
  { role:'system', content:'你是严谨的中文助手' },
  { role:'user', content:'你好' },
  { role:'assistant', content:'你好，有什么可以帮你？' },
  { role:'user', content:'继续…' }
];

5. 关键参数

  • temperature：0 更确定/保守，1 更发散/创意。
  • max_tokens：单次最多生成多少 token（≈字）。
  • top_p：核采样，控制多样性。
  • stop：遇到指定串停止。

6. 流式输出

const stream = await client.chat.completions.create({ model, messages, stream: true });
for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}
搭配：流式输出常配合 SSE 推到前端做打字机效果。

7. 常见坑

坑 1：把 API Key 写死在前端代码，泄露被盗刷；Key 只在服务端用，并走环境变量。
坑 2：多轮对话没回传历史，模型“失忆”；把完整 messages 传回去。
坑 3：上下文超长报 400；做截断或摘要（见 四层记忆）。
坑 4：temperature 太高回答乱；确定性任务设 0。
坑 5：不同供应商参数/模型名不同，直接搬运代码易错；用 供应商抽象 隔离。
