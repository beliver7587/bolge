Spring Boot：从小白到后端主力

Spring Boot 是 Java 后端一站式框架，靠“约定优于配置”让你几行注解就跑起生产级服务。本教程从自动配置讲到 Web/数据/安全/部署，带你把简历工坊这类项目真正落地。

1. 它解决什么问题

传统 Spring 要手写大量 XML、配 Tomcat、管依赖版本，搭个空项目都费劲。Spring Boot 用自动配置 + 起步依赖（starter）把这些样板收掉。

一句话：Spring Boot = Spring 全家桶 + 自动配置 + 内嵌服务器。开箱即跑，生产可用。
适合：企业级后端、需要强类型与稳定生态的服务。不适合：极轻量脚本（用 Node 更快）。

2. 工程化起步

1

用 start.spring.io 生成

选 Java 17 + Maven + 依赖（Web、JPA、MySQL、Security），下载即用。

2

最小应用

@SpringBootApplication
public class App { public static void main(String[] a){ SpringApplication.run(App.class,a);} }

一个注解 + 一个 main，内嵌 Tomcat 已就绪。

3. 核心注解

注解作用
@SpringBootApplication启动 + 组件扫描 + 自动配置
@RestController返回 JSON 的控制器
@RequestMapping路由映射
@Service / @Repository分层标记

4. 依赖注入

@Service
public class UserService {
  private final UserRepo repo;
  public UserService(UserRepo repo) { this.repo = repo; }  // 构造注入
}
  • 容器负责创建与装配对象（IoC/DI），组件加 @Component 系列注解即被管理。
  • 优先构造注入，便于测试与不可变。

5. Web 层

@RestController
@RequestMapping("/api/users")
public class UserController {
  @GetMapping("/{id}") public User get(@PathVariable Long id) { ... }
  @PostMapping public User create(@RequestBody User u) { ... }
}
坑：@RequestBody 需要 Jackson 序列化；字段名不符要加 @JsonProperty。

6. 数据层

用 Spring Data JPA 或 MyBatis-Plus：

public interface UserRepo extends JpaRepository<User, Long> {
  List<User> findByEmail(String email);
}

继承接口即得 CRUD，无需写实现。关系库见 MySQL。

7. 配置管理

# application.yml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/db
    username: ${DB_USER}   # 环境变量注入
  • 多环境：application-dev.yml / -prod.yml，用 spring.profiles.active 切换。
  • 敏感配置走环境变量/配置中心，别硬编码。

8. 安全

Spring Security 做认证/授权：

  • 密码用 BCryptPasswordEncoder 哈希。
  • 路由加 SecurityFilterChain 规则（哪些要登录）。
  • JWT 见 JWT，配合 OncePerRequestFilter 校验。

9. 异常处理

@RestControllerAdvice
public class GlobalEx {
  @ExceptionHandler(NotFound.class)
  public ResponseEntity<?> handle(NotFound e) { return status(404).body(e.msg); }
}

全局统一错误结构，前端（如 React）好处理。

10. 测试

@SpringBootTest
class UserTest {
  @Autowired UserRepo repo;
  @Test void save() { assertTrue(repo.save(new User()).getId() > 0); }
}
  • @WebMvcTest 测 Controller；@DataJpaTest 测数据层（用内存库）。
  • 测试是资深交付的标配。

11. 部署

  • mvn package 打出可执行 jar（内嵌服务器）。
  • 用 Docker 镜像 + PM2/systemd 守护，前接 Nginx 反代。

12. 常见坑

坑 1 循环依赖：两个 Bean 互相注入会启动失败；重构拆分或改用 @Lazy。
坑 2 N+1 查询：JPA 懒加载触发大量 SQL；用 @EntityGraph 或 DTO 投影。
坑 3 版本冲突：起步依赖已管版本，别手动乱引导致冲突。
