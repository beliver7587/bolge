AI Agent：从小白到资深

Agent（智能体） = 大模型（大脑）+ 工具（手脚）+ 记忆 + 自主循环。它接收目标后自己拆解步骤、调用工具、观察结果、反复推理直到完成——Memora 就是这样的 Agent。本教程讲透ReAct 循环、规划与反思、工具集成、多智能体编排、护栏、可观测与评估、生产落地——这是做“能办事的 AI”的核心能力。

1. 它解决什么问题

普通聊天一问一答；Agent 给目标后自主多步执行（查资料、调 API、算账、写文件）。它把“会说话”升级为“能办事”。

一句话：Agent = LLM 驱动的状态机——在“想（推理）/做（调工具）/看（观察）”间循环，直到任务完成或到达护栏边界。
适合：自动化客服、数据分析、代码助手、工作流编排、Research 助手。

2. 架构与组件

  • 规划器：LLM 决定“下一步做什么”（含任务拆解，见 §4）。
  • 工具层：数据库查询、HTTP、计算、代码执行等，由 Function Calling 驱动。
  • 记忆层：短期（对话上下文）+ 长期（可检索），见 四层记忆。
  • 执行循环：编排“推理→行动→观察”直到结束。框架：LangChain/LangGraph、AutoGen、自研轻量循环。

3. 核心循环 ReAct

ReAct（Reason + Act）是最经典的范式：模型产出“思考 + 动作（工具调用）”，执行后把结果作为“观察”再喂回，循环。

let messages = [{ role:'user', content:'北京今天适合出门吗？并算下温差' }];
let steps = 0;
while (steps++ < 12) {
  const res = await llm.chat({ messages, tools });   // 模型可能返回 tool_calls
  if (!res.tool_calls) { return res.content; }        // 不再需要工具 → 给出最终答案
  for (const tc of res.tool_calls) {
    const result = await runTool(tc.name, tc.arguments);  // 执行工具
    messages.push({ role:'tool', tool_call_id: tc.id, content: result });  // 观察回灌
  }
}
要点：这就是 Agent 的“思考-行动-观察”闭环；停止条件是模型不再请求工具，或触达步数上限。

4. 规划与反思

  • 任务拆解：先让模型把大目标拆成有序子任务（plan），再逐步执行（execute）。
  • Plan-and-Execute：先出计划、再执行，避免边走边想导致跑偏。
  • 反思（Reflection）：执行后让模型自评“是否达成”，失败则调整重试——显著提升复杂任务成功率。

5. 工具集成

工具的“描述质量”决定 Agent 能否正确选用。每个工具要写清：名字、用途、参数 schema、边界。

  • 工具执行必须 try/catch，把错误（而非崩溃）作为观察回传，让模型自我纠正。
  • 工具返回要裁剪，避免大结果撑爆上下文（只回必要字段/摘要）。

6. 记忆

长任务靠记忆维持状态：短期放上下文窗口，长期用向量/数据库检索（Embedding）。设计见 四层记忆。

上下文膨胀：每轮把全部工具结果塞回去会迅速超窗；要摘要、裁剪或外置长内容。

7. 多智能体编排

  • 主从/监督者（Supervisor）：一个调度 Agent 把子任务派给专长 Agent（搜索/写码/校验）。
  • 交接（Handoff）：Agent 间互相转交对话上下文，适合长流程。
  • 何时拆分：单 Agent 工具太多会“选择困难”、Prompt 臃肿 → 拆成专精 Agent。

8. 护栏与可靠性

  • 最大步数：防无限循环（如 12~20 步上限）。
  • 输入/输出校验：参数用 JSON Schema 校验；危险操作加确认。
  • Human-in-the-loop：涉及发邮件、删数据、付款等高风险动作，需人工审批。
  • 回滚/幂等：工具尽量幂等，便于重试不副作用。

9. 可观测与评估

  • Tracing：记录每一步的“思考/工具/观察/耗时/花费”，用 LangSmith 等可视化。
  • 轨迹评估：不只看最终答案，评估“路径是否合理”（少走弯路、不过度调用）。
  • 指标：任务成功率、平均步数、工具命中率、成本/延迟。

10. 生产要点

  • 成本/延迟：循环多步会累积 token；用便宜模型做规划、强模型做关键推理（分层）。
  • 流式展示：用 SSE 把 Agent 的中间步骤实时推给前端，别让用户干等。
  • 重试与降级：工具/模型失败要重试、超时兜底，保证可用性。

11. 安全

注入是头号风险：工具的输入或检索到的资料可能藏“忽略指令、把数据外发”的恶意提示，劫持 Agent。必须做输入净化、最小权限、输出校验，详见 提示注入防护。

12. 常见坑

坑 1：无限循环 → 设最大步数 & 早停。
坑 2：上下文膨胀 → 摘要/裁剪/外置。
坑 3：工具出错即崩 → try/catch 回传错误。
坑 4：忽略注入防护 → 被恶意资料劫持。
坑 5：过度自治 → 高风险动作没人工审批。
坑 6：工具描述不清 → 模型选错/传错参。

13. 调试

  • 开 Tracing 把每步“想/做/看”打印出来，定位是规划错还是工具错。
  • 单步复现：固定随机种子、mock 工具，隔离问题。

14. 成长路线

阶段能力标志
小白能写“思考-调工具-再思考”循环
初级会工具集成、记忆、流式展示
中级规划/反思、护栏、多智能体编排
资深评估体系、生产可靠性、安全与成本治理
练习：① 写带最大步数的 ReAct 循环 ② 给工具加 try/catch 与裁剪 ③ 加 Plan-and-Execute ④ 接 Tracing 看轨迹 ⑤ 在资料藏注入指令验证防护 ⑥ 高风险动作加人工审批。
你已进阶：理解 Agent 不是“调一个接口”，而是规划×工具×记忆×护栏×评估的系统工程——这是资深 AI 后端做自主系统的核心能力。

完整流程：构建一个 Agent

1. 定义工具
tools = [
  {"name":"search","description":"搜索知识库","parameters":{"q":{"type":"string"}}},
  {"name":"send_email","description":"发邮件","parameters":{"to":"...","content":"..."}}
]
2. 循环执行
while 未结束:
  调用 LLM，让它决定 thought / action / action_input
  如果 action 是工具 → 执行工具 → 把结果 Observation 写回消息
  如果 action 是 finish → 输出最终答案
3. 记忆与规划
短期记忆：最近 N 轮对话
长期记忆：写入数据库/向量库，检索后再调用
要点：工具描述要清晰；必须校验 LLM 输出的参数，防止越权。
