大模型 LLM

“超级自动补全” —— 读懂语言规律生成文本，是一切 AI 能力的起点。

1. 这是什么

大语言模型（LLM）本质上是一个“超级自动补全”：给它前半句，它根据海量文本训练出的统计规律，预测“下一个最可能出现的字/词”，一个一个往外吐，连成回答。它不是搜索引擎（不会现查），而是“凭记忆生成”——所以会记错、会编造。

2. Token 与计费

模型不吃原始汉字，而是先切成 token（中文通常 1~2 字一个 token）。成本 = 输入 token + 输出 token。一次对话成本随上下文增长——这正是要做“精准检索只取 5 段”（RAG）的原因。

// 调用（以 OpenAI 风格为例）
const res = await client.chat.completions.create({
  model:'gpt-4o-mini',
  messages:[{role:'user', content:'你好'}]
});

4. 幻觉与截止

  • 幻觉：一本正经编错误内容（本质是“猜下一个字”）。
  • 知识截止：只知训练时见过的，新事/公司内部规定一概不知。
解法：用 RAG 外挂知识库现查现用，而非微调。

5. 常见坑

坑 1：把密钥写死在前端代码——必须走后端 + 环境变量（见 供应商抽象）。
坑 2：上下文过长烧钱且变傻——做摘要/检索截断。
坑 3：轻信输出当事实——关键场景要核实与引用。
