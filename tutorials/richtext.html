富文本与 PDF

在网页里编辑带格式的文字（加粗/标题/列表），并把内容导出成 PDF —— 简历工坊的核心能力。学完你能做一个“在线编辑 + 一键导出 PDF”。

1. 这是什么

两块能力：

  • 富文本编辑：让用户在网页里像用 Word 一样排版，底层是 contentEditable 或成熟编辑器（TipTap / Quill / Slate）。
  • 导出 PDF：把网页内容渲染成 PDF，用于打印/下载/分享。
应用场景：简历制作、合同编辑、报表导出、在线文档。

2. 富文本编辑器

推荐 TipTap（基于 ProseMirror，React 友好）：

npm install @tiptap/react @tiptap/starter-kit
import { useEditor, EditorContent } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';

const editor = useEditor({ extensions: [StarterKit], content: '<p>写点什么…</p>' });
return <EditorContent editor={editor} />;
轻量替代：不想引库可用原生 contentEditable + document.execCommand（已废弃但还能用），或 Quill。

3. 导出为 HTML/JSON

editor.getHTML();     // '<h1>标题</h1><p>正文</p>'
editor.getJSON();     // 结构化数据，便于存库

4. 生成 PDF

浏览器端最简单：用 html2pdf.js（基于 jsPDF + html2canvas）：

npm install html2pdf.js
import html2pdf from 'html2pdf.js';
html2pdf().from(element).save('简历.pdf');

更可控的服务端方案：用 Playwright/Puppeteer 无头浏览器把页面打印成 PDF；或用 pdf-lib 直接拼装 PDF。

5. 实战：简历导出

// 拿到编辑区 DOM，导出为 PDF
function exportPDF() {
  const el = document.getElementById('resume');
  html2pdf().set({
    margin: 10,
    filename: '我的简历.pdf',
    html2canvas: { scale: 2 },     // 清晰度
    jsPDF: { unit: 'mm', format: 'a4' }
  }).from(el).save();
}
流程：用户在编辑器排版 → getHTML 存数据库 → 展示页渲染 → 点“导出”用 html2pdf 截取该区域生成 PDF。

6. 常见坑

坑 1：html2pdf 截的是“当前屏幕渲染”，分页处内容被截断——用 CSS 控制 page-break-inside: avoid。
坑 2：字体未在 PDF 中嵌入，导出后字体不对；html2canvas 依赖页面已有字体。
坑 3：图片跨域导致截图失败；图片需同源或允许 CORS。
坑 4：TipTap 内容含 XSS 风险，渲染用户 HTML 时要做消毒（sanitize）。
坑 5：服务端 PDF（Puppeteer）需要服务器环境，纯静态站点做不到，要配 Node.js 后端。
