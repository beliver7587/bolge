MyBatis-Plus

MyBatis 的增强工具 —— 简历工坊数据层用它，单表 CRUD 几乎零 SQL。

1. 这是什么

MyBatis 是 Java 里把 SQL 和代码解耦的持久层框架；MyBatis-Plus（MP） 在它之上加了“通用 CRUD”——你不用为每张表写增删改查的 SQL，MP 自动生成。对单表操作，开发效率极高。

2. 为什么用它

对比：原生 JDBC 要手写大量样板；MP 只要实体类 + 一个接口，selectById、insert、update 全白送，复杂查询再手写 SQL。

3. 定义实体与 Mapper

@TableName("resume")
public class Resume {
  @TableId(type = IdType.AUTO)
  private Long id;
  private String title;
  private Long userId;
  // getter / setter 省略
}

public interface ResumeMapper extends BaseMapper<Resume> {
  // 什么都不用写，已继承 select/insert/update/delete
}

4. 常用 CRUD

// 注入 mapper 后直接使用
Resume r = mapper.selectById(1L);          // 按主键查
mapper.insert(r);                           // 插
mapper.updateById(r);                        // 改
mapper.deleteById(1L);                       // 删

// 条件构造器（不用写 SQL）
mapper.selectList(new QueryWrapper<Resume>()
  .eq("user_id", 10).like("title", "前端"));

5. 常见坑

坑 1：实体类名/字段名和表对不上要用 @TableName / @TableField 显式指定。
坑 2：QueryWrapper 拼条件易 SQL 注入风险——用 .eq() 等安全方法而非 last("...") 拼字符串。
坑 3：逻辑删除、乐观锁等要加注解才生效，别以为默认开启。
