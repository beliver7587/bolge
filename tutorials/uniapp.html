uni-app

用 Vue 语法一套代码发到 H5 / 微信小程序 / App —— 跨端开发首选。学完你能一次开发多端上线。

1. 这是什么

uni-app 是 DCloud 出的跨端框架：写一套基于 Vue 的代码，可编译到微信/支付宝小程序、H5、安卓/iOS App、甚至快应用。

对比：原生小程序要学各自语法；uni-app 统一用 Vue，省去多端重复开发。
适合：创业 MVP、企业内部工具、想一套代码覆盖多端的产品。

2. 环境准备

装 HBuilderX（官方 IDE，开箱即用）或 CLI：

npm install -g @vue/cli
vue create -p dcloudio/uni-preset-vue my-uniapp

3. 第一个页面

<template>
  <view class="content">{{ title }}</view>
</template>
<script>
export default {
  data() { return { title: '你好 uni-app' }; }
}
</script>
<style>
.content { padding: 20rpx; }
</style>
要点：uni-app 用 view 代替 div，单位用 rpx（自适应屏幕宽度）。

4. 生命周期

页面有 onLoad（加载）、onShow（显示）、onPullDownRefresh（下拉刷新）等，比 Web 多了端能力钩子。

5. 条件编译

不同端写不同代码：

// #ifdef MP-WEIXIN
console.log('只在微信小程序生效');
// #endif

6. 打包发布

HBuilderX 里：发行 → 小程序（上传代码到各平台后台）/ 发行 → 网站（H5）/ 发行 → App 云打包（生成安装包）。

7. 常见坑

坑 1：把 Web 的 div/window 直接搬来，小程序不认；用 view 与 uni API。
坑 2：小程序不支持 DOM/BOM（如 document）；别用浏览器专属 API。
坑 3：rpx 与 px 混用导致尺寸偏差；统一用 rpx。
坑 4：跨端插件平台兼容性差异，发布前各端真机测试。
