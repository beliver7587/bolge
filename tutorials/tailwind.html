Tailwind CSS

原子化 CSS 框架 —— Memora 前端用它快速搭出整齐的界面。

1. 这是什么

Tailwind 是原子化的 CSS 框架：它不给你现成“卡片组件”，而是给你一堆极小的工具类（如 flex、p-4、text-center），你直接在 HTML 的 class 里拼出样式。不用再写单独的 .css 文件。

2. 原子化思想

对比：传统写法先起名 .card 再写样式；Tailwind 直接 class="rounded-lg p-4 bg-white shadow"，所见即所得，且全局不会起名冲突。

3. 第一个例子

<button class="px-4 py-2 rounded-lg bg-blue-600 text-white
                hover:bg-blue-700 font-semibold">
  点击
</button>

拆开看：px-4 左右内边距、py-2 上下、rounded-lg 圆角、bg-blue-600 蓝底、hover:bg-blue-700 悬停变色。

4. 响应式

加前缀即可按屏幕宽度生效：md:（≥768px）、lg:（≥1024px）。

<div class="grid grid-cols-1 md:grid-cols-3 gap-4">
  <!-- 手机一列，电脑三列 -->
</div>

5. 常见坑

坑 1：HTML 里 class 一长串看着乱——习惯后其实是“样式就近”，改起来更快。
坑 2：忘记配置 content 扫描路径，会导致样式没生成（Tailwind v3 必配）。
坑 3：重复样式多时，可用 @apply 或抽成组件类收敛。
