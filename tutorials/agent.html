AI Agent

会“自己想办法”的 AI —— 能调用工具、查资料、多步推理去完成任务，而不只是聊一句。Memora 就是这样一个 Agent。学完你能搭一个能办事的 AI。

1. 这是什么

Agent（智能体） = 大模型（大脑）+ 工具（手脚）+ 循环（思考→行动→观察）。它不再一次性回答，而是“先想清楚要做什么，再一步步做，直到完成”。

对比：普通聊天：你问一句，它答一句；Agent：你给目标，它自己拆步骤、调工具、最后交结果。
适合：自动客服、数据分析、代码助手、工作流自动化。

2. 三大件

  • 规划/推理：LLM 决定下一步做什么（用 LLM）。
  • 工具（Tools）：查数据库、调 API、算数、发邮件等能力，见 Function Calling。
  • 记忆（Memory）：记住上下文与历史，见 四层记忆。

3. 运行循环

用户目标 │ ▼ [LLM 思考：要做什么] → 若需要工具 → 调用 Tool → 得到结果 → 再思考 │ ↑________│ ▼ [任务完成] → 返回最终答案

4. 工具调用

把工具描述给模型，模型返回“要调哪个函数、参数是什么”，你执行后再把结果喂回模型：

tools = [{
  name: 'getWeather',
  description: '查询某城市天气',
  parameters: { type:'object', properties:{ city:{type:'string'} } }
}];
// 模型返回 tool_calls → 你执行 getWeather('北京') → 把结果作为 tool 消息回传

5. 实战示例

let messages = [{ role:'user', content:'北京今天适合出门吗？' }];
while (true) {
  const res = await llm.chat({ messages, tools });
  const toolCalls = res.tool_calls;
  if (!toolCalls) { console.log(res.content); break; }   // 不再需要工具，结束
  for (const tc of toolCalls) {
    const result = await runTool(tc.name, tc.arguments);
    messages.push({ role:'tool', tool_call_id: tc.id, content: result });
  }
}
要点：这就是 Agent 的“思考-行动-观察”循环，直到模型不再请求工具。

6. 常见坑

坑 1：无限循环：模型反复调工具停不下来；设最大步数上限（如 10 步）。
坑 2：工具返回过大撑爆上下文；只回传必要字段。
坑 3：工具出错没兜底，Agent 崩溃；对工具调用做 try/catch 并回传错误。
坑 4：忽略 提示注入防护，工具/资料里的恶意指令可能操纵 Agent。
坑 5：没有 记忆 约束，长对话丢失关键信息或越界。
