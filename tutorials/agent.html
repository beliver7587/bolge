Agent 智能体

会“思考→行动→观察”的 AI —— 自主调用工具完成多步任务。

1. 这是什么

普通聊天是“一问一答”；Agent（智能体）是给大模型配上“手脚”（工具）和“循环”：它能自己规划、连续调用多个工具、根据中间结果调整策略，直到把任务做完。比如“帮我查订单并建工单”这种多步活，Agent 能一气呵成。

2. 思考循环

想：用户要啥？该调哪个工具？ → 做：执行工具（查知识/查订单/建工单） → 看：拿到工具返回 → 再想：够了吗？不够继续调 → 收口：生成最终回答

3. 与工具配合

Agent 通过 Function Calling 决定调哪个工具、传什么参数。Memora 把这条链路做成“8 个节点”的可视化编排：意图路由→记忆→知识→工具→生成。

4. 防止死循环

关键：必须设“迭代上限”（如最多 5 轮）。到上限强制收回工具让模型收口，否则可能无限调用掏空 token。
for(let i=0; i<maxIter; i++){
  const decision = await callLLMWithTools();
  if(!decision.tool_calls?.length){ answer=decision.content; break; }
  // 执行工具、把结果回传模型，进入下一轮
}

5. 常见坑

坑 1：没设迭代上限 → 死循环烧钱。
坑 2：工具报错直接整条链崩——要把异常转成结构化错误回传模型，让它自我纠正。
坑 3：工具太多模型选错——用意图路由先收窄范围（见 Memora 手册）。
