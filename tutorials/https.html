HTTPS / certbot

免费申请并自动续期 HTTPS 证书 —— 微信/苹果强制要求。

1. 这是什么

HTTPS 是加密版的 HTTP：数据在传输中被加密，防窃听/篡改。certbot 是 Let's Encrypt（免费证书机构）的官方工具，能自动申请证书并改写 Nginx 配置，新手几乎零配置。

2. 为什么必须

硬性要求：微信、苹果等平台强制要求 HTTPS，否则扫码/打开直接失败；而且不加 HTTPS 数据明文，易被劫持。

3. 申请证书

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名        # 自动：验证域名→签发→改 Nginx→80 跳 443
sudo certbot --nginx -d 你的域名 -d www.你的域名
前提：域名已 A 记录指向服务器 IP，且 Nginx 已配置好该 server_name。

4. 自动续期

证书 90 天有效，certbot 安装时会写入系统的定时任务（certbot renew）自动续。可手动验证：

sudo certbot renew --dry-run    # 模拟续期，不真改

5. 常见坑

坑 1：上 HTTPS 后，登录 Cookie 要设 Secure 标志（COOKIE_SECURE=1），否则浏览器拒收、登录失效。
坑 2：证书过期没续→网站红字警告，务必确认 renew 定时任务在跑。
坑 3：用了 CDN/Cloudflare，证书要在它们那里也配好，否则链路不全加密。
