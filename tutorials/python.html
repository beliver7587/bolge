Python：从小白到 AI 第一语言

Python 语法简洁、生态极广，是 AI/数据/自动化的首选，初学者最友好。本教程讲清它的动态类型、核心数据结构、虚拟环境与 AI 生态——让你能写脚本也能上手机器学习。

1. 它是什么

Python 是动态强类型、缩进驱动语法的解释型语言。它慢于编译型，但开发效率极高，且拥有 numpy/pandas/PyTorch 等顶级库。

一句话：Python = 简洁语法 + 海量库 + AI 第一语言。写起来快，跑起来够用。

2. 工程化起步

python -m venv .venv      # 建虚拟环境
source .venv/bin/activate  # 激活（Windows: .venv\Scripts\activate）
pip install requests
python main.py
务必：每个项目用虚拟环境隔离依赖，别装到全局。

3. 基础语法

x = 10              # 动态类型，不用声明
name = "王越"
if x > 5:            # 靠缩进分块，无大括号
    print(name)
for i in range(3):
    print(i)

4. 数据结构

类型特点
list有序可变 [1,2]
tuple有序不可变 (1,2)
dict键值 {'a':1}
set不重复集合
推导式：[i*2 for i in range(5)] 一行生成列表，Python 的招牌语法糖。

5. 函数

def add(a, b=0): return a + b
square = lambda x: x*x     # 匿名函数
# 解包
def f(*args, **kwargs): ...

6. 面向对象

class Dog:
    def __init__(self, name): self.name = name
    def bark(self): print(self.name)

动态语言里类也是对象，可用元类做高级定制（少用）。

7. 模块与包

  • import 引入模块； from x import y 引入成员。
  • 包是带 __init__.py 的目录，组织大型项目。

8. 文件与 IO

with open('a.txt', 'r', encoding='utf-8') as f:
    for line in f: print(line)

with 自动关文件，避免泄漏。

9. 虚拟环境

venv / conda 隔离依赖；requirements.txt 记录版本，pip freeze > req.txt 导出。

10. 与 AI / 数据

  • 数据：pandas（表）、numpy（矩阵）。
  • AI：PyTorch / TensorFlow 训练模型；openai SDK 调大模型（见 LLM）。
  • 脚本/自动化：爬虫、批处理、运维脚本一把好手。

11. 常见坑

坑 1 可变默认参数：def f(x=[]) 默认值在函数定义时建一次，多次调用共享——用 x=None + 判断。
坑 2 浅拷贝：copy.copy 只拷贝一层，嵌套用 copy.deepcopy。
坑 3 全局解释器锁：CPython 的 GIL 让多线程难并行 CPU 任务；用多进程或异步。

12. 资源与路线

  1. 官方 Python 文档、廖雪峰教程。
  2. 练：用 pandas 读 CSV + 用 requests 写爬虫。
  3. 进 AI：学 numpy/PyTorch，再接 大模型 API。
资深标志：用虚拟环境 + 类型注解（mypy）补强 Python 的“弱类型”，理解 GIL 与深浅拷贝，并把脚本工程化。
