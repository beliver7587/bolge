Ant Design

国内最流行的 React UI 组件库（蚂蚁出品）—— 按钮、表单、表格、弹窗开箱即用，后台管理系统首选。学完你能一天搭出一个专业后台。

1. 这是什么

Ant Design（antd） 是一套高质量 React 组件库，提供几十个常用组件，统一了设计风格（间距、配色、交互）。

一句话：不用自己写按钮/表格/弹窗的样式和交互，import 一个组件就能用，长得很专业。
适合：中后台、管理面板、数据录入系统。
不太适合：追求独特视觉的品牌官网（可用但偏“通用风”）。

2. 环境准备

已有 React（建议 Vite 或 Next.js）项目。antd v5 不再需要单独引入 CSS。

3. 安装与引入

npm install antd

组件按需引入即用：

import { Button, ConfigProvider } from 'antd';

function App() {
  return <Button type="primary">主按钮</Button>;
}

5. 表单实战

import { Form, Input, Button, message } from 'antd';

function LoginForm() {
  const [form] = Form.useForm();
  const onFinish = (values) => {
    message.success('提交：' + JSON.stringify(values));
  };
  return (
    <Form form={form} onFinish={onFinish}>
      <Form.Item name="user" label="用户名" rules={[{ required: true }]}>
        <Input />
      </Form.Item>
      <Form.Item>
        <Button type="primary" htmlType="submit">登录</Button>
      </Form.Item>
    </Form>
  );
}
爽点：rules 内置校验（必填/邮箱/正则），onFinish 直接拿到整理好的数据对象。

6. 主题定制

用 ConfigProvider 改主色等：

import { ConfigProvider, theme } from 'antd';
<ConfigProvider theme={{ token: { colorPrimary: '#39e0d0' } }}>
  <App />
</ConfigProvider>

7. 常见坑

坑 1：antd v5 在 React 18 StrictMode 下可能报警告，属正常，不影响使用。
坑 2：表单拿不到值：忘了用 Form.useForm() 关联 Form form={form}。
坑 3：Next.js 里要用 @ant-design/nextjs-registry 做 SSR 样式注入，否则首屏样式闪。
坑 4：表格 rowKey 没设会报警告；用唯一字段如 rowKey="id"。
坑 5：自定义样式被 antd 覆盖：用更高优先级选择器或 :where 权重调整。
