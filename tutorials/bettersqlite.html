better-sqlite3

Node.js 上最快、最简单的嵌入式 SQLite 库 —— 同步 API、零配置、单文件数据库。做小工具/原型/本地存储首选。学完你能零运维地持久化数据。

1. 这是什么

better-sqlite3 是对 SQLite 的 Node 封装，最大特点是同步 API：调用直接拿到结果，不用 await，代码直观。

对比：MySQL 要起服务、配账号；SQLite 是个文件，开箱即用。适合单机/小流量。
适合：桌面应用、CLI 工具、个人项目、Demo、边缘/Serverless 本地存储。

2. 环境准备

需本地有编译环境（Windows 装 windows-build-tools 或已装 VS Build Tools）。通常直接：

npm install better-sqlite3
提示：它是原生模块，安装时会编译；CI 上用预编译包或 @electron-forge 等现成二进制。

3. 打开数据库

import Database from 'better-sqlite3';
const db = new Database('app.db');     // 文件不存在会自动创建
// 生产建议开启 WAL 提升并发
db.pragma('journal_mode = WAL');

4. 建表

db.exec(`
  CREATE TABLE IF NOT EXISTS user (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    age INTEGER
  )
`);

5. 增删改查

db.prepare('INSERT INTO user(name, age) VALUES (?, ?)').run('小王', 18);
const all = db.prepare('SELECT * FROM user').all();
const one = db.prepare('SELECT * FROM user WHERE id = ?').get(1);
db.prepare('UPDATE user SET age = ? WHERE id = ?').run(19, 1);
db.prepare('DELETE FROM user WHERE id = ?').run(1);

6. 预编译语句

用 prepare 预编译一次、多次执行，既快又防注入：

const insert = db.prepare('INSERT INTO user(name) VALUES (?)');
const insertMany = db.transaction((names) => {
  for (const n of names) insert.run(n);   // 事务批量，原子且快
});
insertMany(['a', 'b', 'c']);

7. 常见坑

坑 1：它是同步的，高并发写会阻塞事件循环；大流量请用 MySQL/Redis 或限制写入。
坑 2：字符串拼接 SQL 导致注入；务必用 ? 占位参数。
坑 3：多进程同时写同一文件会锁；用 WAL 模式缓解，或单写者。
坑 4：路径用相对路径时，工作目录不同会导致生成多个 db 文件；用绝对路径。
坑 5：原生模块在部署时若平台不同需重新编译（如本地 Mac 部署到 Linux）。
