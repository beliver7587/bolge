SSH：从小白到服务器登录

SSH 是安全的远程登录协议，让你在本地操控远程服务器、传文件。部署 Docker、调 Nginx、看日志都靠它。本教程讲清密钥登录与加固——这是上云的第一步。

1. 它是什么

SSH 在客户端与服务器间建立加密通道，替代不安全的 telnet/明文密码。

一句话：SSH = 加密的远程终端。登录、执行命令、传文件都走它。

2. 起步

ssh user@1.2.3.4
ssh -p 2222 user@host      # 非默认端口

3. 密钥登录

ssh-keygen -t ed25519        # 生成密钥对
ssh-copy-id user@host         # 把公钥传服务器
务必：用密钥替代密码登录，既安全又免输密码。私钥本地保管，别泄露。

4. 传文件

scp file.txt user@host:/path/
scp -r ./dist user@host:/var/www/

目录传用 -r；大文件可用 rsync 增量。

5. 隧道

ssh -L 8080:localhost:3000 user@host   # 本地 8080 转发到远端 3000

把远端服务映射到本地调试，不必对外暴露端口。

6. 安全加固

  • 禁用密码登录、只用密钥（PasswordAuthentication no）。
  • 改默认 22 端口，降低被扫。
  • 用 systemd 管 sshd，配合 fail2ban 防爆破。

7. 常见坑

坑 1 权限过开：~/.ssh 权限不对会导致密钥失效，目录 700、文件 600。
坑 2 改端口后忘开防火墙：登录被拒，需先在云控制台放行。
坑 3 known_hosts 冲突：服务器重装后指纹变了，删对应行再连。

8. 资源与路线

  1. OpenSSH 文档、各云厂商入门指南。
  2. 配合 systemd、Nginx、Docker 部署。
  3. 练：生成密钥、禁用密码登录、用 scp 部署一个静态站。
资深标志：用密钥 + 改端口 + 防爆破把 SSH 锁死，并熟练用隧道/rsync 做安全高效的运维。
