Express

最经典的 Node.js Web 框架 —— Memora 用 Express 写 REST 接口与 SSE 流式。

1. 这是什么

Express 是 Node 上最流行的轻量 Web 框架，帮你处理路由（URL→处理函数）、请求解析、中间件。它极简、自由，几乎所有 Node 后端课都从它讲起。

2. 第一个 API

import express from 'express';
const app = express();
app.use(express.json());              // 解析 JSON 请求体

app.get('/api/hi', (req, res) => {
  res.json({ msg: '你好' });          // 返回 JSON
});
app.post('/api/echo', (req, res) => {
  res.json({ youSent: req.body });    // 收前端发来的数据
});

app.listen(3010, () => console.log('listening'));

3. 中间件

中间件是“请求到达路由前/后的一段处理逻辑”，像流水线：

app.use((req, res, next) => {          // 每个请求都先过这里
  console.log(req.method, req.url);
  next();                              // 放行给下一个
});
常用中间件：cors（跨域）、express.json()（解析体）、morgan（日志）。鉴权也可用中间件统一拦截。

4. 与前端联调

前端跑在 5173、后端在 3010，不同端口算“跨域”，要么前端配代理、要么后端加 cors。上线后由 Nginx 把两者统一到同一域名。

5. 常见坑

坑 1：忘记 express.json()，req.body 是 undefined。
坑 2：异步错误没捕获会直接让进程崩——用 try/catch 或全局错误处理中间件。
坑 3：路径参数 /user/:id 与静态文件冲突，注意顺序。
进阶：流式输出用 SSE，鉴权用 JWT。
