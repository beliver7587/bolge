Docker

容器化技术 —— 把应用连同依赖打包成“容器”，一次构建到处运行，告别“我机器上能跑”。学完你能容器化部署自己的服务。

1. 这是什么

Docker 用容器把应用和它所需的环境（系统库、运行时）一起封装。相比虚拟机更轻量：共享宿主内核，秒级启动。

对比：虚拟机带整套操作系统（GB 级、启动慢）；容器只隔离进程（MB 级、秒起）。
核心：镜像（模板，像类）与 容器（运行实例，像对象）。

2. 环境准备

装 Docker Desktop（Win/Mac）或 Linux 上装 docker 引擎。验证：

docker -v
docker run hello-world

3. 镜像与容器

概念说明
镜像 Image只读模板，由 Dockerfile 构建
容器 Container镜像的运行实例，可启停删
仓库 Registry存镜像的地方（Docker Hub）

4. 第一个容器

docker pull nginx
docker run -d -p 8080:80 --name mynginx nginx
# 浏览器访问 http://localhost:8080

5. Dockerfile

给 Node 服务写一份（存为 Dockerfile）：

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]

构建运行：docker build -t myapp . && docker run -p 3000:3000 myapp

6. 编排与发布

多容器用 docker-compose.yml 一键拉起（如 应用+数据库）。部署到服务器时，把镜像推到仓库再 pull 运行。

7. 常见坑

坑 1：容器里数据不持久化，删容器数据没了；用 -v 挂载卷。
坑 2：端口没映射（没 -p），外部访问不了。
坑 3：镜像越积越大；用多阶段构建 / 精简基础镜像（alpine）。
坑 4：容器一直在前台占用终端；加 -d 后台跑。
