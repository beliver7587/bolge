React

用“组件”拼出界面的前端库 —— 简历工坊、网页游戏、Memora 前端都基于 React 生态。

1. 这是什么

React 是 Facebook 开源的前端 JavaScript 库，用来构建用户界面。它的核心思想是：把页面拆成一个个可复用的组件，每个组件管自己的一小块界面和状态，拼起来就是完整应用。

一句话：React 像一个“乐高积木盒”，你用组件（积木）拼出整个网站，数据变了界面自动跟着变。

2. 三个核心概念

① 组件（Component）

一个函数，返回一段界面（JSX）。比如一个“按钮”或“卡片”都可以是组件。

② JSX

把 HTML 写进 JS 里的语法糖，看起来像 HTML，其实是 JavaScript。浏览器不认识 JSX，需要 Vite/打包工具编译成 React.createElement(...)。

③ Props 与 State

  • Props：父组件传给子组件的数据，像函数的入参，只读。
  • State：组件自己内部的数据，变了会触发界面重新渲染。

3. 第一个例子

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);   // 声明一个状态 count
  return (
    <div>
      <p>你点了 {count} 次</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}
export default Counter;
逐行看：useState(0) 给组件一个初始为 0 的状态；点按钮调用 setCount 改值，React 自动重画 {count} 那一行。

4. Hooks 入门

Hook 是“钩子”，让你在函数组件里用上状态、副作用等能力，最常用的两个：

Hook作用例子
useState声明状态表单输入、计数器
useEffect处理副作用请求接口、监听事件
useEffect(() => {
  fetch('/api/user').then(r => r.json()).then(setUser);
}, []);   // 第二个参数 [] 表示“只在挂载时执行一次”

5. 常见坑

坑 1：直接改 state 不生效：count++ 不行，必须用 setCount(count+1)，React 靠“新引用”判断变化。
坑 2：忘记加 key：用 map 渲染列表时每个子项要带唯一 key，否则增删会错乱。
坑 3：useEffect 依赖没写全会拿到旧值；依赖数组要列出所有用到的外部变量。

6. 小结与上手

React 本质是“组件 + 数据驱动界面”。下一步建议：用 npm create vite@latest 选 React 模板跑起来，照着改上面的 Counter 例子，再学状态管理 Zustand 和路由。三个项目的源码里都有大量组件可参考。
