Ant Design

蚂蚁出品的企业级 React 组件库 —— 简历工坊的表单、弹窗、表格都靠它。

1. 这是什么

Ant Design（简称 antd）是一套开箱即用的 React UI 组件库：按钮、表单、表格、弹窗、日期选择器等几百个精心设计的组件。你不用自己写样式，直接像搭积木一样拼出专业后台界面。它背后是“设计语言”，保证整站风格统一。

2. 安装与引入

npm install antd
// 在组件里直接用
import { Button, Form, Input } from 'antd';
提示：antd v5 用 CSS-in-JS，不需要再手动引 CSS 文件，引入组件即可。

3. 常用组件

组件用途
Button按钮（type 控制主/次/危险）
Form / Input表单与输入框，自带校验
Table数据表格，支持分页/排序
Modal弹窗
message顶部轻提示（成功/失败）

4. 表单实战

import { Form, Input, Button, message } from 'antd';

function LoginForm(){
  const [form] = Form.useForm();
  const onFinish = (v) => { message.success('提交：' + v.username); };
  return (
    <Form form={form} onFinish={onFinish}>
      <Form.Item name="username" rules={[{ required:true, message:'必填' }]}>
        <Input placeholder="用户名" />
      </Form.Item>
      <Button type="primary" htmlType="submit">登录</Button>
    </Form>
  );
}
亮点：rules 自带校验，onFinish 拿到已校验的数据，省去手写验证逻辑。

5. 常见坑

坑 1：v4 到 v5 变化大，教程若引用 import 'antd/dist/antd.css' 在 v5 会报错——v5 不需要。
坑 2：自定义主题用 ConfigProvider，别去改 node_modules。
坑 3：表单默认值用 initialValues 或 form.setFieldsValue，直接改 state 不一定生效。
