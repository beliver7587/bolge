RRF

倒数排名融合（Reciprocal Rank Fusion）—— 把多个检索结果（BM25、向量）简单又好用地合在一起。RAG 混合检索的关键一步。学完你能把不同检索“取长补短”。

1. 这是什么

RRF 是一种“融合多个排序列表”的算法。它不看各列表的原始分数（因为不同算法分数尺度不同），只看“排名位置”。

一句话：不管 BM25 打 9.3 分还是向量打 0.81 分，RRF 只看“排第几”，再按排名给分相加。

2. 为什么需要

BM25 和向量检索返回的是不同尺度的分数，没法直接加权。RRF 用排名规避尺度问题，且对各列表“平等对待”，鲁棒性高。

3. 融合公式

RRF_score(d) = Σ over each rank list L 1 / (k + rank_L(d)) k 为常数（常取 60），rank_L(d) 是文档 d 在列表 L 中的名次（第1名=1） 最终按 RRF 总分降序输出

4. 代码实现

function rrf(lists, k = 60) {
  const score = new Map();
  for (const list of lists) {            // 每个 list 是 [{id}, {id}, ...] 名次从1开始
    list.forEach((item, i) => {
      const id = item.id ?? item;
      score.set(id, (score.get(id) || 0) + 1 / (k + i + 1));
    });
  }
  return [...score.entries()].sort((a, b) => b[1] - a[1]);
}
// 用法
const merged = rrf([bm25Hits, vectorHits]);

5. 实战用法

在 RAG 中：

const bm25 = bm25Search(q, 20);       // 关键词检索 Top20
const vec  = vectorSearch(q, 20);     // 语义检索 Top20
const fused = rrf([bm25, vec], 60);    // 融合
const top = fused.slice(0, 5);         // 取前 5 送大模型
效果：BM25 补精确词命中，向量补语义；RRF 把两者都靠前的结果推上去，召回更稳。

6. 常见坑

坑 1：直接把不同算法的原始分相加，尺度不一导致某一路独大；用排名而非分数。
坑 2：k 太小（如 1）让第1名压倒一切，丧失融合意义；常用 60。
坑 3：某路返回过多（如 1000）稀释融合；各路取相同较小窗口（如 20~50）。
坑 4：忘了去重同一文档在不同列表的 id，分数重复计算错乱。
