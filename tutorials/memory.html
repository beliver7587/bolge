四层记忆

给 AI 设计“像人一样分层记忆”的方案 —— 短期上下文、对话历史、长期事实、固定技能。Memora 凭它记住你是谁、聊过什么。学完你能让 AI 真正“记得”。

1. 这是什么

四层记忆 是把 AI 的记忆按“时效与用途”分成四层，分别用不同技术存储与检索，而不是把所有历史一股脑塞进提示。

一句话：上下文窗口有限，不能啥都塞；分四层管理，该短期的不留痕、该长期的精准召回。

2. 四层分别

层存什么时效技术
工作记忆当前对话的 messages本轮内存
情景记忆历史对话记录中短期DB + 摘要
语义记忆提炼出的长期事实（偏好/资料）长期向量库 Embedding
程序记忆固定指令/技能/工具描述永久系统提示 + 配置

3. 工作记忆

就是当前发给模型的 messages 数组。过长就截断或摘要，避免超窗口。

// 超过 N 轮就摘要压缩
if (messages.length > 20) messages = await summarize(messages);

4. 情景记忆

每轮对话落库，需要时按时间/关键词取回最近若干轮：

await db.insert('turn', { user: q, ai: a, ts: Date.now() });
const recent = await db.query('SELECT * FROM turn ORDER BY ts DESC LIMIT 10');

5. 语义记忆

把“用户偏好、关键事实”提炼成句子，生成向量存库；对话时检索相关事实拼进提示，让 AI 长期“记得你”：

facts = extractFacts(history);            // 抽取“用户喜欢简洁回答”等
for (f of facts) vecDB.add(embed(f), f);
// 对话时
const rel = vecDB.search(embed(question), 5);   // 召回相关长期事实

6. 程序记忆

固定的系统指令、可用工具列表、业务规则，放在 system 提示或配置里，每次都带，不随对话变化。

7. 常见坑

坑 1：不分层的把所有历史塞进上下文，既超窗口又烧钱；按层取舍。
坑 2：语义记忆抽取质量差，召回无关事实；用更强的抽取提示或人工校验。
坑 3：情景记忆不清理，隐私/过期信息长期留存；设保留期与删除能力。
坑 4：忘记 提示注入防护，记忆里混入恶意指令。
