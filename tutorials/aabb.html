AABB 碰撞检测：从小白到资深

AABB（Axis-Aligned Bounding Box） 用两个不旋转的矩形是否重叠判断“撞没撞上”，是 2D 游戏最基础的命中判定。本教程讲透重叠的数学充要条件、包围盒层级、连续碰撞（隧穿）、空间加速（broad-phase）、旋转物体处理与性能调试——游戏手感与性能的底层。

1. 它解决什么问题

判定“两个物体是否相交”是物理/战斗/拾取的核心。AABB 把任意形状先用正矩形包起来，只判矩形重叠，O(1)、极快、易实现。

取舍：优点快、简单；缺点不能精确处理旋转/斜物体，且包围盒比原物体大（有“误判”边距）。精细场景配合 OBB/SAT 或多边形分解。

2. 数学本质

两矩形（用左上角 x,y + 宽高 w,h 表示）相撞 ⇔ 在 X、Y 轴都重叠：

A.x < B.x+B.w AND A.x+A.w > B.x AND A.y < B.y+B.h AND A.y+A.h > B.y 四个条件同时成立才重叠（分离轴思想：任一轴不重叠即未撞）
分离轴定理雏形：只要找到一个轴（这里 X 或 Y）上两盒不重叠，就必然不相交——这是一切碰撞检测的核心思想。

3. 实现与层级

function aabb(a, b) {
  return a.x < b.x + b.w &&
         a.x + a.w > b.x &&
         a.y < b.y + b.h &&
         a.y + a.h > b.y;
}
const player = { x:50, y:50, w:30, h:30 };
const enemy  = { x:70, y:60, w:30, h:30 };
if (aabb(player, enemy)) console.log('撞上了');
  • 坐标系统一：明确用左上角还是中心+半宽，全工程一致。
  • 层级包围盒：先用大盒做粗筛，命中再细分（宽相位→窄相位）。

4. 连续碰撞（防隧穿）

高速物体一帧可能“穿过”薄墙（步长 > 墙厚），叫隧穿。对策：

  • 扫掠 AABB（sweep）：算位移线段与障碍最近相交时刻 t∈[0,1]，先做连续检测。
  • 多子步：把一帧切成 N 小步分别检测。
  • 胶囊/射线：运动物体用射线/扫掠体而非静态盒。

5. 空间加速（broad-phase）

N 个物体两两检测是 O(n²)，物体多必卡。用宽相位快速排除明显不相交的对：

  • 均匀网格：把场景切成格子，只查相邻格。
  • 四叉树/BVH：空间划分，规模更大时更优。
  • 典型管线：broad-phase（粗筛候选对）→ narrow-phase（AABB/SAT 精确判定）。

6. 旋转物体

AABB 对旋转物体会用更大的外接盒，误差大。方案：

  • OBB（有向包围盒）+ SAT 分离轴定理：对任意凸多边形取各边法线作轴，投影均重叠才相交。
  • 或把旋转物体转回轴对齐在局部坐标判定。

7. 性能与调试

  • 对象池：碰撞体复用，减少 GC 抖动。
  • 休眠：静止物体标记为 asleep，不参与检测直到被唤醒。
  • 可视化：调试期画包围盒轮廓，直观看误判/穿透。

8. 常见坑

坑 1：坐标系混用（中心 vs 左上角）导致判定偏移。
坑 2：高速物体隧穿 → 扫掠/子步。
坑 3：旋转物体用 AABB 既大又不准 → OBB/SAT。
坑 4：大量物体 O(n²) 卡顿 → 空间划分/宽相位。
