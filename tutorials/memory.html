四层记忆

让 AI 跨会话记得你 —— 会话/情景/语义/程序四层记忆的设计与实现。

1. 这是什么

普通聊天机器人每刷新一次就变回陌生人。长期记忆让 AI 跨多次会话都记得你。Memora 把记忆拆成四层，分层管理、按需检索，是它“有记忆”的核心。

2. 四层分别

层载体说明
会话记忆本次对话记录短期，当前会话的完整问答
情景记忆事件摘要从对话总结的“事件”（如“上周投诉过物流”）
语义记忆事实/画像抽取的“事实”（如“VIP3、在深圳”）
程序记忆规则话术固定行为规则，可后台增删改

3. 写入与检索

每轮对话后异步抽取事实写入语义记忆（不阻塞首字响应）；检索时按“相似度 × 时间衰减 + 关键词”排序，越久远的记忆权重越低。

const decay = Math.pow(0.5, ageDays/30);        // 半衰期 30 天
const score = sim*(0.7+0.3*decay) + 0.15*kw;    // 越久越淡

4. 隐私隔离

铁律：记忆与知识物理分表、检索路径完全分开，杜绝用户 A 的隐私被知识检索命中；所有记忆查询强制带 user_id，隔离下沉到 SQL 层。

5. 常见坑

坑 1：记忆写入阻塞主响应导致慢——务必异步（setImmediate/Worker）。
坑 2：冲突不处理——“我换工作了”会被当成矛盾；应标记旧事实失效而非删除。
坑 3：忘记按 user_id 隔离，串号泄露隐私。
