systemd 服务

Linux 的进程总管 —— 写个 .service 让后端开机自启、崩溃重启。

1. 这是什么

systemd 是绝大多数 Linux（含 Ubuntu）的初始化与服务管理系统。你写一个 .service 配置文件，就能让某个程序成为“系统服务”：开机自动启动、崩溃自动重启、统一看日志。比 PM2 更底层、更“正规”。

2. 为什么用

对比：PM2 是 Node 生态的守护；systemd 是系统级，语言无关，且和 journalctl 日志、开机启动深度整合。

3. 写一个 unit

# /etc/systemd/system/memora.service
[Unit]
Description=Memora AI Customer Service
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/ai-customer-service
ExecStart=/usr/bin/node server.js
Restart=on-failure        # 崩了自动重启
RestartSec=5

[Install]
WantedBy=multi-user.target

4. 常用命令

sudo systemctl daemon-reload      # 改了配置先重载
sudo systemctl enable memora      # 开机自启
sudo systemctl start memora       # 启动
sudo systemctl status memora      # 看状态
journalctl -u memora -f           # 看日志

5. 常见坑

坑 1：工作目录/用户写错，服务起不来——先用 status 看报错。
坑 2：写错 ExecStart 路径，或没给执行权限。
坑 3：用 root 跑服务有安全风险——尽量指定普通用户（如 ubuntu）。
