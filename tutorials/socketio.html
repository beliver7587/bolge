Socket.IO

基于 WebSocket 的实时双向通信库 —— 自动重连、降级、房间广播，做聊天/联机游戏首选。网页游戏平台用它做实时对战。学完你能做实时应用。

1. 这是什么

Socket.IO 封装了 WebSocket，并补充了浏览器兼容、自动重连、断线降级（退化到轮询）、房间/命名空间、广播等能力。

对比：WebSocket 是底层协议；Socket.IO 是“更好用的封装”，开箱即用。
适合：聊天室、实时通知、多人协作、联机游戏。

2. 环境准备

服务端基于 Node.js + Express。安装：

npm install socket.io
# 客户端在浏览器里用（也可 npm i socket.io-client）

3. 服务端

import express from 'express';
import { createServer } from 'node:http';
import { Server } from 'socket.io';

const app = express();
const httpServer = createServer(app);
const io = new Server(httpServer);

io.on('connection', (socket) => {
  console.log('有客户端连上：', socket.id);
  socket.on('disconnect', () => console.log('断开'));
});

httpServer.listen(3000);

4. 客户端

HTML 里直接引 CDN：

<script src="https://cdn.socket.io/4.7.5/socket.io.min.js"></script>
<script>
  const socket = io('http://localhost:3000');  // 连接到服务端
</script>

5. 收发消息

// 客户端发，服务端收
socket.emit('chat', '你好');
// 服务端收
socket.on('chat', (msg) => console.log(msg));

6. 房间与广播

socket.join('room1');                    // 加入房间
io.to('room1').emit('msg', '只对 room1 发');  // 房间广播
socket.broadcast.emit('msg', '给其他所有人发'); // 排除自己
io.emit('msg', '给所有人发');               // 全服广播

7. 实战：聊天

服务端：

io.on('connection', (socket) => {
  socket.on('chat', (txt) => io.emit('chat', txt));   // 收到转发给所有人
});

客户端：

const input = document.getElementById('msg');
document.getElementById('send').onclick = () => {
  socket.emit('chat', input.value); input.value = '';
};
socket.on('chat', (txt) => {
  const li = document.createElement('li'); li.textContent = txt;
  document.getElementById('list').appendChild(li);
});

8. 常见坑

坑 1：前端连不上：跨域。服务端 new Server(httpServer, { cors: { origin: '*' } })。
坑 2：用了 WebSocket 客户端却接 Socket.IO 服务端，协议不兼容；要配对使用。
坑 3：生产环境需把 Socket.IO 路径也经 Nginx 反代（支持 Upgrade），否则长连接断开。
坑 4：广播写错作用域，消息发重复或漏发；理清 socket/io/broadcast/to。
