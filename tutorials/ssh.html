SSH：从小白到资深

SSH（Secure Shell） 是加密的远程登录与命令执行协议（默认 22 端口）。它是运维的“远程遥控器”——登录服务器、传文件、做隧道。本教程讲透协议分层、密钥认证原理、连接优化、文件同步、安全加固、跳板机与端口转发——资深后端掌控服务器的必备能力。

1. 它解决什么问题

Telnet/rsh 明文传输密码；SSH 用加密通道保证机密性与完整性，并支持公钥认证免密登录、端口转发等。

协议分层：传输层（加密/完整性）→ 认证层（密码/公钥）→ 连接层（多路复用通道，承载 shell/转发）。

2. 协议与密钥

  • 对称加密：握手后用协商出的会话密钥加密数据（AES 等）。
  • 非对称：服务器有 host key，首次连接指纹需你确认（防中间人）；客户端用自己密钥做认证。
  • 已知主机：~/.ssh/known_hosts 记录服务器指纹，变更会报警（可能重装/被劫持）。

3. 密钥认证

公钥放服务器、私钥留本地，登录时服务器用公钥挑战、你用私钥应答，无需密码且抗窃听。

ssh-keygen -t ed25519 -C "me@host"      # 推荐 ed25519；RSA 至少 4096
ssh-copy-id user@IP                     # 公钥追加到服务器 authorized_keys
# 或手动：cat ~/.ssh/id_ed25519.pub | ssh user@IP 'cat >> ~/.ssh/authorized_keys'
为何 ed25519 优于 RSA：更短、更快、更安全（椭圆曲线）；老旧设备才需 RSA。

4. 连接优化

把常用配置写进 ~/.ssh/config：别名、复用连接、保活，免重复输 IP/参数。

Host my
  HostName 49.235.163.168
  User ubuntu
  Port 22
  ServerAliveInterval 60      # 防空闲断开
  ControlMaster auto          # 连接复用，第二次秒连
  ControlPath ~/.ssh/%r@%h:%p

之后直接 ssh my。

5. 文件传输

scp ./app.js my:/home/ubuntu/          # 本地→服务器
scp my:/var/log/nginx/access.log ./     # 服务器→本地
rsync -avz --delete ./dist/ my:/var/www/   # 增量同步，大目录首选
rsync 优势：只传差异块、可断点续、保留权限，部署更新远比 scp 高效。

6. 安全加固

  • 禁密码/root 登录：/etc/ssh/sshd_config 设 PasswordAuthentication no、PermitRootLogin no。
  • 改端口：降低暴力扫描（非真正安全，但减噪）。
  • fail2ban：多次失败封 IP，防爆破。
  • 私钥保护：chmod 600 ~/.ssh/id_ed25519；服务器 authorized_keys 600、.ssh 700。

7. 跳板与隧道

ssh -J bastion my                      # ProxyJump：经跳板机访问内网
ssh -L 8080:127.0.0.1:80 my           # 本地转发：把远端 80 映射到本地 8080
ssh -R 9000:127.0.0.1:9000 my         # 远程转发：把本地服务暴露到远端
ssh -D 1080 my                        # 动态转发：本地 SOCKS 代理
实用：本地转发可安全访问服务器上只绑 127.0.0.1 的数据库/管理后台（如 n8n、Redis）。

8. 常见坑

坑 1：文件权限太开放导致密钥不生效；按上面 600/700 修正。
坑 2：22 端口被安全组/防火墙拦截 → 云控制台放行。
坑 3：root 直登被禁 → 用普通用户 + sudo。
坑 4：私钥提交 git 泄露 → 加入 .gitignore，泄露即换密钥。
坑 5：known_hosts 变更报警 → 确认是重装还是被劫持，别盲目 yes。

9. 成长路线

阶段能力标志
小白会生成密钥、免密登录、scp 传文件
初级ssh config 别名/复用、rsync 同步
中级sshd 加固、fail2ban、端口转发
资深跳板机/ProxyJump、密钥治理、bastion 架构
练习：① 用 ed25519 免密登录 ② 写 ssh config 别名+复用 ③ rsync 部署一次 ④ 禁密码登录+fail2ban ⑤ 用 -L 安全访问远端数据库 ⑥ 用 -J 经跳板访问内网。
你已进阶：理解 SSH 不仅是登录，更是安全通道与隧道工具，能加固服务器、做文件同步与网络穿透——这是资深后端掌控基础设施的核心能力。
