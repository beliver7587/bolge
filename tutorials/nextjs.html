Next.js

基于 React 的“全家桶”框架 —— 自带路由、服务端渲染、API 接口，能直接做出可上线的完整网站。学完你能独立搭一个全栈站点。

1. 这是什么

Next.js 是建立在 React 之上的框架。纯 React（Vite 那套）只是“前端库”，而 Next.js 给你补齐了做一个完整网站缺的东西：

你需要的Next.js 提供
多页面 / 路由基于文件的路由（建个文件就是个页面）
SEO / 首屏快服务端渲染（SSR）、静态生成（SSG）
后端接口API Routes（写个文件就是个接口）
图片优化 / 字体内置 <Image> 等优化组件
一句话：React 负责“画界面”，Next.js 负责“把界面组织成网站并跑在服务器上”。简历工坊前端就跑在 Next.js 上。

2. 环境准备

1

装 Node.js（≥18.18）

到 nodejs.org 装 LTS。验证：

node -v
2

准备包管理器

Next.js 官方推荐 npm，也可以用 pnpm/yarn。本文用 npm。

3. 创建项目

npx create-next-app@latest my-site --typescript --eslint --app
cd my-site
npm run dev

参数说明：

  • --typescript：用 TS（推荐，少 bug）。
  • --app：用新的 App Router（现在默认，下面重点讲）。

打开 http://localhost:3000，看到 Next.js 欢迎页即成功。

my-site/
├─ app/
│  ├─ page.tsx        # 首页 /
│  ├─ layout.tsx      # 所有页面的公共外壳（导航/字体）
│  └─ globals.css
├─ public/            # 静态资源（图片等）
└─ package.json

4. 两种路由模式

  • App Router（app/ 目录，新）：每个 page.tsx 是一个路由，推荐。
  • Pages Router（pages/ 目录，旧）：pages/about.tsx = /about。
新手：直接用默认的 App Router，别纠结历史。

5. 页面与组件

在 app/ 下新建 about/page.tsx 就得到 /about 页面：

// app/about/page.tsx
export default function About() {
  return <h1>关于我们</h1>;
}

组件放在 app/ 外或任意处，比如 components/Button.tsx，再 import 使用。注意：App Router 里组件默认是服务端组件（不能直接用 useState / 浏览器 API）；要写交互组件，顶部加 'use client'：

'use client';
import { useState } from 'react';
export default function Like() {
  const [n, setN] = useState(0);
  return <button onClick={() => setN(n + 1)}>👍 {n}</button>;
}

6. 数据获取

服务端组件直接取数（推荐，无需 useEffect）

// app/users/page.tsx  （服务端组件）
async function getUsers() {
  const res = await fetch('https://api.example.com/users');
  return res.json();
}
export default async function Users() {
  const users = await getUsers();     // 在服务端拿数据，首屏就有
  return <ul>{users.map(u => <li key={u.id}>{u.name}</li>)}</ul>;
}
好处：数据在服务端拿到，HTML 里已经包含内容，SEO 友好、首屏快，还不用写 useEffect。

7. API 路由

在 app/api/ 下建文件就是接口：

// app/api/hello/route.ts
export async function GET() {
  return Response.json({ message: '你好 from API' });
}

访问 /api/hello 即可拿到 JSON。支持 GET/POST/PUT/DELETE 等导出函数。

8. 样式方案

  • globals.css：全局样式。
  • CSS Modules：import s from './x.module.css'。
  • Tailwind：npx create-next-app 时可勾选，最受社区欢迎。
  • Ant Design：企业后台首选。

9. 部署上线

最简方案——Vercel（Next.js 官方平台，免费）：

1

打包

npm run build
2

推到 GitHub

把项目推到 GitHub 仓库。

3

Vercel 导入仓库

登录 vercel.com → New Project → 选仓库 → Deploy，几分钟得到域名。

也支持：自托管可用 npm start 起 Node 服务，前面套 Nginx 反代（见运维教程）。

10. 常见坑

坑 1：在服务端组件里用了 useState/onClick 报“Event handlers cannot be passed”。解决：组件顶部加 'use client'。
坑 2：直接 import './x.css' 全局 CSS 只能在 app/ 入口引入；组件局部样式请用 .module.css。
坑 3：API 路由返回要用 Response.json(...)（新版），不是旧的 NextResponse（也可用但非必须）。
坑 4：图片不用 next/image 也能跑，但会失去优化；用 <img> 会有 lint 警告（非错误）。
坑 5：环境变量：客户端要用的必须加前缀 NEXT_PUBLIC_，否则打包后拿不到。
坑 6：路由刷新 404（自托管）：需在服务器配置“所有路径 fallback 到 index.html”或按文档配 rewrites。
