HTML：从小白到语义化专家

HTML 是网页的结构语言，用标签搭出页面骨架。它不负责样式（那是 CSS）和行为（那是 JS）。本教程从“怎么写对标签”讲到“语义化与可访问性”——这是所有前端的根基。

1. 它是什么

HTML（HyperText Markup Language）用标签描述内容的意义与结构，浏览器解析后渲染成页面。它是网页的“骨架”。

一句话：HTML = 用标签表达“这是什么内容”。结构对了，样式和行为才好加。

2. 文档结构

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>标题</title>
</head>
<body>
  <h1>你好</h1>
</body>
</html>
  • <head>：元信息（不显示在页面），如编码、标题、描述。
  • <body>：可见内容。

3. 常用标签

标签含义
h1~h6标题层级
p / ul / ol / li段落与列表
a超链接
img图片（自闭合）
div / span无语义容器（div 块级、span 行内）
table表格

4. 语义化

用“有含义的标签”而非一堆 div：

<header><nav>…</nav></header>
<main><article>…</article></main>
<footer>© 2026</footer>
  • header/nav/main/article/section/aside/footer 让结构与 SEO、屏幕阅读器都更友好。
  • 语义化 = “内容自解释”，也利于 CSS 选择器精准定位。
资深视角：语义化不是“好看”，而是让机器（搜索引擎、辅助技术）正确理解页面；也是团队协作的隐式约定。

5. 表单

<form action="/submit" method="post">
  <label>邮箱<input type="email" name="email" required></label>
  <button type="submit">提交</button>
</form>
  • input 的 type：text/email/password/number/checkbox/radio/date。
  • label 关联输入，提升可点击区域与可访问性。
  • 校验：required、pattern、min/max 浏览器原生支持。

6. 多媒体

<img src="a.jpg" alt="描述" loading="lazy">
<video src="m.mp4" controls></video>
<audio src="s.mp3" controls></audio>
必须写 alt：图片描述不仅是 SEO，更是读屏用户的“眼睛”；装饰图用 alt="" 让读屏跳过。

7. 链接与导航

<a href="/about">关于</a>
<a href="https://x.com" target="_blank" rel="noopener">外链</a>
安全：外链开新窗口要加 rel="noopener"，否则新页面能操控原页面的 window.opener。

8. 元信息

<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="description" content="页面描述，利于 SEO">
  • viewport：移动端适配必备。
  • description：搜索结果摘要。

9. 可访问性

  • 用语义标签 + 合理标题层级。
  • 交互元素用原生 button/a，保证键盘可达。
  • 颜色对比度达标，不只用颜色传达信息。

10. 与 CSS/JS

HTML 结构 + CSS 表现 + JS 行为，三者分离：

<link rel="stylesheet" href="style.css">
<script src="app.js" defer></script>

defer 让脚本在 DOM 解析后执行，不阻塞渲染。

11. 常见坑

坑 1 嵌套错误：<p> 里不能再放块级元素；<a> 不能嵌套 <a>。
坑 2 忘记 lang：不写 lang 影响读屏与 SEO。
坑 3 滥用 div：该用 button 的地方用 div，丧失键盘与语义。

12. HTML5 新特性

  • 语义标签（header/main 等）。
  • canvas（见 Canvas 2D）、video/audio 原生多媒体。
  • localStorage、data-* 自定义属性。

13. 最佳实践

  • 先写结构再写样式，结构优先语义化。
  • 图片必写 alt，外链必加 noopener。
  • 表单用原生校验减负。

14. 资源与路线

  1. MDN HTML 文档（最权威）。
  2. 接着学 CSS、JavaScript、React。
  3. 练：用语义标签手写一个带表单的落地页。
资深标志：写出的 HTML 不仅“能显示”，而且“机器可读、人人可达”——语义化与可访问性成为本能。
