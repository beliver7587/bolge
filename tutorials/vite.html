Vite

当下最主流的前端构建工具 / 开发服务器 —— 启动秒开、热更新飞快。React、Vue 官方都推荐用它。学完你能自己从零搭一个现代前端工程。

1. 这是什么

Vite（法语“快”）是前端构建工具，干两件事：

  • 开发服务器：启动极快，改代码毫秒级热更新（比老牌 Webpack 快很多）。
  • 打包器：npm run build 把代码压缩、合并成浏览器能跑的静态文件。
一句话：Vite 让你不用懂打包原理，也能拥有“现代前端工程”的开发体验。它不绑死框架，React / Vue / 原生都能用。

2. 环境准备

1

装 Node.js（≥18）

见 React 教程。

2

验证

node -v && npm -v

3. 创建项目

npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev

可选模板：react / vue / vanilla（纯 JS）/ react-ts 等。打开终端给的 localhost 地址即可。

4. 目录与脚本

my-app/
├─ index.html        # 入口（Vite 从这儿开始）
├─ vite.config.js    # Vite 配置
├─ package.json
└─ src/
   ├─ main.jsx       # JS 入口
   ├─ App.jsx
   └─ assets/        # 图片等
package.json 脚本：
  "dev":   "vite"            # 开发
  "build": "vite build"      # 打包
  "preview":"vite preview"   # 预览打包结果

5. 配置入门

vite.config.js 里常改两项：

import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  server: { port: 3000, open: true },   // 改端口 + 自动开浏览器
  build: { outDir: 'dist' }             // 打包输出目录
});

6. 引入资源

import logo from './assets/logo.png';   // 直接 import 图片
import './style.css';                   // 引入 CSS
import data from './data.json';         // 引入 JSON
爽点：Vite 帮你处理路径、哈希文件名，不用手动配 loader。

7. 环境变量

项目根目录建 .env：

VITE_API_URL=https://api.example.com

代码里读取：import.meta.env.VITE_API_URL。注意变量必须以 VITE_ 开头才会暴露给前端。

8. 打包部署

npm run build      # 生成 dist/
npm run preview    # 本地先看一眼

把 dist/ 整个上传到任意静态托管（GitHub Pages、Vercel、Nginx）即可上线。注意：dist/index.html 用了绝对路径 /assets/...，若部署在子目录需配 base。

9. 常见坑

坑 1：import 图片路径写错或没加扩展名，报“Failed to resolve import”。
坑 2：部署后白屏：多半是 base 路径问题（子目录部署要设 base: '/子目录/'）。
坑 3：环境变量不生效：忘了加 VITE_ 前缀，或写在 .env.local 但没重启 dev。
坑 4：vite.config.js 用了 require：配置文件是 ESM，用 import 而不是 require。
坑 5：端口被占用：改 server.port 或用 --port 4000。
