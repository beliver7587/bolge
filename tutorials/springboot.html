Spring Boot

Java 世界最主流的后端框架 —— 开箱即用、内嵌 Tomcat，几分钟搭一个生产级 API 服务。简历工坊后端就是它。学完你能独立写 Java 后端。

1. 这是什么

Spring Boot 是 Spring 家族的“快速启动器”，帮你省掉大量 XML 配置。核心价值：

  • 内嵌服务器：自带 Tomcat，java -jar 直接跑，不用单独装 Web 容器。
  • 自动配置：引入依赖就自动配好常用组件。
  • 起步依赖：spring-boot-starter-web 一键拿全套 Web 能力。
一句话：写最少的配置，最快拥有一个能跑的后端服务。

2. 环境准备

1

装 JDK 17+

到 Adoptium 下载 Temurin 17 LTS，安装并配置 JAVA_HOME。

java -version   # 应显示 17 或 21
2

装构建工具

用 Maven（最普遍）或 Gradle。装 Maven 后：

mvn -v
3

装 IDE

推荐 IntelliJ IDEA（社区版免费）。

3. 创建项目

最方便：打开 start.spring.io，选：

  • Project: Maven，Language: Java，Spring Boot: 3.x
  • Dependencies: Spring Web、Spring Data JPA、MySQL Driver（按需）
点 Generate 下载 zip，解压后用 IDEA 打开。

4. 目录结构

src/main/java/com/example/demo/
├─ DemoApplication.java     # 启动类（有 main 方法）
├─ controller/              # 接收 HTTP 请求
├─ service/                 # 业务逻辑
└─ repository/              # 数据库访问
src/main/resources/
├─ application.yml          # 配置文件（端口、数据库等）
└─ application.properties

5. 第一个接口

// DemoApplication.java 同级建一个 HelloController.java
@RestController
public class HelloController {
    @GetMapping("/hello")
    public String hello() {
        return "你好，Spring Boot!";
    }
}

运行 DemoApplication 的 main 方法，浏览器访问 http://localhost:8080/hello 即可看到返回。

6. 分层架构

标准三层：Controller（接请求）→ Service（业务）→ Repository（数据）。示例：

@RestController
@RequestMapping("/users")
public class UserController {
    @Autowired private UserService service;
    @GetMapping("/{id}") public User get(@PathVariable Long id) { return service.findById(id); }
}
好处：职责清晰、易测试、易维护。

7. 连数据库

在 application.yml 配置（详见 MySQL）：

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/demo?useSSL=false&serverTimezone=UTC
    username: root
    password: 123456
  jpa:
    hibernate:
      ddl-auto: update

配合 MyBatis-Plus 或 JPA 即可操作数据。

8. 常见坑

坑 1：端口被占用：默认 8080，改 server.port: 9090。
坑 2：JDK 版本不匹配 Spring Boot 3 要求 Java 17+，用 Java 8 会启动失败。
坑 3：依赖没下载完就跑，报 ClassNotFound；执行 mvn clean install 拉全依赖。
坑 4：@RestController 与 @Controller 混淆：前者返回 JSON/字符串，后者返回页面视图。
坑 5：循环依赖：Spring Boot 2.6+ 默认禁止，重构拆分服务。
