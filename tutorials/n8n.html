n8n：从小白到自动化工作流

n8n 是开源的可视化工作流自动化工具，拖节点连成流程，把“收到邮件→调接口→写库→发通知”这类重复活自动化。Memora 用它做流程编排。本教程讲清节点模型与实战。

1. 它是什么

n8n 用“节点 + 连线”表达自动化流程，每个节点完成一步（触发器、HTTP、代码、数据库）。

一句话：n8n = 拖拽式自动化。不用写胶水代码，可视化编排多系统协作。
适合：跨系统数据同步、告警、定时任务、AI 流程。不适合：超高性能/超复杂逻辑（用代码更可控）。

2. 起步

docker run -it -p 5678:5678 n8nio/n8n    # Docker 起，浏览器开 5678

3. 节点与连接

  • 触发器：Schedule（定时）、Webhook（外部调用）。
  • 动作：HTTP Request、Function（写 JS）、数据库节点。
  • 节点用连线传递数据（JSON），支持多分支。

4. 实战示例

Schedule(每天9点) → HTTP(拉数据) → Function(清洗) → MySQL(入库) → Slack(通知)
价值：原本要写脚本 + 定时任务 + 监控，n8n 一个画布搞定，还能实时看执行流。

5. 与 AI

n8n 内置 LangChain 节点：接 LLM、向量库做 RAG、用 Function Calling 调工具，快速搭 AI Agent 流程。

6. 与运维

  • 和 systemd/Docker 部署，配反向代理（Nginx）。
  • 敏感凭据存 n8n 凭据库，别硬编码在节点里。

7. 常见坑

坑 1 数据量过大：单节点内存装不下大批量，分批/流式处理。
坑 2 凭据泄露：环境变量与凭据用 n8n 内置加密凭据，别明文。
坑 3 自托管升级：数据目录要持久化（挂卷），否则升级丢流程。

8. 资源与路线

  1. 官方 docs.n8n.io、模板库。
  2. 配合 Docker、LLM。
  3. 练：做一个“定时拉接口→入库→发通知”的工作流。
资深标志：能用 n8n 把跨系统流程可视化落地，并把凭据/持久化/批量处理当成部署前提，而不是画完就跑。
