富文本编辑 / PDF 导出：从小白到简历引擎

“所见即所得”编辑器 + 一键导出 PDF，是简历工坊的核心能力。本教程讲清富文本的本质、编辑器选型、文档序列化，以及怎么把 HTML 稳定地变成 PDF。

1. 它解决什么问题

用户要在网页里像用 Word 一样排版（标题、加粗、列表、插入图片），最后导出成一份排版固定的 PDF 发给 HR。这涉及“编辑”和“印刷级输出”两件事。

一句话：富文本 = 在浏览器里编辑带格式内容；PDF 导出 = 把这份内容按纸张尺寸渲染成文件。

2. 编辑器选型

方案取舍
原生 contenteditable零依赖，但要自己处理光标/命令，坑多
Quill开箱即用，API 友好，但定制样式受限
TipTap（基于 ProseMirror）用 Vue/React 组件化，可扩展强，现代首选
Slate高度自定义，复杂度高
资深建议：新项目选 TipTap/ProseMirror，文档模型是结构化 JSON，序列化与协同都好做。

3. contenteditable

浏览器给元素加 contenteditable="true" 就能直接打字。但底层差异大：不同浏览器生成的 HTML 不一致，光标（Selection/Range）管理复杂。

坑：直接依赖 contenteditable 产出的原始 HTML 很脆——建议用成熟编辑器，别手写命令。

4. 文档模型

  • HTML 字符串：最简单，但跨编辑器不兼容、易 XSS。
  • JSON/Delta：结构化描述（如 Quill 的 Delta），稳定、可 diff、可协同。
做法：存储用结构化 JSON，渲染时再转 HTML，导出 PDF 也用它。

5. 常用功能

  • 文本样式：加粗、斜体、标题、列表、对齐。
  • 插入：图片、分割线、链接。
  • 模板：简历工坊提供预设板块（教育/经历），用户只填内容。

6. 序列化

const html = editor.getHTML();          // 存 HTML
const json = editor.getJSON();          // 存结构化
localStorage.setItem('resume', JSON.stringify(json));

草稿存本地（见 Zustand persist 思路），刷新不丢。

7. PDF 导出

import html2pdf from 'html2pdf.js';
html2pdf().set({ filename:'resume.pdf', jsPDF:{ format:'a4' } }).from(el).save();
  • html2pdf.js：基于 html2canvas + jsPDF，把 DOM 截图再塞进 PDF，适合简单排版。
  • 打印法：window.print() + @media print CSS，效果最“印刷级”。
  • 服务端渲染：用 Puppeteer 在服务端生成，质量最高但需后端。
坑：html2canvas 对部分 CSS（如外部字体、box-shadow）支持差，导出前用打印样式“净化”页面。

8. 图片处理

用户插入图片：先上传到对象存储拿到 URL，再插入编辑器，避免把巨大 base64 塞进文档。简历工坊用 OSS + 压缩。

9. 与简历工坊

简历工坊 = 模板编辑（富文本）+ 主题（Tailwind/token）+ 大模型润色 + PDF 导出 + 分享链接，整体由 Spring Boot 后端 + Next.js 前端支撑。

10. 常见坑

坑 1 XSS：渲染用户 HTML 前必须 sanitize（DOMPurify），否则存储型 XSS。
坑 2 导出错位：分页处内容被截断，用打印样式控制 break-inside: avoid。
坑 3 字体：导出 PDF 缺字体导致中文方块，需内嵌字体或用打印法。

11. 最佳实践

  • 文档存结构化 JSON，渲染/导出都从它来。
  • 编辑器与导出共用一套“净化”样式。
  • 图片走上传，不塞 base64。

12. 资源与路线

  1. TipTap 文档 tiptap.dev、Quill 文档。
  2. 搭配 HTML、CSS print 媒体查询。
  3. 练：用 TipTap 做一个能存草稿、能导出 A4 PDF 的简历编辑器。
资深标志：区分“编辑态 HTML”和“导出态 HTML”，用结构化文档模型保证跨端一致，并把安全（sanitize）当成第一优先级。
