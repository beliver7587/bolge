PixiJS

基于 WebGL 的高性能 2D 渲染库 —— 做小游戏、动画、可视化利器。网页游戏平台就用它渲染。学完你能画出会动的 2D 画面。

1. 这是什么

PixiJS 把浏览器的 WebGL（GPU 硬件加速）封装成简单易用的 API，让你用很少代码画出大量高性能的 2D 图形/精灵。

对比：Canvas 2D 用 CPU 画，几百个对象就卡；PixiJS 用 GPU，几千上万个精灵仍流畅——适合游戏。
适合：H5 小游戏、粒子特效、数据可视化、互动广告。
不适合：3D（请用 Three.js）、简单静态图（直接用 CSS/Canvas 更轻）。

2. 环境准备

方式 A：CDN 直接引（最快试手）：

<script src="https://pixijs.download/release/pixi.min.js"></script>

方式 B：在 Vite 项目里 npm install pixi.js 然后 import { Application, Graphics } from 'pixi.js'。

3. 第一个画面

<div id="app"></div>
<script>
const app = new PIXI.Application();
await app.init({ width: 600, height: 400, background: '#0b1020' });
document.getElementById('app').appendChild(app.canvas);
</script>
注意：PixiJS v8 用异步 await app.init(...)；v7 及以前是 new PIXI.Application({...})。本文按 v8。

4. 图形与文字

const g = new PIXI.Graphics();
g.roundRect(50, 50, 120, 80, 12).fill('#5b8cff');   // 圆角矩形
app.stage.addChild(g);

const t = new PIXI.Text({ text: '你好', style: { fill: '#fff', fontSize: 28 } });
t.x = 200; t.y = 70;
app.stage.addChild(t);

5. 加载图片精灵

const texture = await PIXI.Assets.load('hero.png');
const sprite = new PIXI.Sprite(texture);
sprite.anchor.set(0.5);          // 以中心为原点
sprite.x = 300; sprite.y = 200;
app.stage.addChild(sprite);

6. 动画与交互

用 ticker 每帧回调做动画：

app.ticker.add((ticker) => {
  sprite.rotation += 0.02;        // 每帧旋转
});

sprite.eventMode = 'static';      // 开启交互
sprite.on('pointerdown', () => { sprite.scale.x *= 1.1; });

7. 实战：跳动方块

const app = new PIXI.Application();
await app.init({ width: 400, height: 300, background: '#0b1020' });
document.body.appendChild(app.canvas);

const box = new PIXI.Graphics();
box.roundRect(-40, -40, 80, 80, 10).fill('#39e0d0');
box.x = 200; box.y = 0;
app.stage.addChild(box);

let vy = 0;
app.ticker.add(() => {
  vy += 0.4;                 // 重力
  box.y += vy;
  if (box.y > 260) { box.y = 260; vy = -10; }   // 落地反弹
});
运行：保存为 HTML 直接打开，方块会像球一样上下弹跳。

8. 常见坑

坑 1：v8 必须 await app.init()，忘写 await 就访问 app.canvas 会 undefined。
坑 2：坐标从精灵自身原点算，旋转/缩放异常多半是没设 anchor.set(0.5)。
坑 3：精灵太多卡顿：用 ParticleContainer 或合图（sprite sheet）减少 draw call。
坑 4：图片跨域：加载外部图需对方允许 CORS，否则纹理变黑/报错。
坑 5：不清空 ticker 回调会导致内存泄漏，卸载场景时 app.ticker.remove(...)。
