Canvas 2D：从小白到游戏渲染

Canvas 2D 是浏览器原生的位图绘图 API：你拿到一块画布，用代码逐帧画点线面。它零依赖、上手快，是 2D 小游戏与可视化的好起点。本教程讲清坐标系、绘制、动画循环与性能陷阱。

1. 它是什么

Canvas 是一块像素画布，所有内容由 JS 命令绘制，浏览器不保留“对象结构”（不像 DOM）。适合高频重绘的游戏、图表。

一句话：Canvas = 一块像素板 + 一套绘图命令。你负责每一帧画什么。
适合：游戏、粒子、图表、图像编辑。不适合：需要点击某个“图形”并单独交互（要自己算命中），此时用 SVG/DOM 更省心。

2. 起步

<canvas id="c" width="800" height="600"></canvas>
const ctx = document.getElementById('c').getContext('2d');
坑：canvas 的 width/height 是绘图分辨率，CSS 的 width/height 是显示尺寸，两者不一致会拉伸模糊。高清屏要按 devicePixelRatio 放大。

3. 坐标系与状态

  • 原点在左上角，x 右、y 下。
  • 绘图状态（颜色、线宽、变换）是“栈”，用 save()/restore() 包裹避免污染。
ctx.save();
ctx.fillStyle = 'red'; ctx.fillRect(0,0,50,50);
ctx.restore();  // 恢复之前状态

4. 基本形状

ctx.fillRect(x,y,w,h);            // 填充矩形
ctx.strokeRect(x,y,w,h);           // 描边矩形
ctx.beginPath(); ctx.arc(cx,cy,r,0,Math.PI*2); ctx.fill();  // 圆
ctx.beginPath(); ctx.moveTo(0,0); ctx.lineTo(100,100); ctx.stroke();  // 线

5. 颜色与样式

  • fillStyle / strokeStyle：颜色、渐变、图案。
  • lineWidth、lineCap、globalAlpha 透明度。
  • 渐变：createLinearGradient。

6. 文本与图像

ctx.font = '16px sans-serif';
ctx.fillText('得分:10', 10, 20);
const img = new Image(); img.src='s.png';
img.onload = () => ctx.drawImage(img, x, y);  // 画精灵
精灵：游戏里角色/道具就是一张图，用 drawImage 按坐标贴上去。

7. 动画循环

function loop() {
  ctx.clearRect(0,0,W,H);   // 清屏
  update();                 // 更新逻辑（位置/速度）
  draw();                   // 重绘
  requestAnimationFrame(loop);  // 下一帧
}
loop();
关键：每帧先 clearRect 再画，否则旧画面会叠加残留。

8. 变换

ctx.translate(x,y); ctx.rotate(angle); ctx.scale(s,s);
// 之后绘制的坐标都相对新原点/角度

配合 save/restore 做“围绕物体中心旋转”等效果。

9. 性能优化

  • 离屏 canvas：把静态背景预渲染到离屏画布，每帧直接贴。
  • 分层：动的层与静的层分开。
  • 避免每帧创建对象/路径过多；批量绘制。

10. 与 WebGL

Canvas 2D 是 CPU 绘制，元素多会卡；要渲染几千个精灵、特效，用 PixiJS/WebGL 走 GPU。

11. 常见坑

坑 1 清晰度：没按 dpr 放大，画面发虚。
坑 2 状态污染：忘了 restore，导致后续颜色/变换错乱。
坑 3 命中检测：Canvas 不保留对象，点哪个图形要自己算距离/包围盒。

12. 实战

“土豆勇士”这类小游戏：维护一个实体数组（位置/速度），每帧 update + draw；键盘/触摸改速度；分数用 fillText 画。逻辑与 PixiJS 版可复用，只是绘制 API 不同。

13. 资源与路线

  1. MDN Canvas 教程。
  2. 配套学 HTML、CSS、JavaScript。
  3. 练：写一个“移动方块 + 键盘控制 + 计分”的小 demo。
资深标志：懂得用离屏/分层把帧率稳住、理解 Canvas 与 WebGL 的能力边界，并能把游戏逻辑与渲染解耦。
