Node.js

让 JavaScript 跑在服务器上的运行时 —— 前后端统一语言，Memora、网页游戏后端都基于 Node。学完你能写服务端程序。

1. 这是什么

Node.js 是把 Chrome 的 V8 引擎拿出来，让 JavaScript 脱离浏览器在服务器端运行的环境。它不是框架，是“运行时”。

一句话：以前 JS 只在浏览器跑；有了 Node，JS 能写服务器、命令行工具、桌面应用。
特点：事件驱动、非阻塞 I/O，擅长高并发 I/O（接口、网关、实时服务）。

2. 环境准备

到 nodejs.org 装 LTS，验证：

node -v
npm -v        # Node 自带包管理器

3. 第一个脚本

新建 hello.js：

console.log('你好，Node');

运行：node hello.js。就这么简单。

4. 模块与 npm

ESM（推荐，Node 现代写法）：

// math.js
export function add(a, b) { return a + b; }
// main.js
import { add } from './math.js';
console.log(add(1, 2));

CommonJS（老，仍大量存在）：

// math.js
module.exports = { add: (a,b)=>a+b };
// main.js
const { add } = require('./math.js');

npm 装包：npm install lodash，然后 import _ from 'lodash'。

5. 读写文件

import { readFile, writeFile } from 'node:fs/promises';
const txt = await readFile('a.txt', 'utf8');
await writeFile('b.txt', txt + '!');
提示：Node 顶层 await 需在 ESM（"type":"module"）下可用。

6. 起一个 HTTP 服务

import http from 'node:http';
const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({ msg: 'hello' }));
});
server.listen(3000, () => console.log('http://localhost:3000'));
更爽：实际开发用 Express 框架，路由写法更简洁。

7. 常见坑

坑 1：混用 ESM 和 CJS：文件是 .js 但没设 "type":"module"，用 import 会报错，改用 require 或把文件改 .mjs。
坑 2：回调地狱（老代码）；新代码用 async/await + Promise。
坑 3：同步阻塞 API（如 readFileSync）在高并发接口里拖慢整体，尽量用异步。
坑 4：忘记 res.end()，请求一直挂起。
坑 5：全局安装包后命令行找不到，检查 npm 全局路径是否在 PATH。
