向量检索 / Embedding

把文字/图片变成“向量”，用距离找相似内容 —— 语义搜索、推荐、RAG 的底层基石。学完你能实现“按意思搜而不是按关键词搜”。

1. 这是什么

Embedding（嵌入） 是把一段文本映射成一个高维向量（如 1536 维数组），语义相近的文本向量也相近。向量检索 就是按向量距离找最近的内容。

一句话：关键词搜索看“字是否一样”；向量搜索看“意思是否接近”。搜“怎么存钱生利息”也能命中“银行理财入门”。
常见向量库：PostgreSQL + pgvector、Milvus、Qdrant、Chroma、Pinecone（云）。

2. 环境准备

需要：大模型供应商的 Embedding 接口（OpenAI / 国产模型）+ 一个向量库。本地快速试：装 @qdrant/js-client-rest 或 Chroma。

npm install openai chromadb

3. 生成向量

import OpenAI from 'openai';
const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });
const res = await client.embeddings.create({
  model: 'text-embedding-3-small',
  input: '银行理财入门'
});
const vector = res.data[0].embedding;   // 一个约 1536 维的数组

4. 存进向量库

import { ChromaClient } from 'chromadb';
const chroma = new ChromaClient();
const col = await chroma.createCollection({ name: 'docs' });
await col.add({
  ids: ['1'],
  embeddings: [vector],
  documents: ['银行理财入门：把闲钱放入定期或基金…'],
  metadatas: [{ source: 'faq' }]
});

5. 相似度检索

const q = await client.embeddings.create({ model:'text-embedding-3-small', input:'怎么让钱生利息' });
const result = await col.query({ queryEmbeddings: [q.data[0].embedding], nResults: 3 });
console.log(result.documents[0]);   // 返回最相近的 3 段

6. 实战：语义搜索

把知识库每篇文档切块 → 各自生成向量入库 → 用户提问也转向量 → 检索出最相关片段 → 交给 RAG 大模型生成答案。这就是 Memora 记忆/检索的核心链路。

7. 常见坑

坑 1：Embedding 模型和检索库维度要一致，否则插不进去。
坑 2：文档太长要“切块（chunk）”，块太大检索不精准、太小丢上下文。
坑 3：中英文/不同供应商向量空间不同，不能混用比对。
坑 4：Embedding 有成本与速率限制，批量时用批处理并缓存结果。
坑 5：只靠向量检索会召回无关内容，通常要和 BM25 关键词混合（RRF）提升准确。
