Socket.IO

封装 WebSocket 的实时通信库 —— 火柴人派对用它做房间内消息中转。

1. 这是什么

Socket.IO 是在 WebSocket 之上封装的实时通信库，让你用“事件”而非原始消息来通信：发一个带名字的事件，对方监听同名事件即可。它还自动处理重连、降级（不支持 WS 时用长轮询兜底）。

2. 与裸 WebSocket 区别

WebSocketSocket.IO
通信单位文本/二进制帧命名事件（带数据）
重连/降级自己写内置
房间/广播自己实现内置 io.to(room)

3. 服务端

import { Server } from 'socket.io';
const io = new Server(3000, { cors:{ origin:'*' } });

io.on('connection', (socket) => {
  console.log('有新连接');
  socket.on('chat', (msg) => {          // 监听名为 chat 的事件
    io.emit('chat', msg);                // 广播给所有人
  });
});

4. 客户端 + 房间

import { io } from 'socket.io-client';
const socket = io('https://域名');
socket.emit('chat', '你好');             // 发
socket.on('chat', (m) => console.log(m));// 收

// 房间：把多人圈在一起
socket.emit('join', 'room123');
io.to('room123').emit('chat', '仅房间里的人收到');

5. 常见坑

坑 1：客户端和服务端版本要匹配，否则连不上。
坑 2：经过 Nginx 时要配 WebSocket 透传（Upgrade 头），否则握手失败。
坑 3：移动端切后台可能断连，要处理 disconnect 与重连逻辑。
