HTTPS：从小白到加密传输

HTTPS = HTTP + TLS，对网页传输加密，防止窃听与中间人篡改。现代网站标配，Nginx 上的证书用 certbot 免费搞定。本教程讲清证书、自动续期与强制跳转。

1. 它是什么

TLS 在 TCP 之上协商密钥、加密数据。HTTPS 让浏览器与服务器“私聊”，第三方看不到内容、也改不了。

一句话：HTTPS = HTTP over TLS。加密 + 身份认证，网站上线的底线。
必须：登录、支付、API 一律 HTTPS；否则密码明文在公网裸奔。

2. 证书与 CA

  • 证书由 CA（证书颁发机构）签发，证明“这个域名属于你”。
  • 自签证书浏览器不信任（仅测试可用）。
  • 免费且被广泛信任的是 Let's Encrypt。

3. Let's Encrypt

非营利 CA，提供免费、自动、短期的证书（90 天，可自动续）。配合 certbot 几乎零成本上线 HTTPS。

4. certbot 自动化

sudo certbot --nginx -d x.com -d www.x.com   # 自动申请并改 Nginx 配置
sudo certbot renew --dry-run                  # 测试续期

certbot 会配置自动续期（通常挂 systemd timer）。

5. Nginx 配置

listen 443 ssl;
ssl_certificate /etc/letsencrypt/live/x.com/fullchain.pem;
ssl_certificate_key /etc/letsencrypt/live/x.com/privkey.pem;

6. 强制 HTTPS

server {
  listen 80; server_name x.com;
  return 301 https://$host$request_uri;   # 80 全跳 443
}

7. HSTS

add_header Strict-Transport-Security "max-age=31536000" always;

告诉浏览器“以后只走 HTTPS”，防降级攻击。

8. 常见坑

坑 1 证书过期：忘续期网站就红，务必确认自动续期生效。
坑 2 混合内容：HTTPS 页里引了 HTTP 资源，浏览器拦截，统一改 https。
坑 3 全站用自签：非受信证书用户被吓退，用 Let's Encrypt 或正规 CA。
