Vite

秒级启动的前端构建工具 —— 三个项目都用它跑开发服务器和打包产物。

1. 这是什么

Vite（法语“快”）是一个前端构建工具 + 开发服务器。它有两件事：① 开发时给你一个带“热更新”的本地服务器（改代码秒级刷新）；② 上线时把 TS/React 等源码编译、压缩成浏览器能直接跑的静态文件。

2. 为什么快

老工具(Webpack)Vite
启动要先打包整个项目，慢用浏览器原生 ESM，按需编译，秒启
改一处重打包改一处只更新那个模块（HMR）

3. 创建项目

npm create vite@latest my-app -- --template react-ts
cd my-app && npm install

4. 开发与打包

npm run dev      # 开发：http://localhost:5173 ，改代码自动刷新
npm run build    # 打包：产物输出到 dist/ ，可直接丢给 Nginx
npm run preview  # 本地预览打包后的效果
部署关键：dist/ 里是一堆 .html/.js/.css，传到服务器用 Nginx 托管即可（见 Nginx 教程）。

5. 常见坑

坑 1：打包后路径 404？在 vite.config 设 base: '/子路径/'（子路径部署必看）。
坑 2：用了旧浏览器，要配 @vitejs/plugin-legacy 做兼容。
坑 3：环境变量必须以 VITE_ 开头才会被打进前端代码。
