CSS：从小白到资深前端

HTML 管“结构”，CSS 管“表现”。本教程从“会改颜色”讲到“布局引擎原理、层叠优先级、响应式体系、CSS 架构与渲染性能”——这是资深前端在样式层必须掌握的判断力。

1. 它解决什么问题

没有 CSS，网页只有默认黑字白底。CSS 用选择器把“样式规则”应用到元素上，实现布局、视觉与交互反馈。

一句话：CSS 是声明式的：你描述“某类元素应该长什么样”，浏览器负责计算并绘制。难点在于“多条规则冲突时谁赢”（层叠）和“怎么高效布局”（布局引擎）。
资深视角：CSS 不是“美化”，是布局系统 + 渲染性能 + 可维护架构。写得好，响应式/主题/性能都省心；写得烂，!important 满天飞、改一处崩一片。

2. 基础与盒模型

  • 引入：外链 <link>（推荐，可缓存）、<style> 内联、style 属性（最高优先级，尽量别用）。
  • 盒模型：每个元素是一个盒子，由 content + padding + border + margin 组成。默认 width 只算 content；设 box-sizing: border-box 让 width 含 padding/border——全局必设。
  • 单位：px 固定；rem（相对根字体，利于无障碍缩放）；em（相对父）；vw/vh（视口）；%（相对父）。
*, *::before, *::after { box-sizing: border-box; }  /* 行业标准重置 */

3. 层叠与优先级

当多条规则作用于同一属性，按“层叠”决定赢家：

  1. 来源：作者样式 > 用户样式 > 浏览器默认。
  2. 优先级（Specificity）：inline > id > class/属性/伪类 > 元素/伪元素。可用 (a,b,c,d) 记：行内(1,0,0,0) > id 数 > class 数 > 元素数。
  3. 顺序：优先级相同，后写的赢。
坑：!important 能压一切，但会让优先级“失控”，后续难覆盖。把它当最后手段，用来覆盖第三方样式，而非日常写法。

4. 布局：Flex / Grid

  • Flexbox：一维布局（横或纵排）。主轴 justify-content、交叉轴 align-items、gap 间距、flex: 1 占满剩余。居中最省事：display:flex; align-items:center; justify-content:center。
  • Grid：二维布局（行列同时）。grid-template-columns: repeat(3, 1fr) 三列等宽；grid-template-areas 用“命名区域”画布局，语义极清晰。
  • 定位：relative/absolute/fixed/sticky。sticky 做吸顶导航；absolute 需父级 relative 兜底。
.layout { display: grid; grid-template-columns: 240px 1fr; gap: 16px; }  /* 侧栏+内容 */
选型：一维用 Flex，二维（尤其整体页面骨架）用 Grid。两者配合，几乎不需要浮动/定位 hack。

5. 响应式

  • 移动优先：先写小屏样式，再用 min-width 媒体查询往大屏加。
  • clamp(min, val, max)：字体/间距随视口平滑缩放，少写媒体查询。
  • 容器查询 @container：组件按“父容器宽度”而非视口响应——组件级响应式，比媒体查询更适合复用组件。

6. 视觉与动画

  • transition：属性变化加平滑过渡（如 hover 变色）。
  • @keyframes + animation：复杂关键帧动画。
  • 动画性能：只动 transform 和 opacity，这两个走 GPU 合成层，不触发重排/重绘；避免动画 width/height/top（每帧重排，卡）。
  • 阴影/渐变/圆角美化，但别滥用大模糊阴影（贵）。

7. 架构与可维护性

  • 设计令牌（Design Tokens）：颜色/间距/字号定义成 CSS 变量（--color-primary），全站统一、换肤一处生效。
  • BEM 命名：block__element--modifier，避免类名冲突、表达结构。
  • CSS Modules（构建期哈希类名）或 Tailwind（原子类）——见第 10 节。
  • 避免：深层嵌套（如 Sass 里 .a .b .c .d 优先级爆炸）、!important、按页面写死样式。

8. 现代特性

  • CSS 变量 --x + var(--x)：运行时可变、可继承、JS 能读改写（做主题）。
  • :has()：父选择器（“包含某子元素时”），补齐了 CSS 长期缺失的能力。
  • aspect-ratio：固定宽高比（视频/卡片）。gap 已可用于 flex。

9. 性能

  • 重排（Reflow）改几何（增删、改尺寸）最贵；重绘（Repaint）改外观次之；合成（Composite）最便宜。
  • 动画用 transform/opacity（只合成）；批量 DOM 改动减少重排。
  • 关键 CSS：首屏关键样式内联，其余异步加载，提速首屏。
  • will-change 提示浏览器预优化，但别滥用（占内存）。

10. 与框架结合

  • Tailwind：原子类，快但 JSX 变长；适合快速一致地搭 UI（见 Tailwind）。
  • CSS-in-JS（styled-components）：动态主题方便，但有运行时、SSR 需特殊处理。
  • CSS Modules：零运行时、作用域隔离，适合通用组件库。
资深选型：设计系统用 CSS 变量 + Modules；业务快速开发用 Tailwind；需要运行时动态样式才上 CSS-in-JS。

11. 常见坑

坑 1：没设 box-sizing: border-box，width 含 padding 导致布局错位。
坑 2：margin 塌陷/合并（相邻块级 margin 取大值），用 padding 或 BFC 解决。
坑 3：百分比高度失效——父级没明确高度时 height:100% 不生效，需 html,body{height:100%} 或 flex。
坑 4：z-index 不生效——它只在定位元素（relative/absolute/fixed）上有效，且受“层叠上下文”影响（父级创建了上下文，子级 z-index 只在内部比）。
坑 5：flex 子项被压缩/溢出——用 flex-shrink:0 或 min-width:0 控制。
坑 6：用 width/height 做动画导致卡顿，应改 transform。

12. 调试

  • DevTools Elements → 右侧 Computed 看最终生效样式与来源（哪条规则赢了）。
  • Layout 面板可视化 Flex/Grid 轨道、盒模型尺寸。
  • Rendering → Paint flashing 看重绘区域。

13. 成长路线

阶段能力标志
小白会改颜色、写简单样式
初级会用 Flex/Grid 布局、响应式
中级懂层叠优先级、能排查布局 bug、会用变量/令牌
资深设计 CSS 架构、把控渲染性能、选对样式方案
练习：① 用 Grid 搭一个后台三栏布局 ② 用 CSS 变量做明暗主题切换 ③ 用 transform 写一个 60fps 的卡片悬浮动画 ④ 用 DevTools 找出一个页面的重绘热点。
你已进阶：理解层叠、布局引擎与渲染管线，能写出可维护、高性能的样式——这是资深前端在 CSS 层的核心能力。
