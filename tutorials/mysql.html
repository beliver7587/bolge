MySQL

最流行的开源关系型数据库 —— 用表存结构化数据，支持 SQL 查询。简历工坊就用它存数据。学完你能设计表并操作数据库。

1. 这是什么

MySQL 是关系型数据库：数据按“库 → 表 → 行”组织，用 SQL 语言增删改查。它保证事务、一致性，适合存订单、用户、文章等结构化数据。

对比：Redis 是内存键值库（快、适合缓存）；MySQL 是落盘的关系库（持久、适合业务主数据）。

2. 环境准备

最省事：装 Docker 一键起，或用本地安装包（Windows 用 MySQL Installer，Mac 用 brew install mysql）。Docker 方式：

docker run -d --name mysql -e MYSQL_ROOT_PASSWORD=123456 -p 3306:3306 mysql:8

客户端工具推荐 Navicat / DBeaver / TablePlus，图形化操作更直观。

3. 连上数据库

mysql -h 127.0.0.1 -P 3306 -u root -p
# 输入密码后进入 mysql> 提示符

4. 建库建表

CREATE DATABASE demo CHARACTER SET utf8mb4;
USE demo;
CREATE TABLE user (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(50) NOT NULL,
  age INT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
要点：用 utf8mb4 支持 emoji；NOT NULL 约束必填；AUTO_INCREMENT 自增主键。

5. 增删改查

INSERT INTO user(name, age) VALUES ('小王', 18);
SELECT * FROM user WHERE age > 16;
UPDATE user SET age = 19 WHERE name = '小王';
DELETE FROM user WHERE id = 1;

6. 从代码连

Node 用 mysql2：

import mysql from 'mysql2/promise';
const pool = mysql.createPool({ host:'localhost', user:'root', password:'123456', database:'demo' });
const [rows] = await pool.query('SELECT * FROM user');
console.log(rows);

7. 索引与优化

给常查询的列加索引提速：

CREATE INDEX idx_name ON user(name);
注意：索引加速查询但拖慢写入；SELECT *、在列上做函数运算会导致索引失效。

8. 常见坑

坑 1：字符集用 utf8（非真正 UTF-8）导致 emoji 报错，务必 utf8mb4。
坑 2：SQL 拼接导致注入；用参数化查询 ? 占位。
坑 3：没有主键/索引，数据量大时查询极慢。
坑 4：忘记 COMMIT（关闭自动提交时）事务不生效。
坑 5：远程连不上多为防火墙/绑定地址，检查 bind-address 与放行 3306。
