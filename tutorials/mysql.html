MySQL

最流行的开源关系型数据库 —— 简历工坊的结构化数据全存这里。

1. 这是什么

MySQL 是关系型数据库：数据按“表（行和列）”组织，表之间可以建立关联。它用 SQL 语言增删改查，成熟稳定、社区庞大，是绝大多数网站后台的默认选择。

2. 表与 SQL

表就像 Excel：列是字段（姓名、年龄），行是一条记录。常用 SQL：

SELECT * FROM user WHERE id = 1;          -- 查
INSERT INTO user(name) VALUES('王越');     -- 增
UPDATE user SET name='越' WHERE id=1;      -- 改
DELETE FROM user WHERE id=1;               -- 删

3. 建表实战

CREATE TABLE resume (
  id        BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id   BIGINT NOT NULL,
  title     VARCHAR(120),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  INDEX idx_user (user_id)                  -- 给常用查询字段加索引
);

4. 索引与事务

  • 索引：像书的目录，加速查询；但会拖慢写入，别乱加。
  • 事务：把多个操作绑成“要么全成、要么全退”的一笔，保证数据一致（转账必备）。
START TRANSACTION;
UPDATE account SET balance=balance-100 WHERE id=1;
UPDATE account SET balance=balance+100 WHERE id=2;
COMMIT;   -- 或 ROLLBACK 回退

5. 常见坑

坑 1：用字符串拼接 SQL 会 SQL 注入——务必用参数化（见 MyBatis-Plus 的安全写法）。
坑 2：没有主键或索引，数据一大查询就慢。
坑 3：字符集用 utf8mb4 而非旧 utf8，否则存不了 emoji/生僻字。
