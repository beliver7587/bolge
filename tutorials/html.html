HTML

网页的结构语言 —— 用标签搭出页面骨架（标题、段落、按钮、表单）。所有前端的根基。学完你能写出能跑的静态网页。

1. 这是什么

HTML（超文本标记语言）用一对对标签描述页面结构：<h1> 是标题、<p> 是段落、<a> 是链接。浏览器读取它渲染成网页。

三者关系：HTML 是骨架，CSS 是皮肤（样式），JS/Vue 是肌肉（行为）。

2. 环境准备

不需要安装任何东西！新建一个 index.html，用记事本或 VS Code 写，双击即可用浏览器打开。

3. 第一个网页

<!DOCTYPE html>
<html lang="zh-CN">
  <head><meta charset="UTF-8"><title>我的第一个网页</title></head>
  <body>
    <h1>你好，世界</h1>
    <p>这是一段文字。</p>
  </body>
</html>

4. 常用标签

标签作用
h1~h6标题层级
div / span容器（块级/行内）
img图片 src
a链接 href
ul/ol/li列表
button按钮

5. 表单

<form action="/submit" method="post">
  <input name="user" placeholder="用户名">
  <input type="password" name="pwd">
  <button type="submit">登录</button>
</form>

6. 语义化

用 header / nav / main / article / footer 代替满屏 div，利于 SEO 与可读性。

7. 常见坑

坑 1：标签不闭合，布局错乱；养成成对书写习惯。
坑 2：中文乱码；务必 <meta charset="UTF-8">。
坑 3：用 <table> 做布局（已淘汰）；布局请用 CSS Flex/Grid。
坑 4：img 路径写错 404；注意相对路径起点。

8. 下一步

  1. 写一个含标题、图片、表单的个人介绍页。
  2. 学 CSS 美化它。
  3. 学 JavaScript 加点交互。
  4. 看 React/Vue 进阶。
毕业：能写结构清晰的 HTML 页面——前端第一步你已迈出。
