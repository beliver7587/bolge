SSH

安全的远程登录协议 —— 用它从本地电脑连上云服务器敲命令、传文件。部署任何后端都先得会 SSH。学完你能远程掌控服务器。

1. 这是什么

SSH 让你在本地终端安全地操作远程服务器（加密通道）。比起密码登录，推荐用“密钥对”登录，更安全也免输密码。

一句话：SSH 是你和服务器之间的加密“远程遥控器”。

2. 环境准备

本地（Mac/Linux 自带；Windows 用 PowerShell 或装 Git Bash / OpenSSH）。服务器一般是 Linux 并开了 22 端口。

3. 密钥登录

ssh-keygen -t ed25519 -C "my@email.com"
# 一路回车，生成 ~/.ssh/id_ed25519（私钥）和 .pub（公钥）

把公钥放到服务器：

ssh-copy-id user@服务器IP
# 或手动：把 id_ed25519.pub 内容追加到服务器的 ~/.ssh/authorized_keys

4. 连接服务器

ssh user@服务器IP
# 之后输入的是服务器上的命令，如：
#   sudo systemctl status nginx

5. 传文件

# 本地 → 服务器
scp ./app.js user@IP:/home/user/
# 服务器 → 本地
scp user@IP:/var/log/nginx/access.log ./

6. 常见坑

坑 1：权限太开放导致密钥不生效：chmod 600 ~/.ssh/id_ed25519，服务器 authorized_keys 权限 600、.ssh 700。
坑 2：22 端口被防火墙/安全组拦截，连不上；在云控制台放行 22。
坑 3：root 直接登录被禁（多数镜像默认），用普通用户 + sudo。
坑 4：把私钥提交到 git，泄露风险；私钥只留本地，加 .gitignore。
坑 5：长时间无操作断开；在 ~/.ssh/config 加 ServerAliveInterval 60。
