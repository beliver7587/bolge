Nginx

高性能 Web 服务器 / 反向代理 —— 把请求转发给后端、托管静态文件、做负载均衡与 HTTPS 入口。简历工坊部署离不开它。学完你能把网站部署上线。

1. 这是什么

Nginx 是高并发 Web 服务器，常作为“前端入口”：对外暴露 80/443，对内把请求转发给 Node/Spring 等后端（反向代理），也能直接托管静态文件。

一句话：用户只访问 Nginx，Nginx 决定把请求给哪个后端、或返回哪个静态文件。

2. 环境准备

# Ubuntu
sudo apt update && sudo apt install nginx
sudo systemctl start nginx
# 浏览器访问服务器 IP，看到欢迎页即成功

3. 第一个站点

配置在 /etc/nginx/sites-available/，软链到 sites-enabled/：

server {
  listen 80;
  server_name example.com;
  root /var/www/html;
  index index.html;
  location / { try_files $uri $uri/ =404; }
}

4. 反向代理

把 /api 转发给本地 3000 的后端：

location /api/ {
  proxy_pass http://127.0.0.1:3000/;
  proxy_set_header Host $host;
  proxy_set_header X-Real-IP $remote_addr;
}
作用：用户访问 http://域名/api/xxx 实际打到你本机的 Node 服务。

5. 负载均衡

upstream backend {
  server 127.0.0.1:3000;
  server 127.0.0.1:3001;
}
location /api/ { proxy_pass http://backend/; }

6. WebSocket / 静态

# WebSocket 必须加 Upgrade（否则 400）
location /ws/ {
  proxy_pass http://127.0.0.1:8080/;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
}
# SSE 关闭缓冲，避免推送延迟
location /stream { proxy_buffering off; proxy_pass http://127.0.0.1:3000; }

7. 常用坑

坑 1：nginx -t 不校验就 reload，配置错导致 502；改完先 sudo nginx -t 测试。
坑 2：WebSocket/SSE 没配 Upgrade/关闭缓冲，长连接异常。
坑 3：反向代理没带 Host/X-Real-IP，后端拿不到真实域名与 IP。
坑 4：配置改了没 reload：sudo nginx -s reload 才生效。
坑 5：防火墙没放行 80/443，外部访问不了。
