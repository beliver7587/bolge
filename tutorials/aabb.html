AABB 碰撞检测

轴对齐包围盒 —— 用两个矩形是否重叠来判断“撞没撞上”，是 2D 游戏最基础的碰撞算法。网页游戏平台用它做命中判定。学完你能实现游戏碰撞。

1. 这是什么

AABB（Axis-Aligned Bounding Box） 是把物体用“不旋转的矩形”包起来，只要判断两组矩形在 X、Y 轴是否都重叠，就知道是否相撞。

一句话：不管你画的是小人还是飞船，先套个正矩形框，框框碰了就当撞了。
优点：O(1)、极快、实现简单；缺点：不能处理旋转/斜的物体（可用 OBB 或多边形分解）。

2. 核心公式

两矩形 A、B（用 x,y 左上角 + w,h 表示）相撞 ⇔ A.x < B.x + B.w AND A.x + A.w > B.x AND A.y < B.y + B.h AND A.y + A.h > B.y 四个条件同时成立才重叠

3. 代码实现

function aabb(a, b) {
  return a.x < b.x + b.w &&
         a.x + a.w > b.x &&
         a.y < b.y + b.h &&
         a.y + a.h > b.y;
}

4. 实战：矩形碰矩形

const player = { x: 50, y: 50, w: 30, h: 30 };
const enemy  = { x: 70, y: 60, w: 30, h: 30 };
if (aabb(player, enemy)) console.log('撞上了！');

5. 进阶：扫掠检测

物体很快时，一帧可能“穿过”对方（隧穿）。用扫掠 AABB 检测一段位移内是否相交，避免高速穿透漏判。

6. 常见坑

坑 1：坐标用中心点还是左上角要统一；混用导致判定偏移。本文用左上角。
坑 2：高速物体穿越（隧穿）；用扫掠或多子步检测。
坑 3：物体旋转后 AABB 变大且不准；旋转物体用 OBB 或多边形碰撞。
坑 4：大量物体两两检测 O(n²) 卡顿；用空间划分（网格/四叉树）或 端侧权威 简化。
