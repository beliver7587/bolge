Socket.IO：从小白到实时房间

Socket.IO 是封装 WebSocket 的实时通信库，自带自动重连、房间、广播与降级。火柴人派对用它做房间内消息中转。本教程讲清事件模型、房间机制与扩展性。

1. 它是什么

原生 WebSocket 只提供“双向通道”，但缺房间、广播、重连、降级。Socket.IO 在它之上补全套实时通讯能力。

一句话：Socket.IO = WebSocket + 房间/广播/重连/降级。写实时应用省心。

2. 工程化起步

// 服务端（Node + Express）
import { Server } from 'socket.io';
const io = new Server(httpServer);
io.on('connection', (socket) => {
  console.log('新连接', socket.id);
});
// 客户端
import { io } from 'socket.io-client';
const socket = io('http://localhost:3000');

3. 连接与事件

socket.emit('chat', { text: 'hi' });              // 发
socket.on('chat', (msg) => { /* 收 */ });          // 监听
socket.on('connect', () => {});
socket.on('disconnect', (r) => {});

事件名自定义，像消息总线一样收发结构化数据（自动 JSON）。

4. 房间

socket.join('room-123');                  // 进房间
io.to('room-123').emit('move', data);     // 只发给该房间
用法：每个游戏局/聊天组一个房间，消息互不串。火柴人派对里“一局游戏 = 一个房间”。

5. 广播

io.emit('global', data);                  // 全员
socket.broadcast.emit('x', data);         // 除自己外全员
socket.to(room).emit('y', data);          // 房间内

6. 游戏应用

  • 服务端做权威运算：收玩家输入 → 算结果 → 广播状态，防作弊（见 game 架构）。
  • 高频同步用节流/插值，减少带宽。
  • 断线重连靠 Socket.IO 自带机制恢复会话。

7. 鉴权

io.use((socket, next) => {
  const token = socket.handshake.auth.token;
  if (valid(token)) next(); else next(new Error('unauth'));
});

连接握手时校验 token（JWT），非法直接拒绝。

9. 常见坑

坑 1 跨域：客户端连不同域要服务端配 CORS；同域最省事。
坑 2 扩展性：单机内存存房间，多实例要上 Redis 适配器（@socket.io/redis-adapter）共享。
坑 3 泄漏：进/出房间要在 disconnect 时清理，否则房间堆积。

完整流程：Socket.IO 实时房间

1. 服务端
const {Server} = require('socket.io');
const io = new Server(server);
io.on('connection', socket=>{
  socket.join('room1');
  io.to('room1').emit('msg','欢迎');
  socket.on('chat', data=> io.to(data.room).emit('chat', data));
});
2. 客户端
const socket = io('/');
socket.emit('join','room1');
socket.on('chat', data=>appendMessage(data));
3. 适配器
多机部署用 redis-adapter，让消息跨实例广播
npm install @socket.io/redis-adapter
要点：Socket.IO 自动降级；房间适合做群聊；命名空间隔离不同业务。
