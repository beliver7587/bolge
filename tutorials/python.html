Python：从小白到资深工程师

Python 是可读性极强、用途极广的动态语言，是 AI/数据科学/自动化/后端的首选。本教程从“写脚本”讲到解释器与 GIL、类型系统、装饰器、并发模型（asyncio/多进程）、性能与包管理——这是资深 Python 工程师的分水岭。

1. 它解决什么问题

相比 Java/C 的仪式代码，Python 用缩进表达结构、变量无需声明类型，几行就能实现想法。代价是解释执行、运行时不强制类型。

一句话：Python 用“开发速度”换“运行速度”——适合快速验证、胶水逻辑、AI/数据；性能热点再下沉到 C 扩展或换语言。
适合：AI/ML、数据分析、自动化、Web 后端（FastAPI/Django）、运维脚本。
不适合：对延迟/吞吐极致敏感的核心路径（用 C/Java 或 Rust）。

2. 工程化起步

python -m venv venv        # 虚拟环境，隔离依赖
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
  • Python 3.10+；用 uv/poetry 替代裸 pip 做依赖解析与锁文件。
  • 项目用 pyproject.toml 声明元数据与依赖（PEP 621）。

3. 解释器与 GIL

默认实现 CPython（C 写）。它有 GIL（全局解释器锁）：同一进程内任意时刻只有一个线程在执行 Python 字节码。

GIL 真相：多线程只能并发（交替）不能并行 CPU 任务 → CPU 密集用 multiprocessing 或多进程；IO 密集多线程仍有效（等待时释放 GIL）。异步 asyncio 用单线程事件循环扛高 IO 并发。

4. 数据结构

squares = [x*x for x in range(10)]          # 列表推导式
gen = (x*x for x in range(10))              # 生成器：惰性、省内存
# 迭代器协议：__iter__ / __next__，for 循环底层即用它
  • 推导式比手写的 for 更可读更快；生成器处理流式/大数椐不爆内存。
  • dict/set 基于哈希（O(1) 平均）；list 是动态数组。

5. 函数进阶

def log(fn):                 # 装饰器：不改动原函数加功能
  def wrap(*args, **kwargs):
    print("call", fn.__name__)
    return fn(*args, **kwargs)
  return wrap
  • 函数是一等公民（可传参/返回）；*args/**kwargs 收集位置/关键字参数。
  • 闭包捕获外层变量；装饰器是“函数包装函数”，用于日志/缓存/鉴权。

6. 类型系统

def add(a: int, b: int) -> int:
  return a + b
  • 类型提示是渐进式：运行时不做检查，靠 mypy/pyright 静态查错。
  • 大型项目必上类型——把“运行才暴露”的错提前到编译期。

7. 面向对象

  • @dataclass 自动生成 __init__/__repr__/__eq__，少写样板。
  • __slots__ 限制属性、省内存（禁动态添加）。
  • 多继承有 MRO（方法解析顺序），super() 按 C3 线性化调用。
  • 上下文管理器 with + __enter__/__exit__，资源自动释放。

8. 并发模型

场景选型
CPU 密集multiprocessing（绕过 GIL）
IO 密集（高并发连接）asyncio（单线程事件循环）
混合多进程 + 异步/线程池
import asyncio
async def main():
  await asyncio.gather(fetch(1), fetch(2))   # 并发 IO

9. 性能

  • 用 cProfile 找热点；纯 Python 循环慢 → 向量化（numpy）或下沉 C（cython/Rust 扩展）。
  • 避免在大循环里反复创建对象；用 __slots__、局部变量提速。

10. 包管理

  • pip 装包；requirements.txt 或 pyproject.toml 管依赖。
  • 用 uv/poetry 做锁版本与可复现构建；私仓可配 --index-url。

11. 常见坑

坑 1：可变默认参数 def f(x=[]) 跨调用共享 → 用 x=None。
坑 2：闭包延迟绑定（循环里 lambda 捕获同一变量）→ 用默认参数固化。
坑 3：== 比内容、is 比对象身份；小整数/字符串有缓存别依赖 is。
坑 4：变量遮蔽（局部名盖了内置 list/open）→ 别用内置名当变量。
坑 5：裸 except: 吞掉所有异常（含 KeyboardInterrupt）→ 用 except Exception。
坑 6：全局装包污染 → 永远用虚拟环境。

12. 调试诊断

  • pdb 断点；cProfile/line_profiler 找热点；logging 结构化日志。
  • 性能火焰图（py-spy）在线采样，不改动代码。
