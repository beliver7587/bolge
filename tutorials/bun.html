Bun + Elysia

更快的 JS 运行时 + 轻量后端框架 —— 网页游戏前端用它构建、后端也用它跑。

1. 这是什么

Bun 是近年兴起的 JavaScript 运行时，定位是 Node 的“更快替代”：启动快、内置打包/测试、兼容 npm 生态。Elysia 是构建在 Bun 之上的极简、高性能后端框架，API 风格类似 Express 但类型更优雅。

2. 为什么比 Node 快

维度BunNode
底层引擎JavaScriptCore（Safari 同款）V8（Chrome 同款）
启动极快较快
内置能力打包/测试/运行一体需额外工具

3. 第一个服务

// 直接用 Bun 跑，不用装框架
Bun.serve({
  port: 3000,
  fetch(req) {
    return new Response("Hello from Bun!");
  }
});

4. Elysia 框架

import { Elysia } from 'elysia';
new Elysia()
  .get('/hello', () => ({ msg: '你好' }))
  .listen(3000);
亮点：Elysia 的路由返回值自动序列化成 JSON，且类型推导强，写 API 很省心。

5. 常见坑

坑 1：个别 Node 原生模块（如 isolated-vm）在 Bun 下不兼容——必要时混用 Node（网页游戏项目就是 Bun + Node 务实并存）。
坑 2：生产用 Bun 跑长驻服务，先确认稳定性；不确定就用 Node。
坑 3：Windows 上 Bun 仍在完善，建议 Linux/macOS 开发。
