PM2 进程守护

Node 程序的“保姆” —— 崩溃自启、开机启动、看日志，游戏服务靠它常驻。

1. 这是什么

PM2 是 Node.js 的进程管理器（也支持 Bun/Python 等）。你关掉终端、程序崩了、服务器重启，它都能让服务“活着”——崩溃自动重启、开机自动启动、随时看日志。

2. 为什么需要

痛点：直接 node server.js 跑，关掉终端程序就死；崩了不会自己起。PM2 解决这所有问题，是部署 Node 服务的标配。

3. 常用命令

npm i -g pm2
pm2 start server.js --name game      # 启动并命名
pm2 list                             # 看所有进程状态
pm2 logs game                        # 看某个进程日志
pm2 restart game                     # 发版后重启
pm2 save                             # 存档进程列表（开机恢复用）

4. 开机自启

pm2 startup      # 按提示执行它生成的命令
pm2 save         # 之后重启服务器会自动拉起

5. 常见坑

坑 1：忘记 pm2 save，服务器重启后服务没起来。
坑 2：用 root 跑服务不安全——生产建议普通用户降权运行。
坑 3：日志无限增长占满磁盘——配日志轮转或定期清理。
替代：更“正规”的方案是 systemd 托管。
