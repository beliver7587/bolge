React

用“组件”拼出界面的前端库 —— 简历工坊、网页游戏、Memora 前端都基于 React 生态。学完本节，你能独立用 React 写一个带状态的小应用。

1. 这是什么

React 是 Facebook 开源的前端 JavaScript 库，用来构建用户界面。它的核心思想一句话总结：

一句话：把页面拆成一个个可复用的组件，你只描述“界面长什么样”，数据变了 React 自动把界面更新成对的样子。你不用手动操作 DOM。

为什么要用它？

  • 不用手抖 DOM：传统写法是 document.getElementById(...).innerHTML = ...，状态一多就乱。React 让你写 return <h1>{title}</h1>，数据 title 变了界面自动变。
  • 组件复用：一个 <Button/> 可以到处用，改一处全站生效。
  • 生态最大：路由、状态管理、UI 库（Ant Design）、服务端渲染（Next.js）一应俱全。
  • 需求多：招聘市场上 React 岗位最多，学会它能直接找前端工作。
适合：中后台系统、数据看板、单页应用（SPA）、移动端（React Native）。
不适合：纯静态展示页（直接写 HTML 更简单）、超轻量小工具（引入 React 体积偏大）。

2. 环境准备

React 项目需要 Node.js 来跑开发服务器和打包。跟着下面 4 步走：

1

安装 Node.js（含 npm）

去 nodejs.org 下载 LTS 版本（如 20.x），一路下一步安装。装完自带 npm（包管理器）。

2

验证安装

打开终端（Win 用 PowerShell / Mac 用终端），输入：

node -v      # 应输出 v20.x 之类
npm -v       # 应输出 9.x / 10.x 之类

能看到版本号就成功了。

3

用 Vite 创建项目

Vite 是现在最主流的构建工具（快）。在你想放项目的文件夹里执行：

npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install

第一句会问你“Ok to proceed?”，回车即可；--template react 表示用 React 模板。第二、三句进入目录并安装依赖（首次会下载几十秒）。

4

认识目录

my-react-app/
├─ index.html        # 页面入口，里面有个 <div id="root">
├─ package.json      # 项目信息 + 依赖列表
├─ vite.config.js    # Vite 配置
└─ src/
   ├─ main.jsx       # 把 React 挂到 #root 上
   ├─ App.jsx        # 最顶层组件（从这里开始写）
   └─ index.css      # 全局样式

3. 跑起第一个项目

在 my-react-app 目录里执行：

npm run dev

终端会打印一个本地地址，通常是 http://localhost:5173。浏览器打开它，看到 Vite 的欢迎页就成功了。

试手：打开 src/App.jsx，把里面的文字改一下，保存，浏览器会自动刷新——这就是“热更新”，开发体验拉满。

以后常用命令：

命令作用
npm run dev本地开发（带热更新）
npm run build打包到 dist/，用于上线部署
npm run preview本地预览打包后的结果

4. 核心概念

① 组件（Component）

组件就是一个返回 JSX 的函数。文件名以大写开头（App.jsx、Button.jsx），这样 React 才知道它是组件而不是普通标签。

// src/App.jsx
function App() {
  return <h1>你好，React</h1>;
}
export default App;

② JSX

把 HTML 写进 JS 的语法糖。注意：

  • JSX 里写 JS 表达式要用 {} 包起来，比如 <p>{1 + 1}</p> 显示 2。
  • class 要写成 className（因为 class 是 JS 关键字）。
  • 标签必须闭合：<img />、<br />。

③ Props（父传子的数据）

Props 像函数的入参，只读。父组件传，子组件收：

function Welcome({ name }) {        // 解构 props
  return <h2>你好，{name}</h2>;
}
// 使用：<Welcome name="小王" />

④ State（组件自己的数据）

State 是可变的内部数据，变了会触发重渲染。用 useState：

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);   // [值, 改值的函数]
  return (
    <div>
      <p>点击了 {count} 次</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}
关键：不能直接改 state（count++ 无效），必须用 setCount 传“新值”，React 才会重画。

5. 事件 / 列表 / 条件

事件处理

React 事件用驼峰：onClick、onChange、onSubmit，值是函数。

列表渲染 + key

用 map 把数组变成组件列表，每个子项必须带唯一 key（帮 React 识别增删）。

const list = ['苹果', '香蕉', '橙子'];
<ul>
  {list.map((item, i) => <li key={i}>{item}</li>)}
</ul>
坑：用数组下标 i 当 key 只在“列表不增删”时安全；会增删排序时请用稳定 ID（如 item.id）。

条件渲染

{isLogin ? <UserPanel /> : <LoginForm />}
{showTip && <p>这是提示</p>}

6. 副作用 useEffect

组件里“不是渲染”的事（请求接口、定时器、监听）叫副作用，放进 useEffect。

import { useState, useEffect } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  useEffect(() => {
    // 组件挂载后执行一次：拉取数据
    fetch('/api/users')
      .then(r => r.json())
      .then(setUsers);
  }, []);   // 第二个参数 [] = 只在挂载时跑一次

  return <ul>{users.map(u => <li key={u.id}>{u.name}</li>)}</ul>;
}
坑：依赖数组 [] 里要写全用到的外部变量，否则闭包拿到旧值。比如依赖 userId 就要写成 [userId]，它会随 userId 变化重新请求。

7. 表单与受控组件

React 里输入框的值由 state 控制，叫“受控组件”：

function NameForm() {
  const [name, setName] = useState('');
  return (
    <form onSubmit={(e) => { e.preventDefault(); alert('提交：' + name); }}>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <button type="submit">提交</button>
    </form>
  );
}
要点：onChange 把输入同步到 state；e.preventDefault() 阻止表单默认刷新页面。

8. 样式的 3 种写法

方式写法适合
普通 CSSimport './App.css' + className传统、可控
内联 style动态值（如进度条宽度）
CSS Modulesimport s from './App.module.css'避免类名冲突
新手建议：先用普通 CSS 文件 + className，最直观。想提速可上 Tailwind 或 Ant Design。

9. 实战：Todo 清单（完整可运行）

下面这个项目把上面所有知识点串起来：添加、删除、标记完成、统计。把 src/App.jsx 整个替换成下面的代码即可运行。

import { useState } from 'react';

function App() {
  const [text, setText] = useState('');
  const [todos, setTodos] = useState([]);

  const add = () => {
    const t = text.trim();
    if (!t) return;                       // 空内容不添加
    setTodos([...todos, { id: Date.now(), text: t, done: false }]);
    setText('');                          // 清空输入框
  };

  const toggle = (id) =>
    setTodos(todos.map(t => t.id === id ? { ...t, done: !t.done } : t));

  const remove = (id) => setTodos(todos.filter(t => t.id !== id));

  const left = todos.filter(t => !t.done).length;

  return (
    <div style={{ maxWidth: 420, margin: '40px auto', fontFamily: 'sans-serif' }}>
      <h1>📝 我的待办</h1>
      <div>
        <input
          value={text}
          placeholder="写点什么…"
          onChange={(e) => setText(e.target.value)}
          onKeyDown={(e) => e.key === 'Enter' && add()}
        />
        <button onClick={add}>添加</button>
      </div>

      <ul>
        {todos.map(t => (
          <li key={t.id} style={{ margin: '8px 0' }}>
            <span
              onClick={() => toggle(t.id)}
              style={{
                cursor: 'pointer',
                textDecoration: t.done ? 'line-through' : 'none',
                color: t.done ? '#999' : '#000'
              }}>
              {t.text}
            </span>
            <button onClick={() => remove(t.id)} style={{ marginLeft: 10 }}>删除</button>
          </li>
        ))}
      </ul>

      <p>还剩 {left} 项未完成，共 {todos.length} 项</p>
    </div>
  );
}
export default App;
运行：保存后浏览器自动刷新，输入文字回车或点“添加”即可。你已经用 React 写了一个真实可用的小应用！

10. 常见坑

坑 1：直接改 state 不生效：count++ 不行，必须 setCount(count+1)。改对象/数组也要“先拷贝再改”：setUser({...user, age: 18})。
坑 2：列表忘了 key：用 map 渲染时每个子项要带唯一 key，否则增删错乱、控制台报警告。
坑 3：useState 是“异步”的：连续 setCount(count+1) 两次并不会 +2，因为两次用的都是旧 count。正确做法用函数式更新：setCount(c => c+1)。
坑 4：useEffect 死循环：依赖数组里放了每次渲染都变的对象/数组，导致反复执行。把依赖写成基本类型，或把函数用 useCallback 包起来。
坑 5：在 useEffect 里发请求没做清理，组件卸载后 setState 报错。加 return 清理函数或用“已取消”标记。
坑 6：忘记 import：用了 useState 却没 import { useState } from 'react'，会报“未定义”。
坑 7：{} 里不能直接写语句（如 if），只能写表达式。要用分支就用三元 ? : 或 &&。
坑 8：把 onClick={handleClick()} 写成调用（带括号），会“渲染时就执行一次”。应写 onClick={handleClick} 或 onClick={() => handleClick()}。

11. 调试与生态

  • React DevTools：Chrome 装扩展，能看到组件树和每个组件的 state/props，调试神器。
  • 报错看栈：React 报错信息现在很友好，点链接能跳到出错组件。
  • 路由：多页面用 react-router-dom。
  • 状态管理：组件多了、跨页面共享数据用 Zustand（轻量）或 Redux。
  • UI 库：不想自己写样式就用 Ant Design。
