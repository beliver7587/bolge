Git

代码版本控制系统 —— 记录每次改动、随时回退、多人协作不打架。程序员必备。学完你能独自管理版本并与他人协作。

1. 这是什么

Git 给项目建一个“时光机”：每次提交（commit）存下完整快照，可随时回到任意版本。配合 GitHub 还能多人协作、备份到云端。

对比：网盘/U盘只存最新版；Git 存全部历史，且能并行开发（分支）。

2. 环境准备

装 Git（Windows 装 Git for Windows；Mac brew install git；Linux apt install git）。配置身份：

git config --global user.name "你的名字"
git config --global user.email "you@example.com"

3. 第一个仓库

cd my-project
git init                 # 初始化仓库
echo "# 我的项目" > README.md
git add README.md
git commit -m "首次提交"

4. 提交与查看

git status               # 看哪些文件改了
git add -A               # 暂存全部改动
git commit -m "改了首页"
git log --oneline        # 看历史

5. 分支

git branch feature       # 建分支
git checkout feature     # 切过去
# 改完合并回主分支
git checkout main && git merge feature
要点：分支让你并行试错，不污染主线；开发完再合并。

6. 远程协作

git remote add origin https://github.com/你/仓库.git
git push -u origin main     # 推到 GitHub
git pull                    # 拉取他人改动

7. 常见坑

坑 1：提交前没 git add，改动没进版本；先 add 再 commit。
坑 2：git push 被拒（远程有别人提交）；先 git pull 再推。
坑 3：把密钥/.env 提交进仓库泄露；用 .gitignore 排除。
坑 4：强推 git push --force 覆盖他人历史；非必要时禁用。

8. 下一步

  2. 学 Docker 打包环境。
