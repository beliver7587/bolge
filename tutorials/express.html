Express

Node.js 最经典的 Web 框架 —— 极简、灵活，几行代码写一个 REST API。Memora 后端就用它。学完你能独立写后端接口。

1. 这是什么

Express 是 Node.js 的 Web 框架，在原生 http 之上封装了简洁的路由、中间件机制。

一句话：原生 http 写接口很啰嗦；Express 让你 app.get('/x', ...) 一句话搞定路由。
适合：REST API、BFF、中小型后端。轻量、自由；需要更多功能自己加中间件。

2. 环境准备

已装 Node.js。建项目：

mkdir my-api && cd my-api
npm init -y
npm install express

3. 第一个服务

import express from 'express';
const app = express();
app.get('/', (req, res) => res.send('你好 Express'));
app.listen(3000, () => console.log('http://localhost:3000'));

保存为 server.js，node server.js 后访问即可。

4. 路由

app.get('/users', (req, res) => res.json([{id:1, name:'小王'}]));
app.get('/users/:id', (req, res) => res.json({ id: req.params.id }));
app.post('/users', (req, res) => res.status(201).json(req.body));
app.put('/users/:id', ...);
app.delete('/users/:id', ...);

5. 中间件

中间件是“请求到达路由前/后执行的函数”，用来做日志、鉴权、错误处理。

app.use((req, res, next) => {
  console.log(req.method, req.url);   // 日志
  next();                            // 放行到下一个
});

6. 解析请求体

app.use(express.json());        // 解析 JSON 请求体
app.post('/users', (req, res) => {
  const { name } = req.body;   // 直接用
  res.json({ ok: true, name });
});

7. 实战：待办 API

let todos = [];
app.get('/todos', (req, res) => res.json(todos));
app.post('/todos', (req, res) => {
  const t = { id: Date.now(), text: req.body.text, done: false };
  todos.push(t);
  res.status(201).json(t);
});
app.delete('/todos/:id', (req, res) => {
  todos = todos.filter(t => t.id != req.params.id);
  res.json({ ok: true });
});
练手：用 Postman 或前端 React 调这些接口，就是一个最小后端。

8. 常见坑

坑 1：忘了 express.json()，req.body 是 undefined。
坑 2：中间件顺序错：next() 没调用导致请求挂起；路由要在中间件之后注册（或放在合适顺序）。
坑 3：用了 ES Module（"type":"module"）却 const express = require('express')，混用报错；统一用 import。
坑 4：跨域（前端 3000 调后端 4000）被浏览器拦截；加 cors 中间件 npm i cors。
坑 5：没处理异常，出错返回 500 且进程可能崩；用错误中间件 app.use((err,req,res,next)=>...)。
