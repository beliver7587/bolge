CSS

层叠样式表 —— 给 HTML 穿上“皮肤”：颜色、间距、布局、动画。学完你能把丑页面变好看、把元素摆到位。

1. 这是什么

CSS 用“选择器 + 声明”控制外观：h1 { color: red; } 表示所有 h1 文字变红。它和 HTML（结构）、JS（行为）三足鼎立。

现代写法：原子化如 Tailwind 直接用类名；传统写法则写在 .css 文件里。

2. 环境准备

同样无需安装。在 HTML 里用 <link rel="stylesheet" href="style.css"> 引入，或写 <style> 内联。

3. 第一个样式

<style>
  body { font-family: sans-serif; background: #0f1424; color: #fff; }
  .card { padding: 16px; border-radius: 12px; background: #1a2138; }
</style>
<div class="card">我是一个卡片</div>

4. 选择器

写法含义
.class类选择器
#idID 选择器
div p后代选择器
a:hover悬停状态

5. 盒模型

每个元素是个盒子：内容 + 内边距(padding) + 边框(border) + 外边距(margin)。设 box-sizing: border-box 让尺寸更可控。

6. Flex 布局

.row { display: flex; gap: 12px; justify-content: center; align-items: center; }
要点：Flex 是一维布局神器；二维网格用 grid。响应式用 @media 适配手机。

7. 常见坑

坑 1：忘记 box-sizing: border-box，宽度算错导致换行。
坑 2：用 float 做整体布局（已淘汰）；用 Flex/Grid。
坑 3：样式被覆盖（层叠优先级）；ID > 类 > 标签，内联最高。
坑 4：单位混用，移动端错位；多用 rem/%/vw。

8. 下一步

  2. 学 Tailwind 原子化加速。
  3. 练 Flex/Grid 布局。
