Ant Design：从小白到企业级组件

Ant Design（antd）是蚂蚁出品的企业级 React 组件库：表单、表格、弹窗、布局一应俱全，自带设计语言。本教程讲清它怎么提效、主题怎么改、以及与体积/样式的常见冲突怎么解。

1. 它解决什么问题

每个项目都在重复造 Button、Modal、Table、分页、日期选择……不仅慢，还多团队视觉不一致、可访问性参差不齐。

一句话：antd 把“成熟的企业级 UI 组件 + 统一设计语言”打包好，你只拼业务，不用纠结像素与交互细节。
适合：中后台、管理控制台、表单密集应用。不适合：追求高度定制的营销页、品牌极强的 C 端产品（改造成本高）。

2. 工程化起步

1

安装

npm i antd           # v5 自带 CSS-in-JS，无需引 CSS 文件
npm i @ant-design/icons  # 图标
2

用起来

import { Button, DatePicker } from 'antd';
import dayjs from 'dayjs';   // antd v5 用 dayjs 而非 moment
export default () => <Button type="primary">提交</Button>;

3. 设计令牌

antd 用 Design Token（CSS 变量）描述颜色/圆角/阴影。改主题就是改这些 token，全站统一生效。

资深做法：用 token 定义品牌色、圆角、字体，团队所有页面共用一套，避免“每个人手调颜色”。

4. 核心组件

  • Button：type（primary/default/dashed/link）、loading、size。
  • Input / Select / DatePicker：受控值 + onChange。
  • Modal：确认框、表单弹窗。
  • Message / Notification：全局反馈。
<Select options={[{value:'a',label:'A'}]} onChange={v=>...} />

5. 表单与校验

const [form] = Form.useForm();
<Form form={form} onFinish={save}>
  <Form.Item name="email" rules={[{required:true,type:'email'}]}>
    <Input />
  </Form.Item>
  <Button htmlType="submit">提交</Button>
</Form>
坑：antd Form 是托管受控的——不要自己再 value/onChange 包 Input，交给 Form.Item 即可，否则冲突。

6. Table 表格

<Table rowKey="id" dataSource={list} columns={[
  { title:'名称', dataIndex:'name' },
  { title:'操作', render:(_,r)=><Button>编辑</Button> },
]} pagination={{ pageSize:10 }} />
  • columns 声明列；render 自定义单元格。
  • 分页、排序、筛选开箱即用；大数据用 scroll + 虚拟滚动。

7. 主题定制

import { ConfigProvider, theme } from 'antd';
<ConfigProvider theme={{ token:{ colorPrimary:'#5b8cff', borderRadius:8 },
  algorithm: theme.darkAlgorithm }}>
  <App />
</ConfigProvider>
暗色模式：一行 theme.darkAlgorithm 全局切换，不必自己写两套样式。

8. 按需与体积

  • v5 用 CSS-in-JS，没有全量 CSS 文件，按使用组件动态注入样式。
  • 图标要按需引入具体图标，避免全量打包。
  • 体积大头在组件本身；非必要别整站引入，配合路由拆包。

9. 布局 Layout

<Layout><Layout.Sider>菜单</Layout.Sider>
  <Layout><Layout.Header/><Layout.Content>页面</Layout.Content></Layout>
</Layout>

Layout 提供 Sider/Header/Content/Footer 标准中后台骨架。

10. 国际化

import zhCN from 'antd/locale/zh_CN';
<ConfigProvider locale={zhCN}>…</ConfigProvider>

内置多语言包，切换 locale 即可。

11. 常见坑

坑 1 v4→v5 差异：v5 去 CSS 文件、改用 dayjs、主题用 token。老项目升级要对照迁移指南。
坑 2 样式污染：和全局 CSS/reset 冲突时，用 ConfigProvider 的 cssVar 或调优先级。
坑 3 受控冲突：Form.Item 已托管，别再给子组件加 value。

12. 与 Tailwind

两者可共存：Tailwind 管布局/间距，antd 管复杂交互组件。注意 className 优先级与 reset 冲突，建议用 antd 的 token 而非 Tailwind 改组件内部。

13. 最佳实践

  • 用 ConfigProvider 统一主题与 locale。
  • 复杂表单交给 antd Form，别手写受控。
  • 表格分页/排序用内置，少造轮子。

14. 资源与路线

  1. 官方站点 ant.design（组件示例齐全）。
  2. 先学 React 受控/表单概念。
  3. 练：用 Layout + Form + Table 搭一个带增删改查的管理页。
资深标志：能用 token 建立团队设计系统、规避样式冲突、把 antd 当“积木”而非“黑盒”——出了问题知道往哪改。
