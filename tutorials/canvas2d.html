Canvas 2D

浏览器原生 2D 绘图 API —— 土豆勇士用它零依赖画游戏画面。

1. 这是什么

<canvas> 是 HTML 里一块“画布”，配合 2D 绘图上下文（Context），你可以用代码画矩形、圆、文字、图片，甚至做动画。它不依赖任何库，是最轻量的绘图方案。

对比：Canvas 用 CPU 画，适合简单场景；大量精灵/高帧率游戏用 PixiJS(WebGL) 更好。

2. 画第一笔

<canvas id="cv" width="400" height="300"></canvas>
<script>
  const cv = document.getElementById('cv');
  const ctx = cv.getContext('2d');        // 拿到画笔
  ctx.fillStyle = '#5b8cff';              // 颜色
  ctx.fillRect(50, 50, 120, 80);          // 画一个矩形 (x,y,宽,高)
  ctx.beginPath();
  ctx.arc(250, 100, 40, 0, Math.PI*2);    // 画个圆
  ctx.fill();
</script>

3. 动画循环

每帧清屏→重画，就成动画。用 requestAnimationFrame 跟随屏幕刷新：

let x = 0;
function loop(){
  ctx.clearRect(0,0,400,300);     // 先清屏
  ctx.fillRect(x, 100, 30, 30);   // 画方块
  x = (x + 2) % 400;              // 移动
  requestAnimationFrame(loop);     // 下一帧继续
}
loop();

4. 监听输入

canvas.addEventListener('mousemove', e => {
  const r = canvas.getBoundingClientRect();
  const mx = e.clientX - r.left, my = e.clientY - r.top;  // 画布内坐标
});
手机端：把 mousemove 换成 touchmove，用 e.touches[0].clientX 取手指坐标（土豆勇士的摇杆就是这么做的）。

5. 常见坑

坑 1：canvas 的 width/height 是“画布像素”，CSS 的宽高是“显示大小”，二者不一致会模糊——建议用 JS 按 DPR 设置。
坑 2：忘记 clearRect，旧画面会叠加成一团。
坑 3：频繁创建对象（如每帧 new Image）会 GC 卡顿，图片要预加载复用。
