Memory：从小白到 AI 记忆

Memory（记忆）让 大模型 应用跨轮对话保持上下文、记住用户偏好。Memora 的“四层记忆”就是典型实现。本教程讲清记忆分层与实现取舍。

1. 它是什么

LLM 本身无状态，每次调用都只是“一段文本”。记忆就是把这些状态（对话历史、用户画像、事实）存起来，下次再喂回模型。

一句话：Memory = 给无状态的 LLM 加“上下文仓库”。让它显得“记得你”。

2. 记忆的类型

类型作用例子
短期/会话当前对话历史这轮聊了什么
长期/用户跨会话的用户画像偏好、姓名
工作记忆本次任务的中间结论Agent 的待办

3. 实现方式

  • 会话历史：直接把 messages 存库，按会话取。
  • 向量记忆：把长期事实 Embedding 入向量库，需要时检索相关片段。
  • 摘要记忆：历史过长时让 LLM 总结，压缩成短上下文。
  • 结构化：用户画像存成字段（JSON），便于精确读取。

4. 与 RAG 的区别

RAG 是“外部知识库检索”（面向文档），Memory 是“关于用户/会话的状态”（面向交互）。二者常结合：检索知识 + 记住用户。

Memora 做法：四层记忆 = 短期（本轮）+ 长期（用户）+ 知识（RAG）+ 工作（任务），分层管理。

5. 常见坑

坑 1 上下文溢出：历史越攒越长，超 LLM 窗口；用摘要/检索裁剪。
坑 2 隐私：记忆里可能含敏感信息，要加密、可删除（合规）。
坑 3 记忆污染：错误/被注入的内容记下来会持续影响；写前校验。

6. 资源与路线

  1. LangChain Memory、MemGPT 思路。
  2. 配合 RAG、Agent、Embedding。
  3. 练：给聊天机器人加“记住用户名”的长期记忆。
资深标志：能用分层记忆把“上下文管理”做对——既不溢出也不丢关键信息，并处理好隐私与删除。
