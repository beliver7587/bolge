Function Calling

让大模型“点名要调用哪个函数、传什么参数” —— 把 AI 接到真实世界（查库、发消息、算账）。Agent 的手脚就是它。学完你能让 AI 真正执行动作。

1. 这是什么

Function Calling 是大模型的一项能力：你告诉它有哪些函数可用（名称、用途、参数格式），它根据用户意图返回“该调哪个、参数是什么”，由你来执行并回传结果。

一句话：模型不直接执行，而是“开单据”（要调 A 函数、参数 x），你按单据办事再把结果告诉它。

2. 核心流程

你：系统提示 + 工具清单 + 用户问题 │ ▼ 模型：返回 tool_calls（要调的函数与参数） ← 而非直接回答 │ ▼ 你：在代码里执行该函数 → 得到结果 │ ▼ 你：把结果作为 tool 角色消息回传模型 │ ▼ 模型：结合结果给出最终自然语言答案

3. 定义工具

const tools = [{
  type: 'function',
  function: {
    name: 'getWeather',
    description: '查询指定城市的当前天气',
    parameters: {
      type: 'object',
      properties: { city: { type: 'string', description: '城市名' } },
      required: ['city']
    }
  }
}];

4. 调用与执行

const res = await client.chat.completions.create({
  model: 'gpt-4o-mini',
  messages,
  tools,                 // 把工具清单交给模型
  tool_choice: 'auto'
});
const tc = res.choices[0].message.tool_calls?.[0];
if (tc) {
  const args = JSON.parse(tc.function.arguments);
  const result = await getWeather(args.city);   // 你执行
  messages.push(res.choices[0].message);        // 先存模型的 tool_calls 消息
  messages.push({ role:'tool', tool_call_id: tc.id, content: result });
  const final = await client.chat.completions.create({ model, messages });  // 再问一次得答案
}

5. 实战

用户说“北京天气怎么样”→ 模型返回 getWeather({city:'北京'}) → 你查到“晴 25℃” → 回传 → 模型答“北京今天晴，25 度，适合出门”。整套就是 Agent 的基本动作。

6. 常见坑

坑 1：参数 JSON 解析失败；用 try/catch，并让模型重新生成。
坑 2：忘记把模型的 tool_calls 消息原样存回 messages，导致后续请求缺上下文报错。
坑 3：工具 description 写不清，模型乱调；描述要像“给同事看的说明书”。
坑 4：工具执行慢/超时拖垮对话；加超时与降级。
坑 5：忽视权限与 提示注入防护，模型可能被诱导调用危险工具。

7. 下一步

  1. 定义一个工具并跑通“问天气”。
  2. 学 Agent 把多个工具串联。
  3. 学 四层记忆 让 Agent 记住上下文。
  4. 看 Memora，Function Calling 实战。
毕业：能定义工具、解析 tool_calls、执行并回传——把 AI 接到真实世界，你已掌握。
