Express：从小白到 Node Web 框架

Express 是最经典的 Node.js Web 框架，用中间件 + 路由写接口。Memora 的 REST 与 SSE 流式都基于它。本教程讲清中间件模型、路由与错误处理——这是 Node 后端的事实标准。

1. 它是什么

Express 在 Node 原生 http 之上提供：路由、中间件管道、便捷的请求/响应对象。它“极简”，把组织逻辑的自由留给你。

一句话：Express = 路由 + 中间件 + 轻量封装。小而灵活，生态成熟。

2. 工程化起步

import express from 'express';
const app = express();
app.use(express.json());            // 解析 JSON 请求体
app.listen(3000, () => console.log('up'));
坑：忘了 express.json()，req.body 是 undefined。

3. 路由

app.get('/api/users/:id', (req, res) => {
  res.json({ id: req.params.id });
});
app.post('/api/login', (req, res) => { /* req.body */ });
  • 方法 get/post/put/delete 对应 REST。
  • req.params 路径参数，req.query 查询参数。

4. 中间件

中间件是“请求处理流水线上的函数”，签名 (req,res,next)：

app.use((req, res, next) => {          // 全局中间件
  console.log(req.method, req.url);
  next();                              // 放行到下一个
});
资深：鉴权、日志、CORS 都做成中间件；顺序很重要——先解析 body，再路由。

5. 请求与响应

  • req.body / params / query / headers 拿输入。
  • res.json() / res.send() / res.status().json() 返回。
  • res.setHeader 或 res.cookie 控制响应头/ cookie。

6. 错误处理

app.use((err, req, res, next) => {     // 4 参中间件 = 错误处理器
  res.status(err.status || 500).json({ msg: err.message });
});

业务里 next(err) 把错误抛给统一处理器。

7. 静态文件

app.use(express.static('public'));  // 托管 public/ 下静态资源

8. 安全加固

  • helmet：加安全响应头。
  • cors：控制跨域（前端 React 调用时配）。
  • express-rate-limit：防刷/防爆破。

10. 常见坑

坑 1 忘 json 解析：见第 2 节。
坑 2 异步错误未捕获：async 路由里 throw 不会进错误中间件，要用 try/catch 或包装。
坑 3 中间件顺序：错误处理中间件必须放最后。

完整流程：Express 搭 API 服务

1. 初始化
npm init -y
npm install express cors helmet morgan
2. 写路由
const app = express();
app.use(express.json());
app.get('/api/users', (req,res)=>{ res.json([{id:1,name:'Tom'}]); });
app.post('/api/users', (req,res)=>{ const u = req.body; ... });
app.listen(3000);
3. 中间件
app.use('/api', authMiddleware);  // 鉴权
app.use(errorHandler);            // 统一错误处理
要点：路由分层到 routes/；错误处理中间件要放最后。
