Zustand

极简的 React 状态管理库 —— 三个项目都用它管全局状态。

1. 这是什么

当多个组件要共享同一份数据（比如“当前登录用户”“购物车”），就需要“状态管理”。Zustand（德语“状态”）是一个极轻量的方案：一个 store 存全局状态，任何组件直接读、直接改，没有 Provider 包裹、没有样板代码。

2. 为什么不用 Redux

对比：Redux 要写 action、reducer、dispatch，样板代码多；Zustand 一个 create 搞定，心智负担小，中小项目首选。

3. 创建 Store

import { create } from 'zustand';

const useStore = create((set) => ({
  count: 0,
  user: null,
  inc: () => set((s) => ({ count: s.count + 1 })),
  setUser: (u) => set({ user: u }),
}));
要点：set 用来更新状态；函数（如 inc）也定义在 store 里，组件调用即可。

4. 在组件里用

function Counter(){
  const count = useStore(s => s.count);   // 只订阅 count
  const inc = useStore(s => s.inc);
  return <button onClick={inc}>{count}</button>;
}
性能技巧：用选择器 s => s.count 只取需要的字段，其它字段变了不会触发本组件重渲染。

5. 常见坑

坑 1：把整个 store 解构成对象 const {count} = useStore() 会让组件在“任何状态变化”时都重渲染——记得用选择器。
坑 2：异步数据：在 action 里 await 后再 set，不要直接返回 Promise 当状态。
坑 3：SSR（Next.js）要注意 store 是全局单例，可能跨请求串数据——可用 createStore 每请求新建。
