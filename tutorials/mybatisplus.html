MyBatis-Plus

MyBatis 的增强工具 —— 不写 SQL 也能做 CRUD，单表操作效率翻倍。学完你能极简地操作数据库。

1. 这是什么

MyBatis-Plus（MP） 在 MyBatis 之上加了“开箱即用的通用 Mapper/Service”，单表 CRUD 不用写 XML、不用写 SQL。

一句话：MyBatis 要手写 SQL；MP 帮你把“增删改查”默认实现好，复杂 SQL 你再写。
适合：国内 Java 后端主流，尤其管理后台表单多、单表操作多的场景。

2. 环境准备

在 Spring Boot 项目里引入：

<dependency>
  <groupId>com.baomidou</groupId>
  <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
  <version>3.5.7</version>
</dependency>
<!-- 同时要有 MySQL 驱动，见 MySQL 教程 -->

3. 三步上手

1

实体类（对应表）

@TableName("user")
public class User {
  @TableId(type = IdType.AUTO) private Long id;
  private String name;
  private Integer age;
  // getter/setter 省略
}
2

Mapper 接口

public interface UserMapper extends BaseMapper<User> {
  // 不用写任何方法，CRUD 全在 BaseMapper 里
}
3

启动类加扫描

@MapperScan("com.example.demo.mapper")
@SpringBootApplication
public class DemoApplication { ... }

4. 增删改查

@Autowired UserMapper userMapper;

userMapper.insert(user);                 // 增
userMapper.selectById(1L);               // 查
userMapper.updateById(user);             // 改
userMapper.deleteById(1L);               // 删
userMapper.selectList(null);             // 查全部

5. 分页

先注册分页插件，再调用：

@Bean public MybatisPlusInterceptor mpInterceptor() {
  MybatisPlusInterceptor i = new MybatisPlusInterceptor();
  i.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
  return i;
}
// 使用
Page<User> page = userMapper.selectPage(new Page<>(1, 10), null);
page.getRecords();   // 本页数据
page.getTotal();     // 总条数

6. 条件构造器

QueryWrapper<User> w = new QueryWrapper<>();
w.gt("age", 18).like("name", "王").orderByDesc("id");
userMapper.selectList(w);

7. 常见坑

坑 1：忘了 @MapperScan，启动报找不到 Mapper Bean。
坑 2：字段名和数据库列名不一致导致 null，用 @TableField("col_name") 映射。
坑 3：主键自增没标 @TableId(type=IdType.AUTO)，插入报错。
坑 4：分页没加插件，selectPage 返回全部不分页。
坑 5：MP 版本与 Spring Boot 3 不匹配，用 mybatis-plus-spring-boot3-starter。
