RAG：从小白到资深

检索增强生成（RAG）让大模型“先查资料再回答”，解决幻觉、知识截止与私有数据问题——是 Memora 这类知识型 AI 的核心。本教程讲透两阶段架构、切块、混合检索与重排、提示接地、评估体系、生产与安全——这是做生产级 RAG 的硬功。

1. 它解决什么问题

大模型有两个硬伤：会编造（幻觉）和不懂你的私有/最新数据。RAG 把“知识”外置到检索系统，只让模型做“基于给定资料的生成”，从而可溯源、可更新。

对比微调：RAG 改知识只需更新文档，无需重训；微调改行为/风格。多数知识问答首选 RAG。
适合：企业知识库、客服、文档问答、法律/医疗辅助、带引用的助手。

2. 两阶段架构

离线建库：文档 → 切块 → 嵌入 → 入库（向量库 + 关键词索引） 在线问答：提问 → 改写 → 多路召回 → 融合/重排 → 组装 Prompt → LLM 生成（带引用）

两阶段解耦：建库是批量离线任务；问答是在线低延迟链路。组件包括分块器、检索器（向量 + BM25）、重排器、提示模板、生成模型。

3. 切块策略

切块质量直接决定召回上限：

  • 粒度：200~800 token 常见，带重叠（overlap）防边界信息丢失。
  • 结构感知：按标题/段落/表格边界切，优于硬按字数切；保留层级上下文（父块）。
  • 元数据：标题、来源、时间、权限——用于过滤与可解释。

4. 检索与重排

// 多路召回 + RRF 融合 + 重排
const vecHits = await vectorDB.search(qEmb, topK=20);
const bm25Hits = await bm25.search(q, topK=20);
const fused = rrf([vecHits, bm25Hits], k=60);     // 按排名融合，见 RRF
const reranked = await reranker.rerank(q, fused, topN=5);  // 精排取 top5
  • 混合检索：向量捕语义、BM25 捕精确词（型号/订单号），互补。
  • 重排（rerank）：用 cross-encoder 对召回结果二次精排，质量显著高于纯向量 topK。
  • 元数据过滤：先按权限/时间/来源缩窄，再语义召回。

5. 提示组装

const context = reranked.map((h,i)=>`[${i+1}] ${h.text}`).join('\n');
const prompt = `你是基于资料的助手，只根据下面带编号的资料回答，资料没有就如实说“不知道”。
禁止凭空编造。
资料：
${context}
问题：${question}`;
接地（grounding）约束：明确“仅依据资料、无则说不知道、禁止编造”，并让模型输出引用编号——既降幻觉又便于核查。

6. 生成与上下文窗口

  • 控制 topN 与块大小，避免超出模型上下文窗口或稀释重点。
  • 长上下文模型能塞更多资料，但“塞太多”反而降低注意力精度——精排比堆量更重要。

7. 评估体系

别只靠“看着像对”。用离线评测集量化：

  • 忠实度（faithfulness）：答案是否真能从资料推出（防编造）。
  • 答案相关性：是否切题。
  • 上下文召回率：正确答案所需资料是否进了 topK。
  • 框架参考 RAGAS；用 LLM-as-judge 做自动化评分。

8. 高级技巧

  • 查询改写/扩展：把口语问题改写成检索友好表述，或多查询覆盖不同角度。
  • 多跳检索：先召一小步、再基于结果二次检索，解决跨文档推理。
  • 父子块：检索用小块（精准），返回用大块（上下文完整）。

9. 生产要点

  • 延迟：检索+重排+生成链路要流式返回（见 SSE），别让用户干等。
  • 缓存：相同/相似问题缓存答案或检索结果，省成本降延迟。
  • 增量更新：文档变更重嵌受影响块，删旧块，避免脏召回。
  • 可观测：记录每次召回的命中与耗时，便于排障与评估。

10. 安全

检索内容也可能注入：若资料（尤其用户可投稿内容）里藏有“忽略上述指令…”的提示，可能劫持模型。要做输入净化、输出校验，详见 提示注入防护。

11. 常见坑

坑 1：切块不当 → 召回不准（按语义边界切）。
坑 2：只靠向量 → 精确词查不出 → 混合检索 + 重排。
坑 3：不约束“依据资料” → 模型仍编造。
坑 4：上下文超窗 → 控制 topN/块大小。
坑 5：文档更新后旧向量残留 → 脏召回。
坑 6：忽略检索内容注入 → 被恶意资料劫持。

12. 调试

  • 打印 topK 召回内容与相似度，看是否相关；用评测集跑忠实度/召回率。
  • 端到端 tracing（LangSmith 之类）定位是“召回错”还是“生成错”。

13. 成长路线

阶段能力标志
小白能搭“检索→拼Prompt→生成”链路
初级会切块、混合检索、约束提示
中级重排、评估体系、查询改写
资深生产调优、安全、指标驱动迭代
练习：① 搭一条含 BM25+向量+RRF 的检索 ② 加 rerank 看答案质量变化 ③ 用评测集算忠实度/召回率 ④ 在资料藏一句注入指令验证防护 ⑤ 做增量更新脚本。
你已进阶：理解 RAG 的不是“调一个接口”，而是检索质量×提示工程×评估×安全的系统工程——这是资深 AI 后端做知识型产品的核心能力。
