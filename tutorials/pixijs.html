PixiJS / WebGL

用 GPU 加速画 2D 图形的渲染库 —— 网页游戏火柴人派对用它画大屏画面。

1. 这是什么

WebGL 是浏览器调用显卡（GPU）画图的标准接口；PixiJS 是把 WebGL 难用的底层 API 封装成简单好用的 2D 渲染库。网页游戏要画几百个精灵、做丝滑动画，用 DOM 元素会卡死，必须用 GPU 渲染——这就是 PixiJS 的舞台。

2. 为什么用 GPU

方式原理适合
DOM / CSS浏览器排版引擎普通网页，几十个元素
Canvas 2DCPU 软件绘制简单动画、少量图形
WebGL / PixiJSGPU 并行渲染游戏、海量精灵、60fps

3. 第一个例子

import { Application, Sprite, Texture } from 'pixi.js';

const app = new Application();
await app.init({ width: 800, height: 600, background: '#0b1020' });
document.body.appendChild(app.canvas);

const sprite = Sprite.from('hero.png');   // 一个“精灵”（可移动的图像）
sprite.x = 100; sprite.y = 100;
app.stage.addChild(sprite);                // 加到舞台才显示
要点：所有要显示的物体都 addChild 到 app.stage（舞台），每帧 PixiJS 自动用 GPU 重绘。

4. 游戏主循环

游戏每秒要重画 60 次，PixiJS 提供 ticker：

app.ticker.add((ticker) => {
  sprite.x += 3;                       // 每帧让精灵右移
  if (sprite.x > 800) sprite.x = 0;    // 出界回到左边
});

5. 常见坑

坑 1：资源没加载完就 Sprite.from 会得到空白——用 Assets.load 先加载再创建。
坑 2：忘记 addChild，物体不显示，是最常见的新手错误。
坑 3：移动端注意 resolution 与 autoDensity，否则高分屏模糊。
