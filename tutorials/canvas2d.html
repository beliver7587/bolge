Canvas 2D

浏览器原生的“画布”绘图 API —— 不依赖任何库，画线、画图、做动画、做小游戏都行。学完你能脱离框架直接画 2D 画面。

1. 这是什么

Canvas 是 HTML 的一个 <canvas> 元素，配 JavaScript 的 2D 上下文（getContext('2d')），可以像素级地绘制图形、文字、图像。

一句话：它是一个“画板”，你用 JS 命令在上面画点、线、矩形、圆，并一帧帧更新做成动画。
vs PixiJS：Canvas 2D 是底层标准、零依赖、易上手；PixiJS 在其上封装、用 GPU 更快。新手先学 Canvas 2D 打基础。

2. 环境准备

零依赖，只要一个浏览器 + 文本编辑器。新建 index.html 即可。

3. 第一个画布

<canvas id="cv" width="400" height="300"></canvas>
<script>
const cv = document.getElementById('cv');
const ctx = cv.getContext('2d');      // 拿到画笔
ctx.fillStyle = '#5b8cff';
ctx.fillRect(50, 50, 120, 80);        // 画一个矩形
</script>
提示：canvas 的 width/height 属性才是真实像素尺寸；用 CSS 改大小会拉伸模糊，要用 cv.width = ...。

4. 画图形/文字

ctx.fillStyle = '#39e0d0';  ctx.fillRect(0,0,40,40);   // 实心矩形
ctx.strokeStyle = '#fff';  ctx.strokeRect(60,0,40,40); // 描边矩形
ctx.beginPath(); ctx.arc(150, 40, 20, 0, Math.PI*2); ctx.fill(); // 圆
ctx.fillStyle = '#fff'; ctx.font = '20px sans-serif';
ctx.fillText('你好', 200, 45);

5. 动画循环

function loop() {
  ctx.clearRect(0, 0, cv.width, cv.height);   // 清空上一帧
  // ...在这里画新位置...
  requestAnimationFrame(loop);                // 下一帧
}
loop();

6. 鼠标交互

cv.addEventListener('mousemove', (e) => {
  const x = e.offsetX, y = e.offsetY;   // 相对画布坐标
  console.log(x, y);
});

7. 实战：弹球

const cv = document.getElementById('cv');
const ctx = cv.getContext('2d');
let x = 50, y = 50, vx = 3, vy = 2;
function loop() {
  ctx.clearRect(0, 0, cv.width, cv.height);
  x += vx; y += vy;
  if (x < 10 || x > cv.width-10) vx *= -1;
  if (y < 10 || y > cv.height-10) vy *= -1;
  ctx.beginPath(); ctx.arc(x, y, 10, 0, Math.PI*2);
  ctx.fillStyle = '#facc15'; ctx.fill();
  requestAnimationFrame(loop);
}
loop();
运行：在 <canvas id="cv" width="400" height="300"></canvas> 下方放这段脚本，黄小球会在框内反弹。

8. 常见坑

坑 1：用 CSS 设宽高导致画面模糊——用 cv.width/height 属性设真实分辨率（高 DPI 屏乘以 devicePixelRatio）。
坑 2：忘记 beginPath()，多条路径连在一起乱画。
坑 3：动画不清除上一帧，画面糊成一片——每帧 clearRect。
坑 4：ctx 状态（fillStyle 等）会保留，连续画不同颜色要重新赋值。
坑 5：大量对象逐帧重画卡顿——考虑用 PixiJS/WebGL。

9. 下一步

  1. 用 Canvas 做一个随鼠标移动的光标特效。
  2. 学 PixiJS 提升渲染性能。
  3. 学 Socket.IO 把画布状态同步给多人。
  4. 看主页动态背景，就是 Canvas 粒子。
毕业：能拿画笔、画图形文字、做动画循环与交互——原生 2D 绘图你已掌握。
