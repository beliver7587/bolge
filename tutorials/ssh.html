SSH / 服务器部署

从买云服务器到上线 —— 把代码跑在 24h 开机的云电脑上。

1. 这是什么

SSH（Secure Shell）是你远程控制服务器的命令行通道——部署、看日志、改配置全靠它。所谓“部署上线”，就是把本地写好的代码传到云服务器、启动服务、用 Nginx 对外暴露。

2. 买机与登录

选一家云厂商开一台 Ubuntu 的云服务器（本项目用 2 核 2G），拿到公网 IP。登录：

ssh ubuntu@服务器IP      # 输入密码；推荐改用密钥登录更安全
名词：IP=门牌号，域名=好记别名，端口=楼内房间号（22=SSH，80=HTTP，443=HTTPS）。

3. 上传文件

scp -r ./dist ubuntu@IP:/home/ubuntu/app    # 安全拷贝（基于 SSH）

也可 git clone 直接拉代码。上传后 npm install 装依赖、pm2/systemd 启动。

4. 完整链路

本地写代码 → 构建成静态/后端 → scp/git 上传 → 服务器装依赖 + 启动 → Nginx 反代 + HTTPS → 浏览器打开域名，真机验证

5. 常见坑

坑 1：SSH 坏了进不去服务器——改 sshd 配置前先备份、改完开新终端测试（网页游戏项目真实事故：UseDNS 卡死）。
坑 2：安全组只开放 22/80/443，游戏端口绑 127.0.0.1 别暴露。
坑 3：DNS 解析要等几分钟才生效，期间用 IP 访问即可。
