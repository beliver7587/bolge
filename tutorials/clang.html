C 语言：从小白到理解计算机底层

C 是贴近硬件的系统级语言，操作系统、数据库、编译器大多由它或它的子孙写成。本教程讲清指针与内存——这是理解“程序到底怎么跑”的钥匙。

1. 它为什么重要

学 C 不是要写业务，而是理解：内存怎么排布、指针怎么寻址、堆栈怎么工作。这些概念是 Java、Python、甚至 前端 性能优化的底层基础。

一句话：C = 离机器最近的高级语言。手动管内存，零抽象开销。

2. 起步

#include <stdio.h>
int main() {
  printf("hello\n");
  return 0;
}

编译：gcc main.c -o main && ./main。没有运行时/虚拟机，编译出机器码直接跑。

4. 指针

指针是存内存地址的变量，是 C 的灵魂也是最大难点。

int x = 10;
int *p = &x;        // p 指向 x 的地址
printf("%d", *p);   // 解引用，得到 10
*p = 20;            // 通过指针改 x
坑：未初始化/已释放的指针是“野指针”，解引用会崩溃或破坏内存。务必初始化为 NULL。

5. 数组与字符串

int a[3] = {1,2,3};
char s[] = "hi";     // 字符串是 char 数组，末尾 '\0' 结束
  • 数组名在很多语境下退化成指针，a[i] 等价于 *(a+i)。
  • 字符串靠 '\0' 判断结束，忘写会越界读。

6. 内存管理

int *p = malloc(sizeof(int) * 10);  // 堆上分配
free(p);                            // 用完必须释放
两大坑：① 忘记 free → 内存泄漏；② 释放后再用 / 重复释放 → 悬空指针崩溃。

7. 结构体

struct User { int id; char name[32]; };
struct User u = {1, "王越"};
struct User *p = &u; printf("%d", p->id);

结构体把相关数据打包，指针用 -> 访问成员。

8. 函数与多文件

  • 函数先声明后使用；多文件用 .h 头文件声明、.c 实现。
  • static 限制作用域；extern 跨文件引用。

9. 常见坑

坑 1 缓冲区溢出：strcpy 不检查长度，超了就覆盖别的内存；用 strncpy/边界判断。
坑 2 数组越界：C 不帮你检查，越界是未定义行为。
坑 3 内存泄漏/悬空：见第 6 节，配对 malloc/free，释放后置 NULL。

10. 与高级语言

高级语言（Java、Python、JS）有 GC 和边界检查，省心但慢一点。理解 C 后能看懂它们底层的“代价”在哪。

11. 资源与路线

  1. 《C 程序设计语言》（K&R）经典。
  2. 练：写一个含动态数组与结构体的小工具，体会 malloc/free。
  3. 进而学操作系统/数据结构，理解底层。
资深标志：把指针与内存当成直觉，能分析“这段 C 为什么崩/漏”，并理解高级语言 GC 背后的取舍。
