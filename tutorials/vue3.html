Vue 3

渐进式前端框架 —— 用“数据驱动视图”，改数据页面自动变。国内项目、uni-app 都用它。学完你能写可交互的 Vue 页面。

1. 这是什么

Vue 3 是声明式框架：你描述“数据长什么样”，它负责把数据渲染成 DOM；数据一变，视图自动更新，不用手动操作 DOM。

对比：React 用 JSX 写组件；Vue 用模板（HTML 风格）写，更贴近原生 HTML，上手更直观。
核心：组合式 API（ref/reactive）+ 单文件组件（.vue）。

2. 环境准备

用官方脚手架起项目（需装 Node.js）：

npm create vue@latest my-app
cd my-app && npm install && npm run dev

浏览器打开提示的 http://localhost:5173 即看到页面。

3. 第一个组件

<template>
  <h1>{{ msg }}</h1>
</template>
<script setup>
const msg = '你好 Vue';
</script>

4. 响应式数据

用 ref 让数据变“响应式”，改它页面自动刷新：

<script setup>
import { ref } from 'vue';
const count = ref(0);
function add() { count.value++; }   // 注意 ref 要用 .value
</script>

5. 事件与绑定

<template>
  <p>计数：{{ count }}</p>
  <button @click="add">+1</button>
  <input v-model="text" placeholder="输入">
</template>
要点：@click 绑定事件，v-model 双向绑定表单，v-for 列表渲染，v-if 条件渲染。

6. 一个计数器

<template>
  <button @click="add">点了 {{ count }} 次</button>
</template>
<script setup>
import { ref } from 'vue';
const count = ref(0);
const add = () => count.value++;
</script>

7. 常见坑

坑 1：ref 在 JS 里要 .value，模板里不用；混用导致读不到值。
坑 2：直接给 reactive 对象整体替换（obj = {...}）会丢失响应式；用 Object.assign 改属性。
坑 3：在 setup 外定义普通变量当状态，不会触发更新。
坑 4：v-for 没加 :key，列表重排错乱；用稳定唯一值作 key。
