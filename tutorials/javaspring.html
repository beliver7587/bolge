Java Spring

Java 企业级框架家族 —— 用 IoC/DI 解耦、注解驱动开发，含 Spring Boot 一键启动。学完你能用 Java 写后端服务。

1. 这是什么

Spring 是 Java 生态最主流的后端框架，核心思想 IoC（控制反转） 与 DI（依赖注入）：对象的创建和依赖由容器管理，你只管写业务逻辑。Spring Boot 在其上做“自动配置”，让你几乎零 XML 就能跑起来（详见 Spring Boot）。

一句话：Spring 负责“搭好一切”，你只填业务；Spring Boot 让你“开箱即跑”。

2. 环境准备

装 JDK 17+ 与 Maven/Gradle。最简方式：用 start.spring.io 在线生成项目骨架，或用 IDE（IntelliJ IDEA）新建 Spring Boot 项目。

# 用 Spring Boot CLI 也可
brew install springboot

3. 第一个接口

@RestController
public class HelloController {
  @GetMapping("/hello")
  public String hello() { return "Hello Spring"; }
}

启动后访问 http://localhost:8080/hello 即返回文字。

4. IoC / DI

@Service
public class UserService { public String name() { return "小王"; } }

@RestController
public class C {
  @Autowired private UserService svc;   // 容器自动注入
  @GetMapping("/who") public String who() { return svc.name(); }
}
要点：@Component/@Service/@Controller 交给容器管理，@Autowired 注入依赖，解耦且易测试。

5. 分层架构

经典三层：Controller（接收请求）→ Service（业务逻辑）→ Repository/DAO（数据）。配合 MyBatis-Plus 操作数据库。

6. 与数据库

在 application.properties 配数据源，用 Spring Data JPA 或 MyBatis-Plus 写 CRUD，无需手写大量样板。

7. 常见坑

坑 1：循环依赖（A 注入 B、B 注入 A）；用构造器注入或拆分层解决。
坑 2：包扫描不到 Bean（类不在启动类同包或子包）；注意 @SpringBootApplication 位置。
坑 3：端口被占用启动失败；改 server.port。
坑 4：JDK 版本与 Spring Boot 不匹配；Boot 3 需 JDK 17+。
