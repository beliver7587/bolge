Java Spring：从小白到资深后端

Spring 是 Java 企业级开发的基石框架，核心是 IoC 容器与 AOP，衍生出 MVC、Data、Security、Cloud 等全家桶。Spring Boot 是它的“一键启动器”。本教程讲透容器本质、DI、AOP 代理、声明式事务、MVC 请求流程与生态分工——这是资深 Java 工程师的内功。

1. 它解决什么问题

早期 JavaEE/EJB 配置繁琐、侵入性强。Spring 用轻量容器 + 非侵入 解决：对象创建与依赖交给容器（IoC），横切逻辑（事务、日志、鉴权）用切面剥离（AOP），业务代码保持纯净。

一句话：Spring 提供“对象如何被创建/组装/增强”的基础设施，让你专注业务；Spring Boot 在此之上做自动配置让你开箱即跑。
适合：一切 Java 后端；尤其需要长期演进、强类型、大团队协作的企业系统。

2. 工程化起步

  • JDK 17+（Spring 6/Boot 3 要求），Maven 或 Gradle。
  • 用 start.spring.io 勾选依赖生成骨架；Spring Boot 章节讲启动细节。
  • 标准包结构：controller / service / repository / config / dto。

3. IoC 容器

ApplicationContext 是容器，管理 Bean 的注册、实例化、装配与生命周期。

@Configuration
public class AppConfig {
  @Bean
  public UserService userService() { return new UserService(); }  // 手动声明 Bean
}
  • 作用域：singleton（默认，全局一个）、prototype（每次取新实例）、request/session（Web 作用域）。
  • 生命周期：实例化 → 属性填充 → @PostConstruct → 就绪 → @PreDestroy。
  • 扫描：@ComponentScan 自动发现 @Component/@Service/@Controller。

4. 依赖注入

@Service
public class OrderService {
  private final PaymentClient pay;          // 构造注入（推荐，不可变、易测）
  public OrderService(PaymentClient pay) { this.pay = pay; }
}
  • 构造注入 > 字段注入：字段 @Autowired 难测试、隐藏依赖、循环依赖更难查。
  • 条件化装配 @ConditionalOn...：Spring Boot 自动配置靠它按 classpath 决定装不装 Bean。

5. AOP 切面

AOP 把“横切关注点”（日志、事务、鉴权、监控）从业务里抽出来，用代理在方法前后织入。

@Aspect
@Component
public class LogAspect {
  @Around("execution(* com.demo.service..*(..))")
  public Object log(ProceedingJoinPoint p) throws Throwable {
    long t = System.nanoTime();
    try { return p.proceed(); }
    finally { System.out.println(p.getSignature() + " 耗时 " + (System.nanoTime()-t)); }
  }
}
  • 代理机制：有接口用 JDK 动态代理，否则 CGLIB 子类代理——这决定了 @Transactional 等注解只能拦截“外部调用”（见第 6 节）。
  • 切面顺序用 @Order 控制。

6. 声明式事务

@Transactional 本质是 AOP：方法开始前开事务、正常提交、异常回滚。

失效根因：① 自调用（同类方法互调绕过代理）② 非 public ③ 异常被 catch 吞掉 ④ 数据库引擎不支持（如 MyISAM）。要生效须“经代理的外部调用”。

7. Spring MVC

请求流程：DispatcherServlet → HandlerMapping 找控制器 → HandlerAdapter 执行 → 返回 ModelAndView/JSON，经 ViewResolver/消息转换器输出。注解 @RequestMapping/@GetMapping/@RequestBody/@Valid 驱动。

8. 生态全景

  • Spring Data：统一 Repository 抽象（JPA/MongoDB/Redis）。
  • Spring Security：认证授权（详见 Spring Boot 安全节）。
  • Spring Cloud：微服务套件（注册中心、网关、熔断、配置中心）。
  • Spring Batch：批处理；Spring AMQP/Kafka：消息。

9. 与 Boot 分工

分工：Spring = 内核（容器/AOP/事务/MVC）；Spring Boot = 在此之上的“自动配置 + 起步依赖 + 内嵌服务器”，让你零配置启动。学 Boot 前先懂 Spring 内核，排错才知根因。

10. 常见坑

坑 1：循环依赖（A↔B）；构造注入下直接启动失败，逼你拆边界。
坑 2：包扫描路径不对 → Bean 未注册 NoSuchBeanDefinition。
坑 3：@Transactional 自调用失效 → 拆 Bean 或走代理。
坑 4：singleton 里注入 prototype 但每次都是同一个 → 用 ObjectProvider 或 lookup。
坑 5：上下文过大（扫太多包）拖慢启动；按模块切分。

11. 调试

  • IDEA 断点；--debug 看自动配置报告；/actuator/beans 看容器 Bean。
  • 用 Arthas 在线诊断 Bean/代理/方法耗时。

12. 成长路线

阶段能力标志
小白能写 Bean、接口、分层
初级懂 DI、MVC 流程
中级懂 AOP、事务边界、容器原理
资深设计模块边界、排代理/事务疑难、用 Cloud 做微服务
练习：① 手写 @Bean 配置并对比 @ComponentScan ② 写一个 @Aspect 统计 Service 耗时 ③ 故意自调用触发 @Transactional 失效并修复 ④ 读自动配置报告理解条件装配。
你已进阶：理解 Spring 内核（容器/AOP/事务）与 Boot 的分工，能设计清晰边界、排代理与事务疑难——这是资深 Java 工程师的硬功夫。
