Python

语法简洁、用途极广的脚本语言 —— AI、数据分析、自动化首选，初学者最友好。学完你能写自动化脚本与小工具。

1. 这是什么

Python 以可读性强著称，几乎不用写样板，几行就能干大事。它是 AI/机器学习、爬虫、运维脚本、后端（Django/FastAPI）的通用语言。

对比：比 Java/C 少很多仪式代码；适合快速实现想法。

2. 环境准备

装 Python 3.10+（勾选 “Add to PATH”）。建议用虚拟环境隔离依赖：

python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

3. 第一个程序

print("Hello Python")
name = input("你叫什么？")
print("你好", name)

保存为 hi.py，运行：python hi.py

4. 基础语法

nums = [1, 2, 3]
for n in nums:
    if n % 2 == 0:
        print(n, "是偶数")
# 字典
d = {"age": 18}
print(d.get("age"))
要点：用缩进表示代码块（不用花括号）；变量无需声明类型。

6. 实战：脚本

批量重命名文件、自动发请求、定时爬数据……Python 几行搞定。例如读 CSV：

import csv
with open("data.csv") as f:
    for row in csv.reader(f):
        print(row)

7. 常见坑

坑 1：缩进不一致（空格/Tab 混用）直接报错；统一用 4 个空格。
坑 2：可变默认参数陷阱：def f(x=[]) 会共享；用 x=None。
坑 3：全局装包污染；务必用虚拟环境。
坑 4：Python 2 与 3 语法不同；确认用 3。
