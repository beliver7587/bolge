Tailwind CSS

用“类名”直接写样式的工具库 —— 不用再写一堆 CSS 文件。学完你能几秒钟排出好看的界面。

1. 这是什么

Tailwind 是“原子化 CSS”框架：它提供成千上万个小类名（如 flex、p-4、text-red-500），你把类名直接写到 HTML 上，样式就生效，不用自己写 CSS 规则。

对比：传统写法要先写 .card{...} 再用 class="card"；Tailwind 直接 class="rounded-lg p-4 bg-white shadow"，所见即所得。
为什么火：不用起名、不用来回切文件、复用度高、打包后体积小（只保留用到的类）。

2. 环境准备

已有 Vite / Next.js 项目即可。没项目先按 Vite 或 Next.js 建一个。

3. 装到项目里

npm install -D tailwindcss @tailwindcss/postcss postcss
npx tailwindcss init -p        # 生成 tailwind.config.js + postcss.config.js

在 tailwind.config.js 指定要扫描的文件：

export default {
  content: ['./index.html', './src/**/*.{js,ts,jsx,tsx}'],
  theme: { extend: {} },
  plugins: []
}

在 CSS 入口（如 src/index.css）引入三个指令：

@tailwind base;
@tailwind components;
@tailwind utilities;

4. 第一个样式

<button class="bg-blue-600 text-white px-4 py-2 rounded-lg hover:bg-blue-700">
  点我
</button>

含义：蓝色背景 / 白字 / 左右内边距 4 / 上下 2 / 圆角 / 悬停更深蓝。保存即生效，不用写一行 CSS！

5. 常用类速查

想要的效果类名
弹性布局flex items-center justify-between
间距p-4(内) m-2(外) gap-3
文字text-sm text-red-500 font-bold
背景/边框bg-white border rounded-xl
阴影shadow shadow-lg
尺寸w-full h-10 max-w-md

6. 响应式

前缀代表断点：sm: md: lg: xl:。

<div class="grid grid-cols-1 md:grid-cols-3 gap-4">
  <!-- 手机 1 列，≥768px 变 3 列 -->
</div>

7. 暗色模式

在 config 开启 darkMode: 'class'，然后给根节点加 class="dark"：

<div class="bg-white dark:bg-gray-900 text-black dark:text-white">...

8. 常见坑

坑 1：样式不生效：八成是 content 路径没包含你的文件，Tailwind 没扫描到。
坑 2：忘了引入 @tailwind 三条指令，页面完全没有样式。
坑 3：动态拼接类名（class={"text-" + color}）Tailwind 扫描不到，不会被打包。要用完整字符串或 safelist。
坑 4：类名写太长影响可读性；复杂组件可抽成组件或用 @apply 在 CSS 里聚合。

9. 下一步

  1. 把现有项目的 CSS 慢慢换成 Tailwind 类名。
  2. 配合 React 做组件。
  3. 需要现成组件用 Ant Design（后台）或 Tailwind UI 模板。
  4. 看简历工坊源码，里面大量使用 Tailwind。
毕业：能在 Vite/Next 里配置 Tailwind，用原子类快速排版、做响应式与暗色——前端界面效率直接翻倍。
