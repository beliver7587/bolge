PM2

Node.js 进程管理器 —— 让后端服务后台常驻、崩溃自动重启、多进程利用多核。学完你能把 Node 服务稳稳跑在服务器上。

1. 这是什么

PM2 是 Node 的进程守护工具。直接 node server.js 关掉终端就停了；用 PM2 启动后，它在后台跑，挂了自动拉起，还能看日志、做负载。

一句话：PM2 就像给 Node 服务配了个“保姆”，宕机自动复活、开机自动启动。

2. 环境准备

sudo npm install -g pm2
pm2 -v

3. 启动进程

pm2 start server.js --name my-api
# 或带环境变量
pm2 start server.js --name my-api --env production

4. 常用命令

命令作用
pm2 list看所有进程
pm2 logs my-api看日志
pm2 restart my-api重启
pm2 stop / delete停止 / 删除
pm2 monit实时监控面板

5. 集群模式

用多进程吃满多核 CPU：

pm2 start server.js -i max     # max = 按 CPU 核数起进程

6. 开机自启

pm2 save                     # 保存当前进程列表
pm2 startup                  # 生成开机启动脚本（按提示执行）

7. 常见坑

坑 1：忘了 pm2 save，服务器重启后进程没起来；save + startup 一起做。
坑 2：日志无限增长占满磁盘；配置日志轮转 pm2 install pm2-logrotate。
坑 3：端口被旧进程占着，新启动失败；pm2 delete 旧的再起。
坑 4：全局装的 pm2 在 sudo 下找不到；用 npm root -g 确认路径或加软链。
