Java

一次编写、到处运行的面向对象语言 —— JVM 跨平台，企业后端与安卓的主力。学完你能用 Java 写程序与后端。

1. 这是什么

Java 是静态类型、面向对象的语言，靠 JVM（Java 虚拟机）实现“一次编译，到处运行”。它语法严谨、生态庞大，是银行/电商/安卓的默认选择。

对比：Python 动态、简洁；Java 强类型、严谨、适合大型协作项目。
生态：Spring 家族是企业后端事实标准。

2. 环境准备

装 JDK（建议 17+），配好 JAVA_HOME。验证：

java -version
javac -version

3. 第一个程序

public class Hello {
  public static void main(String[] args) {
    System.out.println("Hello Java");
  }
}

保存为 Hello.java，编译运行：javac Hello.java && java Hello

4. 面向对象

class Person {
  String name;
  Person(String n) { name = n; }
  void say() { System.out.println("我是" + name); }
}
要点：类/对象、封装、继承、多态是 Java 核心；一切围绕对象组织。

5. 集合

用 List、Map、Set 管理一组数据：

List<String> list = new ArrayList<>();
list.add("a");
Map<String, Integer> map = new HashMap<>();
map.put("age", 18);

6. 异常处理

try {
  int x = 1 / 0;
} catch (Exception e) {
  System.out.println("出错：" + e.getMessage());
}

7. 常见坑

坑 1：类名与文件名必须一致（public 类）；否则编译失败。
坑 2：空指针 NullPointerException；调用前判空或用 Optional。
坑 3：== 比较对象比的是引用而非内容；字符串用 equals。
坑 4：忘记释放资源（流/连接）；用 try-with-resources。
