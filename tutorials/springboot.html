Spring Boot

Java 后端一站式框架 —— 简历工坊后端用它搭 REST 服务。

1. 这是什么

Spring Boot 是基于 Spring 的Java 后端框架，核心口号是“约定优于配置”：你不用写一堆 XML 和繁琐配置，它帮你把常用组件（Web、数据库、安全）自动装配好，几行代码就能起一个可运行的后端服务。

2. 为什么用它

能力说明
内嵌服务器自带 Tomcat，java -jar 直接跑，不用另装
自动配置引入依赖即自动装配，极大减少样板
生态完整安全、数据库、缓存、消息全家桶

3. 第一个接口

@RestController
@RequestMapping("/api/user")
public class UserController {
  @GetMapping("/{id}")                  // GET /api/user/1
  public String get(@PathVariable Long id){
    return "用户" + id;
  }
}
注解是关键：@RestController 声明这是个接口类；@GetMapping 把方法映射到某个 URL；Spring 自动把返回值转成 JSON。

4. 分层结构

Controller（接收请求） → Service（业务逻辑） → Mapper / Repository（操作数据库，见 MyBatis-Plus） → Entity（数据模型）

5. 常见坑

坑 1：端口冲突：默认 8080，被占就在 application.yml 改 server.port。
坑 2：依赖版本不匹配（JDK 与 Spring Boot 版本要对应），IDE 报一堆错。
坑 3：跨域：前端不同源访问接口要加 @CrossOrigin 或全局 CORS 配置。
搭配：数据库访问看 MyBatis-Plus，部署看 systemd / Nginx。
