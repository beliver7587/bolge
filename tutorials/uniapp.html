uni-app：从小白到资深前端

uni-app 用 Vue 语法写一套代码，编译到 H5、微信/支付宝等小程序、App（iOS/Android）。本教程讲透跨端编译原理、条件编译、pages.json 路由、平台差异与原生能力——这是资深做跨端工程的实战认知。

1. 它解决什么问题

一套业务要在 H5、多个小程序、App 上跑，各端语法/API 不同，重复开发成本高。uni-app 用统一的 Vue 代码 + 编译转换，一次编写多端发布。

一句话：uni-app 把 Vue 代码编译成各端的原生形态（小程序 WXML/微信 API、H5 的 Web、App 的 Weex/native），兼顾开发效率与覆盖。
对比：纯原生（每端一套，体验最好但成本高）；Flutter/RN（跨 App 强，但小程序支持弱）；uni-app（小程序 + H5 + App 全覆盖，国内生态好）。

2. 工程化起步

npm install -g @vue/cli
vue create -p dcloudio/uni-preset-vue my-uniapp
cd my-uniapp && npm install
npm run dev:h5          # 跑 H5
npm run dev:mp-weixin   # 跑微信小程序（用微信开发者工具打开 dist）

也可用官方 HBuilderX（可视化、真机调试方便）。

3. 核心机制

<template>
  <view class="content">{{ title }}</view>   <!-- 用 view 而非 div（小程序生效） -->
</template>
<script setup>
const title = '你好 uni-app';
</script>
  • 语法是 Vue，但组件要用 uni 内置标签（view/text/image），它们在各端映射到原生组件。
  • 生命周期：应用级 onLaunch、页面级 onLoad/onShow（兼容 Vue 的 onMounted）。

4. 跨端原理

uni-app 在编译期把 Vue SFC 转成目标平台代码：小程序端生成 .wxml/.wxss/.js 并调用微信 API；H5 端生成标准 Web；App 端走原生渲染。因此运行时不依赖 Vue 运行时解释，而是真编译。

坑底：不是“运行时兼容层”，所以各端能力差异要在编译期/代码里处理（见条件编译）。

5. 组件与 API

  • UI 用 uni 组件（view/text/scroll-view/swiper），别用 HTML 标签（小程序不认）。
  • 设备/网络 API 用 uni.xxx：uni.request、uni.navigateTo、uni.getSystemInfo。
uni.request({ url: '/api/user', success: (res) => console.log(res.data) });

6. 路由与页面

路由在 pages.json 声明（不是写路由文件）：

{
  "pages": [
    { "path": "pages/index/index", "style": { "navigationBarTitleText": "首页" } },
    { "path": "pages/user/user" }
  ],
  "tabBar": { "list": [{ "pagePath": "pages/index/index", "text": "首页" }] }
}
要点：新页面要在 pages 数组登记，否则编译不到；tabBar 做底部导航。

7. 状态与样式

  • 状态管理同 Vue：Pinia 可用。
  • 尺寸用 rpx（响应式像素，750rpx = 屏宽），自动适配不同屏幕；H5 也可用 px。

8. 原生能力

  • 插件市场：DCloud 插件市场有大量原生扩展（支付、地图、推送）。
  • 原生模块 / 离线打包：需要深度原生能力时用原生插件或 App 离线打包。
  • 条件编译调用平台 API：// #ifdef MP-WEIXIN ... // #endif。

9. 性能与分包

  • 小程序分包：主包超限（如微信 2MB）要拆 subPackages，首屏只下主包。
  • 长列表用 scroll-view 或虚拟列表，避免一次性渲染。
  • H5 端按需引入，减包。

10. 常见坑

坑 1：用 div/span 而非 view/text → 小程序端不渲染或异常。
坑 2：平台 API 差异（如 H5 有 window、小程序没有）→ 必须用条件编译，否则某端崩。
坑 3：条件编译散落各处，代码可读性差；集中抽“平台适配层”。
坑 4：小程序主包超体积 → 不分包无法上传。
坑 5：V3/Vue3 模式下部分旧 API 不支持，要查兼容表。

11. 调试

  • H5：浏览器 DevTools。
  • 小程序：对应平台开发者工具（微信/支付宝）。
  • App：HBuilderX 真机运行 / 模拟器。

12. 成长路线

阶段能力标志
小白能创建项目、写页面跑 H5/小程序
初级会路由、API、条件编译
中级分包、原生插件、平台适配层
资深设计跨端架构、把控包体积与各端质量
练习：① 用 uni-app 写一个列表页并跑 H5 + 微信小程序 ② 用 pages.json 配 tabBar ③ 写一个只在微信端生效的功能（条件编译）④ 给小程序做分包。
你已进阶：理解“编译到多端”的跨端范式，能在平台差异中设计出稳健的适配架构——这是资深跨端工程师的能力。
