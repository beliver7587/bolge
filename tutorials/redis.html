Redis

内存键值数据库 —— 用作缓存与会话存储，给后端提速。

1. 这是什么

Redis 是把数据放在内存里的键值数据库，读写极快（微秒级），常用于“缓存”（把慢查询的结果暂存）、“会话存储”、“排行榜”、“限流计数”。它是 MySQL 的好搭档：热数据放 Redis，冷数据放 MySQL。

2. 为什么快

核心：数据在内存 + 单线程事件循环 + 极简协议，所以快；但内存贵、重启可能丢（可配持久化）。

3. 常用数据结构

类型用途
String缓存值、计数器（INCR）
Hash存对象（用户信息）
List队列、最新列表
ZSet排行榜（带分数排序）

4. 实战用法

# 缓存：先查 Redis，没有再查库并写入
GET resume:1
SET resume:1 "{...}" EX 300     # 缓存 5 分钟

# 限流：1 分钟内最多 60 次
INCR rate:ip:1.2.3.4
EXPIRE rate:ip:1.2.3.4 60
简历工坊用法：把频繁读取的简历/模板缓存起来，减轻 MySQL 压力；登录会话也可放 Redis 实现多端共享。

5. 常见坑

坑 1：键没设过期时间，内存被撑爆——缓存必须带 TTL。
坑 2：把 Redis 当主库，重启丢数据——重要数据要持久化(AOF/RDB)或仍落 MySQL。
坑 3：大 key（单值过大）会阻塞，注意拆分。
