better-sqlite3

Node 的嵌入式 SQLite 库 —— Memora 用单机文件存用户与记忆。

1. 这是什么

SQLite 是“单文件数据库”，不用启服务，一个 .db 文件就是整个库。better-sqlite3 是 Node 上最快的 SQLite 驱动，而且 API 是同步的，写起来直观，没有回调/Promise 缠绕。

2. 同步 vs 异步

对比：多数 Node 库是异步（await）；better-sqlite3 故意用同步——因为本地文件 IO 很快，同步反而更简单且性能更好（Memora 实测足够）。

3. 基本用法

import Database from 'better-sqlite3';
const db = new Database('memora.db');   // 没有就自动创建

db.exec(`CREATE TABLE IF NOT EXISTS user(
  id INTEGER PRIMARY KEY, name TEXT)`);
const ins = db.prepare('INSERT INTO user(name) VALUES(?)');
ins.run('王越');

const row = db.prepare('SELECT * FROM user WHERE id=?').get(1);
console.log(row);

4. 事务

const tx = db.transaction((items) => {
  for (const it of items) ins.run(it);
});
tx([{name:'a'},{name:'b'}]);   // 要么全写，要么全不写
Memora 用法：记忆去重/冲突消解就是在事务里批量比对+写入，保证一致性。

5. 常见坑

坑 1：它是原生模块，安装时要本地编译——Node 22 可能失败，锁 Node 20 并用 npm rebuild（Memora 真实踩坑）。
坑 2：同步阻塞：单次查询很慢（如大批量）会卡住事件循环，大数据量请换 MySQL/Postgres。
坑 3：并发写要小心，单连接串行；高并发场景不适合。
