n8n

开源的工作流自动化平台 —— 用拖拽节点把“触发→处理→动作”串起来，免写代码做自动化（类似 Zapier/Make）。学完你能搭一个自动化工单/通知流。

1. 这是什么

n8n 是可视化自动化工具：每个“节点”是一个动作（如定时、HTTP 请求、发邮件、调用 LLM），把节点连线就是一条自动化流水线。

一句话：不写代码，拖几个方块连起来，就能让“收到表单 → 存数据库 → 发 Slack 通知”自动跑。
适合：内部自动化、数据同步、AI 工作流编排（可内嵌大模型节点）。

2. 环境准备

最省事用 Docker：

docker run -d --name n8n -p 5678:5678 -e N8N_SECURE_COOKIE=false n8nio/n8n

浏览器打开 http://服务器IP:5678 即可。

3. 第一个工作流

  1. 新建 Workflow。
  2. 加一个 Trigger 节点（如 Manual Trigger 手动触发，或 Schedule 定时）。
  3. 加一个 Function 节点处理数据，或 HTTP Request 调接口。
  4. 连线后点 Execute 运行。

4. 节点与连线

数据在节点间以 JSON 流转：上一个节点的输出，是下一个节点的输入。可在节点里用表达式 {{ $json.field }} 取上一步的字段。

// Function 节点示例
return [{ json: { msg: '你好 ' + $json.name } }];

5. 接 Webhook / API

  • Webhook 节点：暴露一个 URL，外部 POST 进来即触发。
  • HTTP Request 节点：调用任意 REST API（如 Express 写的后端）。
  • AI 节点：内置 OpenAI/国产模型节点，可做“收到文本→大模型处理→存库”。

6. 常见坑

坑 1：节点数据格式不匹配（期望数组却给对象）；在 Function 节点用 return [{json:{...}}] 规范输出。
坑 2：Webhook 没配域名/HTTPS 在公网访问不便；配合 Nginx 反代。
坑 3：循环节点产生海量执行，把内存吃满；注意循环与批量设置。
坑 4：敏感凭据别硬编码在节点里，用 n8n 的 Credentials 管理。

  4. 看简历工坊自动化相关。
